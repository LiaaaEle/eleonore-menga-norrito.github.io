Home Screen: Campaign Follow-Up Tab

SEARCH TIP  Press CTRL + F (Windows and Linux) or CMD + F (Mac) to search within this page.

To access this screen, click Home.

NOTE This documentation presents you the Campaign follow-up tab and its different features.

For more information on this screen, see the following documentations:

  • Home Screen: Introduction

  • Home Screen: Overview Tab

  • Home Screen: Performance Tab

  • Home Screen: Action Portfolio Tab

  • Home Screen: Resources Tab

The Campaign follow-up tab gives you:

  • Your nonhistorical campaign progress

    NOTE The CSR Insight application supports two types of campaigns:

    • Historical campaigns: Proforma data collected by import through the Data Import screen
    • Nonhistorical campaigns: Data collected by manual entry through the Data Collection Campaigns screen

    NOTE The CSR Insight application supports two types of campaigns:

    • Historical campaigns: Proforma data collected by import through the Data Import screen
    • Nonhistorical campaigns: Data collected by manual entry through the Data Collection Campaigns screen

    To create campaigns, see Campaign Set Up or Data Recovery.

  • The number of alerts and questions related to this campaign

 

 

To view your campaign progress, select the desired campaign from the Choose a campaign drop-down menu.

NOTE If you select a campaign not deployed on the Entity selected from the point of view (POV), but deployed on one or multiple of its child entities, you can view a global campaign follow-up for this organization in aggregate mode.

 

To access your campaign, click the button.

The Data Collection Campaigns screen appears with your selected campaign.

 

To view your campaign progress by entity, click the button.

The Campaign Progress – Entity Vision screen appears with your selected campaign.

 

To access the pending alerts for this campaign, click the button.

The Alerts screen appears with the pending alerts for your selected campaign.

 

To access the questions related to this campaign, click the button.

The Chat Room pop-up panel appears at the right of the screen.
