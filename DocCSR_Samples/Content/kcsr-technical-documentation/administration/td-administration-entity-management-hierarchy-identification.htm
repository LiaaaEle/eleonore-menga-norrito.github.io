Security Notes

Some actions, such as screen access, are permitted only for authorized users, that is, users with the appropriate profile. In other words, if the user does not have the right profile, the user cannot perform the action.

To configure this security (also called user rights), complete the following steps:

  1. Define the profiles in the Profile Management screen.

  2. Define users and attach one or more profiles to them in the User Management screen.

  3. Assign user rights to the desired profiles in the Profile Matrix screen.

The Hierarchy column contains a list of entities included in the Hierarchy selected from the point of view (POV), and hierarchized by generation level with parent and child entities.

NOTE To know more on entity hierarchization, see the Entity Management: Introduction and Hierarchy Management documentations.

 

From the Hierarchy column, you can:

  • Create an Entity

  • Edit Identification Items for an Entity

  • Move an Entity

  • Duplicate an Entity

  • Disable an Entity

 

The Entity identification column contains identification items for each entity:

Item Description

Code

Code used to identify the entity uniquely. No duplicates are allowed.

This code contains letters and/or numbers. No spaces nor special characters are allowed.

Underscore and hyphen are allowed.

Label

Entity label. No duplicates are allowed. By default, displayed in your user language.

Entry date

Exit date

Dates on which the entity entered and exited the data collection scope.

These dates make it possible to note the variation in scope.

NOTE Scope variation is a proforma restatement. To know more on the Proforma feature, see the Proforma documentation.

Entity type

The entity type, that is its data collection point.

NOTE To manage entity types, see the Entity Type Management documentation.

You can also read the Entity Management: Three Dots Button to learn how to create an entity type.

Currency

Currency used within an entity.

 

From the Entity identification column, you can edit identification items for an entity.

 

Create an Entity

You can create a parent entity with the level 1 generation, or a child entity with a lower generation level from the Hierarchy column.

Create a Parent Entity

To create a parent entity with the level 1 generation:

  1. Click the button next to the label of the Hierarchy column.

    The Create entity pop-up panel appears.

  2. Enter the following information:

    • The Code

    • The Label in all languages available in the CSR Insight application.

      NOTE Only one Label sub-column will be displayed in the Entity Identification column. This Label is in the language you use in the CSR Insight application.

      On the contrary, the export file displays the entity label in all available languages.

  3. Select from the drop-down menus:

    • The Entry date

    • The Currency

  4. Enable or disable data collection for the entity by switching on or off the switch button.

  5. Optional: Select from the drop-down menus:

    • The Exit date

    • The Entity type

  6. Click Save.

Create a Child Entity

To create a child entity:

  1. Click right on the entity that you want to be the parent of the new child entity in the Hierarchy column.

    A drop-down menu appears.

  2. Click Create entity from the drop-down menu.

    The Create entity pop-up panel appears with the Parent field automatically filled in.

  3. Enter the following information:

    • The Code

    • The Label in all languages available in the CSR Insight application.

      NOTE Only one Label sub-column will be displayed in the Entity Identification column. This Label is in the language you use in the CSR Insight application.

      On the contrary, the export file displays the entity label in all available languages.

  4. Select from the drop-down menus:

    • The Entry date

    • The Currency

  5. Choose to enable or disable data collection for the child entity by switching on or off the switch button.

  6. Optional: Select from the drop-down menus:

    • The Exit date

    • The Entity type

  7. Click Save.

Edit Identification Items for an Entity

You can edit identifications items for an entity from the Hierarchy or the Entity identification column.

NOTE The currency of an entity can only be edited if no data is collected on it.

 

To edit identification items for an entity from the Hierarchy column:

  1. Click right on the entity for which you want to edit its identification items in the Hierarchy column.

    A drop-down menu appears.

  2. Click Edit entity from the drop-down menu.

    The Edit entity pop-up panel appears.

  3. Edit the information as desired.

  4. Click Save.

NOTE From the Hierarchy column, you can also enable or disable data collection for the entity by switching on or off the switch button.

 

To edit identification items for an entity from the Entity identification column:

  1. Position your cursor at the line of the entity for which you want to edit the identification items.

  2. Double-click the cell in the sub-column of the identification item you want to edit in the Entity identification column.

  3. Edit the information contained in the cell.

  4. Click the button at the top right of the nested grid.

  5. Repeat the same steps for each identification item you want to edit for the entity.

Move an Entity

There a two ways to move an entity from the Hierarchy column:

  • Change the Parent Entity of a Child Entity

  • Move Up or Down a Child Entity among the entities that have the same parent.

Change the Parent Entity of a Child Entity

NOTE Any change of parent entity for a child entity results in the modification of the data already consolidated.

To change the parent of an entity:

  1. Click right on the entity for which you want to change the parent entity in the Hierarchy column.

    A drop-down menu appears.

  2. Click Change parent from the drop-down menu.

    The Move the parent entity pop-up window appears to confirm the change.

  3. Click Validate.

    The Move organization pop-up panel appears with the Actual parent field automatically filled in.

  4. Select the New parent from the drop-down menu.

  5. Click OK.

Move Up or Down a Child Entity

You can rearrange child entities among themselves.

To do so:

  1. Drag and drop the line of the entity you want to move up or down.

    The Move confirmation pop-up window appears to confirm the move.

  2. Click OK.

Duplicate an Entity

You can duplicate an entity from the Hierarchy column if you have the right to add an entity.

Duplicating an entity means creating a new entity with the same identification elements as the duplicated entity except for its code and its labels in English and in French.

 

To duplicate an entity:

  1. Click right on the entity for which you want to change the parent entity in the Hierarchy column.

    A drop-down menu appears.

  2. Click Duplicate entity from the drop-down menu.

    The Duplicate entity pop-up panel appears with the Entry date, Exit date, Entity type, and Currency fields automatically filled in.

  3. Enter the following information:

    • The Code

    • The English label

    • The French label

  4. Click Save.

Disable an Entity

NOTE Entities can be disabled only if no data was entered or calculated in campaigns.

Disable an entity means make this entity inactive. An inactive entity can no longer be used in the CSR Insight application.

If you only want to disable data collection, and not exclude the entity from any use in the application, see the Entity Management: Usage Column documentation.

 

To disable an entity from the Hierarchy column:

  1. Click right on the entity that you want to disable in the Hierarchy column.

    A drop-down menu appears.

  2. Click Disable entity from the drop-down menu.

    The Deactivation pop-up window appears to confirm the deactivation.

  3. Click Validate.
