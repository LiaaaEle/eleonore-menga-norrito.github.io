User Access

SEARCH TIP  Press CTRL + F (Windows and Linux) or CMD + F (Mac) to search within this page.

To access this screen:

  1. Click Administration > Entity management.

  2. For an entity, click the cell in the User access sub-column of the Usage column.

    A list of users that have access to the entity appears.

  3. Click a user name from this list.

Security Notes

Some actions, such as screen access, are permitted only for authorized users, that is, users with the appropriate profile. In other words, if the user does not have the right profile, the user cannot perform the action.

To configure this security (also called user rights), complete the following steps:

  1. Define the profiles in the Profile Management screen.

  2. Define users and attach one or more profiles to them in the User Management screen.

  3. Assign user rights to the desired profiles in the Profile Matrix screen.

The table below contains screen actions that are related to user rights:

Module Screen Action

Entity management

Entity management

Screen access*

*Users who can access the Entity Management screen can access the User Access screen.

Introduction

The User access screen provides information on entity access by user and entity. This screen is read-only.

Key Benefits

  • Verify user permissions for specific entities

  • Conduct access audits efficiently

  • Identify permission inheritance pathways

Prerequisites

Access restrictions to entities are defined for each profile and user.

To display user access data, configure entity access restrictions in the Profile Management screen for profiles, then in the User Management screen for users.

Point of View (POV)

Users can filter entity access information by selecting the following items in the POV:

  • User: Select the user. By default, this item displays the user selected from the Usage column in the Indicator Management screen.

  • Entity: Select the entity for which to view access information. By default, this item displays the entity associated with the user selected from the Usage column in the Indicator Management screen.

The table displays the entity access based on the selected POV criteria. If the selected user cannot access the selected entity, the table remains empty.

Related screens

  • User Access: View functional scope access permissions by user (different from entity access)

  • User Audit Trail: Audit actions related to users and profiles

Description of the Table Columns

The table contains the following columns:

Column Description

Profile

Profile attached to the user.

NOTE To create and manage profiles, see Profile Management. To attach profiles to users, see User Management.

Scope

Functional scope to which the user has access. If a user has no access restrictions to functional scopes, All is displayed.

NOTE To create and manage functional scopes, see Functional Scope Management and Scope Indicators. To attach functional scopes to users, see User Management.

Access type

Type of entity access:

  • Direct from the current entity: The user can access the selected entity and all its child entities. Access to selected entity is not inherited from another entity.

  • Access inherited from the X entity (where X represents the parent entity label): The user can access the child entity because they have access to its parent entity.

Export a User Access Table

To export the table, click the button located in the toolbar at the top right of the screen.

An Excel file containing the user access data is automatically downloaded to your computer.
