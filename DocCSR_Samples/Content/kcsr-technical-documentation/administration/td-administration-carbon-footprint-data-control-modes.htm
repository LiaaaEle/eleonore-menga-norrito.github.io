Introduction

This screen allows you to define the default financial and operational controls by entity for an indicator, regardless of the campaign.

Description of the Table Columns

The table contains the following columns:

Column Description

Code

Code used to identify the entity uniquely.

English label

The English label of the entity on which the indicator is deployed.

French label

The French label of the entity on which the indicator is deployed.

Default financial control

Default operational control

Depending on the consolidation type selected in the point of view (POV), you can view the default financial control or the default operational control defined for a given indicator and entity.

Default financial control inherited

Default operational control inherited

NOTE This column changes when you add, edit, or delete a default financial or operational control.

Depending on the consolidation type selected in the POV, you can view the default financial control or the default operational control inherited by an entity from another one or from itself.

Inherited control from

NOTE This column changes when you add, edit, or delete a default financial or operational control.

Depending on the consolidation type selected in the POV, you can view the entity from which the financial or operational control has been inherited:

  • If the entity is a parent entity, the control is inherited from itself

  • If the entity is a child entity and no control has been yet selected for this entity, the control is inherited from its parent entity.

  • If the entity is a child entity and a control has been selected for this entity, the control is inherited from itself.

Add, Edit or Delete the Default Financial and Operational Controls

To add, edit, or delete the default financial and operational control for an indicator:

  1. Select in the POV:

    • The Indicator

    • The Consolidation type: financial control or operational control

  2. Depending on the consolidation type selected in the POV, double-click the Default financial control or Default operational control cell in the line of the entity for which you want to set up the default control.

    A drop-down appears.

  3. Select one of the options displayed in the drop-down.

    NOTE To delete the default control defined, select the blank option.

  4. Save.

NOTE To view the default financial and operational controls defined for an indicator in the Data Collection Campaigns screen:

  1. Enable the selection of the control mode in the Indicator Management screen.
  2. Set up the options for the Financial control and the Operational control drop-down menus displayed in the Data Collection Campaigns screen:
    1. Create an emission factor category in the Management of Emission Factor Categories screen.
    2. Create an emission factor and bind it to the emission factor category, in the Emission Factors List screen.
    3. Bind the emission to the indicator you want to edit the financial and the operational control in the Association of Emission Factors with Activity Indicators screen.
    4. Select the default financial and operation controls defined for the indicator in the Data Collection Campaigns screen.
    5. Click Save.

Import or Export Default Financial and Operational Controls

To export default financial controls:

  1. Select By financial control, as the Consolidation type, from the POV.

  2. Click the button at the top left of the screen.

    The Export pop-up window appears with a download link.

  3. Click the download link to download the Excel file.

 

To export default operational controls:

  1. Select By operational control, as the Consolidation type, from the POV.

  2. Click the button at the top left of the screen.

    The Export pop-up window appears with a download link.

  3. Click the download link for the Excel file.

 

To import default financial or operational controls:

  1. Export the default financial or operational controls, as mentioned above.

  2. Open the exported Excel file.

  3. Fill in the Excel template, then save your data.

    NOTE To help you fill in the Excel template, see the Fill In the Excel template appendix.

  4. Back to the CSR Insight application, click the button at the top left of the screen.

    The Import pop-up window appears.

  5. Choose a file.

  6. Click OK.
