Campaign Settings: Entities to Deploy for an Indicator

SEARCH TIP  Press CTRL + F (Windows and Linux) or CMD + F (Mac) to search within this page.

To access this screen, click: Administration > Campaign management > Campaign settings, then click the button of the desired line. The Campaign Settings: Indicators to Deploy screen is displayed. Click the button at the beginning of the desired indicator line to view the entities attached to this indicator.

Click the button to return to the Home Screen.

Security Notes

Some actions, such as screen access, are permitted only for authorized users, that is, users with the appropriate profile. In other words, if the user does not have the right profile, the user cannot perform the action.

To configure this security (also called user rights), complete the following steps:

  1. Define the profiles in the Profile Management screen.

  2. Define users and attach one or more profiles to them in the User Management screen.

  3. Assign user rights to the desired profiles in the Profile Matrix screen.

Introduction

This screen enables you to deploy the indicator selected in the Campaign Settings: Indicators to Deploy on entities. Check consistency rules before deploying indicators on entities within a campaign to ensure data integrity and prevent deployment conflicts.

You can also mark indicators as Data to be imported by administrator, and verify which entities have collected data.

 

The point of view (POV) is locked for the following items (you cannot modify them on this screen):

  • Hierarchy

  • Year

  • Campaign

  • Chapter

  • Theme

  • Section

  • Indicator

Description of the Table Columns

The table contains the following fields:

Field Description

Code

Unique code used to identify the entity. This code was defined on the Entity Management screen and cannot be modified here.

Label

Entity label.

Entity type

Corresponds to the data collection point defined during indicator configuration. A data collection point contains a set of entities that will collect data for this indicator by default.

When creating a campaign, this indicator is quickly associated to all entities with the same data collection point.

Examples of data collection point: Group, Regional, Country, Site, Business Unit.

Deployment

Boxes are checked for the entities in which the indicator is deployed.

NOTE Checkboxes cannot be cleared once data has been entered for the deployed indicator or entity. This prevents accidental data loss. To undeploy the entity, you must first delete all associated data.

Data to be imported by administrator

Check this box when data will be loaded through imports by administrators rather than manual entry by contributors. This prevents contributors from accidentally modifying imported data while keeping it visible in the workflow to validators. Contributors can view but not edit this data.

The indicator is then in read-only mode on the Data Collection Campaigns screen for this entity.

Data gathered during the campaign

This field displays only two states: grayed-out (no data collected) or YES (data exists). The field cannot be manually edited; it updates automatically based on data entry activity.
