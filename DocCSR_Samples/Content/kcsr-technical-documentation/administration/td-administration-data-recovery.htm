Introduction

STEP BY STEP

Recovering historical data means integrating existing data into the CSR Insight application.

 

To recover historical data by import:

  1. Create campaigns with external data from this screen.

    TIP  Use this screen during the project phase to carry out bulk imports — up to 52 megabytes — at once. No need to go through either the campaign setting screens or the data collection screen.


  2. Add existing indicators to already created campaigns from the Data Import screen.

     

    TIP  Using this screen for historical campaigns is mandatory. These are campaigns that can only contain imported data.

    Click the button to access directly the Data Import screen.

 

This screen allows you to create, by import, campaigns with external data, namely containing indicators deployed on one or more entities for a particular year and period.

 

Consistency rules are the same as for creating campaigns through the Campaign Settings screen and deploying indicators and entities on these campaigns, respectively from the Campaign Settings: Indicators to Deploy and Campaign Settings: Entities to Deploy for an Indicator screens:

  • Only one campaign can be created for each "year - period" data couple.

  • An "indicator - entity" data couple can only be deployed on one campaign for a particular year and periodicity.

  • Indicator deployment can only be done on active entities.

  • An indicator cannot be deployed on a parent entity and its child entities.

  • An indicator associated with a data collection point, called Collect level in the CSR Insight application, can only be deployed to entities belonging to that data collection point.

    NOTE For more information, see Indicator Management: Data Typology Column and Entity Type Management.

 

NOTE

Do not confuse creating campaigns with existing data by import with creating historical campaigns. These are nonhistorical campaigns. The difference between these two types of campaign is as follows:

  • Historical campaigns: campaigns whose proforma data are collected by import through the Data Import screen

  • Non-historical campaigns: campaigns whose data are collected by manual entry through the Data Collection Campaigns screen

You can only create historical campaigns through the Campaign Settings screen.

Create Campaigns with External Data by Import

NOTE On this screen, the creation of campaigns and the import of indicators within these campaigns is done at the same time.

Therefore, this documentation provides a single procedure for both of these simultaneous actions.

To create campaigns by import, you must follow several steps:

  1. Export and fill in the template file.

  2. Import this file.

    Campaigns are temporarily created. You cannot view them on the Campaign Settings screen or the Data Collection Campaigns screen until you have started them.

  3. Check imported data. Make as many changes as desired.

  4. Start campaigns when ready.

    Campaigns are actually created. You can view them on the Campaign Settings screen and on the Data Collection Campaigns screen.

Export and Fill In the Template File

To export the template file:

  1. Click the export button at the top left of the screen.

    The Export format data pop-up window appears with a download link.

  2. Click the download link for the Excel file.

 

To help you fill in the Excel template, see the Fill In the Excel Template appendix. After filling in the template file, save your data.

Import the Template File

NOTE If your imported file contains errors or warnings, you can rectify them and make a new import. Refer to the information on import status.

To import the template file you filled in:

  1. Click the import button at the top left of the screen.

    The Historical recovery pop-up window appears.

  2. Select the Indicator search mode to determine how the system matches indicators in your Excel file to indicators in the CSR Insight application:

    • Label if your Excel file uses indicator names

    • Reference if your Excel file uses indicator codes

  3. Choose a file.

    WARNING Import only the file you exported and filled in. Otherwise, the import will fail.

  4. Click OK.

    Campaigns are temporarily created. You cannot view them on the Campaign Settings screen or the Data Collection Campaigns screen until you have started them.

Check Imported Data

TIP  For big data verification, export the content of each campaign, one by one.

If you are missing indicators or your campaign does not contain the correct indicators, do a new import through this screen to create a new campaign.

Otherwise, make your settings changes for this campaign, then start it.

 

To make the creation of campaigns effective, you must first check the imported data and make the desired changes. Click the button in the Status column of the line associated to your import.

 

A new window appears at the bottom of the screen. You can view a table containing information on your temporarily created campaigns:

Column Description

Name

Campaign label. By default, displayed in your user language.

You can edit the campaign label in all languages available in the CSR Insight application.

Period

Period during which data is collected for this campaign.

 

When data are collected once a year, that is yearly, the period used is Full year.

 

When data are collected every six months, that is half-yearly, the periods used are:

  • HY1 (Half Year 1): First half of the year (first semester)

  • HY2 (Half Year 2): Second half of the year (second semester)

 

When data are collected four times a year, that is quarterly, the periods used are:

  • Q1: First quarter

  • Q2: Second quarter

  • Q3: Third quarter

  • Q4: Fourth quarter

 

When data are collected monthly, the periods used are the twelve calendar months (January through December).

Campaign type

Periodicity of data collection for this campaign:

  • Yearly: Data is collected once a year.

  • Semiannually: Data is collected twice a year (once in the first semester, once in the second semester).

  • Quarterly: Data is collected four times a year (once in the first quarter, once in the second quarter, once in the third quarter, once in the fourth quarter).

  • Monthly: Data is collected twelve times a year, that is once a month.

Deadline - Data entry

Campaign data entry deadline.

Triggers an alert on the Data Collection Campaigns screen when exceeded.

Deadline - Validation

Campaign data validation deadline.

Triggers an alert on the Data Collection Campaigns screen when exceeded.

Deadline - Closing

Campaign closing deadline.

Triggers an alert on the Data Collection Campaigns screen when exceeded.

 

To check the content of your campaigns, that is the indicators they contain:

  1. Click the button at the beginning of the line of the concerned campaign.

    The History recovery pop-up window appears with a download link.

  2. Click the download link for the Excel file.

  3. Open the exported file.

 

To change the campaign label in all languages available in the CSR Insight application, as well as selecting a Default display mode and N-1 source:

  1. Click the button at the beginning of the line of the campaign you want to edit information.

    The Update campaign pop-up panel appears.

  2. Make your changes.

  3. Click OK.

NOTE Since no proforma or forecast version has been created yet in the application, your created campaign cannot have either as a N-1 source.

However, you can use your campaign as a reference version, that is, containing the carbon footprint data you want to publish. If yes, select Published as the N-1 source. If not, leave empty.

 

To change the deadlines for data entry, data validation, and campaign closure:

  1. Double-click the cells from the Deadline - data entry, Deadline - validation, and Deadline - Closing columns for the line of the concerned campaign.

  2. Select a date from the calendar widget.

  3. Click OK.

Start Campaigns

When your campaign is ready to use, you can start it. Starting a campaign means you can no longer change the campaign settings. You can however still deploy or undeploy indicators and entities, respectively from the Campaign Indicators and Indicator Entities screens.

 

To start a campaign, click the button at the beginning of the line of the campaign you want to start.

Description of the Table Columns

The table contains the following columns:

Column Description

Author

User who initiated the import.

Date

Import date.

Status

Import status:

  • Import in progress: File is being processed. Refresh the page to check for completion. You may use other screens while waiting.

  • Import with success: All data is successfully imported. Campaigns are temporarily created. You cannot view them on the Campaign Settings screen or the Data Collection Campaigns screen until you have started them.

  • Import in error: File contains errors, that is, required fields were not completed or were not completed correctly. Valid data was imported; only erroneous rows were rejected. Export the Error file to identify and correct errors, then import it.

  • Import with warnings: Your imported file contains warnings when one or multiple campaigns have already been created for a " year - period - organization - indicator" data couple. Nothing happens for information associated to warnings: no campaign creation or replacement. Valid information without associated errors or warnings is successfully imported.

  • Import finalized: All campaigns temporarily created by import were started. Consequently, these campaigns are now actually created. You can view them on the Campaign Settings screen, as well as on the Data Collection Campaigns screen.

 

Error file

When your imported file contains errors, an Error file is automatically created. Click the button to export this file.

NOTE This file contains for each row the reason for the import failure in the last column.

Comment

Comment associated to the imported file.

File name

Imported file name.

Imported file

Click the button to export the Imported file.
