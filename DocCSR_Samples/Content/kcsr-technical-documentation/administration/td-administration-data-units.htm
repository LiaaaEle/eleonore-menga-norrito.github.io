Security Notes

Some actions, such as screen access, are permitted only for authorized users, that is, users with the appropriate profile. In other words, if the user does not have the right profile, the user cannot perform the action.

To configure this security (also called user rights), complete the following steps:

  1. Define the profiles in the Profile Management screen.

  2. Define users and attach one or more profiles to them in the User Management screen.

  3. Assign user rights to the desired profiles in the Profile Matrix screen.

Introduction

This screen allows you to manage units used in CSR Insight.

The unit categories are in the Category drop-down menu in the point of view (POV).

NOTE In the CSR Insight application, you can use three types of units:
  • The default unit
  • The input unit: the unit of the data entered for the indicator
  • The preference unit: the unit your entered data will be converted to

In this screen, you can define the default unit for each unit category.

Units with a conversion factor can be selected, on the Data Collection Campaigns screen, as an input or preference unit.

Add a Unit

To add a unit:

  1. Click the button at the top left of the table.

    The Add a unit pop-up panel appears.

  2. Enter a unit in all available languages.

  3. Click OK.

Update a Unit

To update a unit:

  1. Click the button at the beginning of the concerned line.

    The Edit a unit pop-up panel appears.

  2. Enter the new desired unit in all available languages.

  3. Click OK.

Delete a Unit

To delete a unit:

  1. Click the button at the beginning of the concerned line.

    The Delete this unit pop-up window appears to confirm the deletion.

  2. Click OK.

Import or Export a Unit

To export units:

  1. Click the button at the top left of the screen.

    The Export units pop-up window appears with a download link.

  2. Click the download link for the Excel file.

To import units:

  1. Export the units, as mentioned above.

  2. Open the exported Excel file.

  3. Fill in the Excel template, then save your data.

  4. Back to the CSR Insight application, click the button at the top left of the screen.

    The Import units pop-up window appears.

  5. Choose a file.

  6. Click OK.

Do a Specific Action

You can do specific actions with the following items:

Item Description

Unit

Unit label. By default, displayed in your user language.

To view the unit label in all languages available in the CSR Insight, click the cell.

A pop-up window appears.

Default unit

Check the box to define the unit as the default unit.

Conversion factor

To enter conversion factors:

  1. Click the box of the unit you want.

  2. Enter a value.

  3. Save the data.

If the value entered does not correspond to an interval or to precise options, the input box becomes red. You can no longer save your input.

WARNING The default unit's conversion factor must be equal to 1.
