Security Notes

Some actions, such as screen access, are permitted only for authorized users, that is, users with the appropriate profile. In other words, if the user does not have the right profile, the user cannot perform the action.

To configure this security (also called user rights), complete the following steps:

  1. Define the profiles in the Profile Management screen.

  2. Define users and attach one or more profiles to them in the User Management screen.

  3. Assign user rights to the desired profiles in the Profile Matrix screen.

Introduction

Emission reporting formats, also called versions in the CSR Insight application, are the regulations on which the carbon footprint must be based:

  • BEGES V4, or

  • BEGES V5, or

  • GHG protocol

NOTE For more information on emission reporting formats, see the Emission Restitution Formats section in the Carbon Footprint documentation.

This screen allows you to set up emission reporting formats. More precisely, you can associate an emission category and sub-category, that is, an emission, with an emission post depending on:

  • The Year

  • The Entity

  • The EF category: the emission factor category

  • The Control type: financial control or operational control

  • The Version: the emission restitution format

Description of the Table Columns

The table contains the following columns:

Column Description

Emission sub-category

The emission sub-category name.

NOTE To manage emission sub-categories, see the Management of Emission Categories documentation.

Control

Depending on the control type selected in the point of view (POV), the financial or operational control associated with the emission.

Scope

The emission post scope.

Emission post

The emission post bound to the emission.

Bind an Emission to an Emission Post

NOTE You can bind an "Emission – Control mode" couple to multiple emission posts. If you do so:

  • The same emission will be recorded multiple times in the carbon footprint report and in the table of the Carbon Footprint Audit screen.
  • When importing, the following alert message appears in the Excel file: "Emission/control mode couple is already used in another emission post".

 

To bind an emission to an emission post:

  1. Click the button at the top left of the table.

    The Bind an emission to a post pop-up panel appears.

  2. Select from the drop-down menus:

    • The Emission category

    • The Emission sub-category

    • The Control: the financial control or operational control you want to associate with the emission

    • The Post: the emission post that you want to link to the emission sub-category

  3. Click OK.

    A new line appears in the table with the newly-made association.

Unbind an Emission Sub-Category from an Emission Post

To unbind the emission factor from the activity indicator:

  1. Click the button at the beginning of the line for the association you want to break.

    The Unlink an emission to a post pop-up window appears to confirm your action.

  2. Click OK.

    The emission sub-category and the emission post are unbound.

Copy the Settings from One Year to Another

To copy the settings from one year to another:

  1. Select the Year from which you want to copy the settings in the POV. For example, 2022.

  2. Select the other POV items as well.

  3. Click the button at the top left of the table.

    The Copy parameters pop-up panel appears with the Source year and the Current organization fields automatically filled in.

  4. Select the Target year from the drop-down menu. For example, 2023.

  5. Click OK.

  6. Select the Year, to which you copied the settings, from the POV. In our example, 2023.

    The copied settings appears in the table.

Import or Export the Associations between the Emissions and the Emission Posts

To export the associations between the emissions and the emission posts:

  1. Click the button at the top left of the screen.

    The Export pop-up window appears with a download link.

  2. Click the download link for the Excel file.

 

To import the associations between the emissions and the emission posts:

  1. Export the associations between the emissions and the emission posts as mentioned above.

  2. Open the exported Excel file.

  3. Fill in the Excel template, then save your data.

    NOTE To help you fill in the Excel template, see the Fill In the Excel template appendix.

  4. Back to the CSR Insight application, click the button at the top left of the screen.

    The Import pop-up window appears.

  5. Choose a file.

  6. Click OK.
