Introduction

Security Notes

Some actions, such as screen access, are permitted only for authorized users, that is, users with the appropriate profile. In other words, if the user does not have the right profile, the user cannot perform the action.

To configure this security (also called user rights), complete the following steps:

  1. Define the profiles in the Profile Management screen.

  2. Define users and attach one or more profiles to them in the User Management screen.

  3. Assign user rights to the desired profiles in the Profile Matrix screen.

The Indicator identification column contains identification items for each indicator:

Item Description

Reference

Code used to identify the indicator uniquely. No duplicates are allowed.

This code contains letters and/or numbers. No spaces, periods, or arithmetic operands are allowed.

Underscore is allowed.

Label

Indicator label. No duplicates are allowed. By default, displayed in your user language.

You can edit the indicator label in all languages available in the CSR Insight application.

Short label

Shortened version of the indicator label. No duplicates are allowed. 30 characters maximum. By default, displayed in your user language.

You can edit the shortened indicator label in all languages available in the CSR Insight application.

Business owner

User who is responsible for an indicator.

By default, this user is the recipient of questions related to this indicator in the Chat Room.

Expected trend

Trend given to the values of an indicator:

  • Maximize: indicator values increase over time

  • Minimize: indicator values decrease over time

NOTE To delete the expected trend of an indicator, select the Empty option.

 

From the Indicator Identification column, you can Edit Identification Items for an Indicator.

 

The Indicator identification block in the Identity card has the same content as the Indicator identification column. To access the Identity card, see Edit an Indicator.

Edit Identification Items for an Indicator

There a two ways to edit identification items for an indicator:

  • From the Identity Card

  • From the Indicator Identification Column

From the Identity Card

To edit identification items from the Identity card:

  1. Make the Identity card appears for the desired indicator as indicated in the Edit an Indicator section.

  2. Go to the Indicator identification block.

  3. Edit the information as desired.

  4. Click Save at the top right of the Identity card.

From the Indicator Identification column

To edit identification items from the Indicator identification column:

  1. Position your cursor at the line of the indicator for which you want to edit the identification items.

  2. Double-click the cell in the sub-column of the identification item you want to edit in the Indicator identification column.

  3. Edit the information contained in the cell.

  4. Click the button at the top left of the nested grid.

  5. Repeat the same steps for each identification item you want to edit for the indicator.
