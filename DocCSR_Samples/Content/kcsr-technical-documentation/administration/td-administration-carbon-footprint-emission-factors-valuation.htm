Introduction

This screen allows you to set up the emission factor value for each gas (CO2, CH4, N2O, HFCs, PFCs, SF6, CO2 b, CO2 avoided, Others) and uncertainty value. You can also view the total value for all the gases.

NOTE Only a supervisor administrator (also called an administrator with GS rights, that is a user with all user rights) can view, import and export the values of an emission factor with the AIE (Agence Internationale de l’Energie) or IEA (International Energy Agency) documentary source.

Description of the Table Columns

The table contains the following columns:

Column Description

EF category

The name of the emission factor (EF) category.

NOTE To manage emission factor categories, see the Management of Emission Factor Categories documentation.

EF sub-category

The name of the emission factor (EF) sub-category.

NOTE To manage emission factor sub-categories, see the Management of Emission Factor Categories documentation.

EF code

Code used to identify the emission factor (EF) uniquely.

This code is especially used in the calculation formulas of the carbon footprint.

This code contains letters and/or numbers.

Emission factor

The emission factor name.

EF unit

The emission factor (EF) unit composed of two units set up on the Emission Factor List screen:

  • Numerator unit

  • Denominator unit

EF source

The emission factor (EF) source, that is the name of the regulatory organization from which the emission factor comes.

NOTE To manage EF sources, see the Documentary Sources of Emission Factors documentation.

Emission category

The name of the emission category.

NOTE To manage emission categories, see the Management of Emission Categories documentation.

Emission sub-category

The name of the emission sub-category.

NOTE To manage emission sub-categories, see the Management of Emission Categories documentation.

CO2

The emission value for the CO2 gas.

CH4

The emission value for the CH4 gas.

N2O

The emission value for the N2O gas.

HFCs

The emission value for the HFC gases.

PFCs

The emission value for the PFC gases.

SF6

The emission value for the SF6 gas.

Others

The emission value for the other gases.

Not decomposed total

The total sum of all the emission values for the following gases:

  • CO2

  • CH4

  • N20

  • HFCs

  • PFCs

  • SF6

Base

NOTE For BEGES V4 and BEGES V5, the required calculation method is Location based.

For GHG protocol, you can choose between the Location based and Market based calculation methods, or use both.

To select a calculation method, go to the Emission Factor List screen.

Calculation method of scope 2 emissions associated with the emission factor:

  • Location based, or

  • Market based

By default, if the cell is empty, the calculation method will be Location based.

For more information on scopes and scope 2 calculation methods, see the following sections in the Carbon Footprint documentation:

  • Emission Reporting Formats

  • Location Based and Market Based

CO2 b

The emission value for the class B CO2 gas.

CO2 avoided

The value for the CO2 avoided.

Uncertainty (%)

The uncertainty percentage of the emission factor.

Comment

Comment on emission factor values. Optional.

Add or Edit Emission Factor Values

To add or edit emission factor values, follow these two steps:

  1. Add an Emission Factor Line in the table

  2. Add or Edit Values for an Emission Factor

Add an Emission Factor Line

To add an emission factor line in the table:

  1. Select the Year, the Entity and the Category of the emission factor from the point of view (POV).

    NOTE By default, you can view all the emission factor categories.

  2. Click the button at the top left of the table.

    The Add an emission factor pop-up panel appears.

  3. Select from the drop-down menus:

    • The EF category

    • The EF sub-category

    • The Emission category

    • The Emission sub-category

  4. Optional: Enter a comment in the Comment input zone.

  5. Click OK.

    A new emission factor line appears in the table.

Add or Edit Values for an Emission Factor

You can add or edit values:

  • For an Emission Factor Not Used in a Calculation

  • For an Emission Factor Used in a Calculation

For an Emission Factor Not Used in a Calculation

To add or edit values for an emission factor not used in a calculation:

  1. Double-click one of the following cell:

    • CO2

    • CH4

    • N2O

    • HFCs

    • PFCs

    • SF6

    • CO2 b

    • CO2 avoided

    • Others

    • Uncertainty (%)

  2. Enter the desired value. Positive value only.

  3. Click the Enter key.

  4. Save.

  5. Optional: Recalculate the emission final value as indicated in the Recalculate the Emission Final Value section below.

For an Emission Factor Used in a Calculation

NOTE There is a button at the beginning of the lines of the emission factors used in a calculation.

To add or edit values for an emission factor used in a calculation:

  1. Click the button at the beginning of the concerned line.

    A pop-up windows appears to confirm.

  2. Click OK.

    The button becomes the icon. You can now edit the values in the line.

  3. Follow the procedure written in the For an Emission Factor Not Used in a Calculation section above.

  4. Recalculate the emission final value as indicated in the Recalculate the Emission Final Value section below.

WARNING Once adding and editing values is enabled, you can no longer disable it.

Delete an Emission Factor Line

You can delete emission factor lines when no values are entered.

To delete an emission factor line:

  1. Click the button at the beginning of the desired line.

    The Delete an emission factor pop-up window appears to confirm the deletion.

  2. Click OK.

    The emission factor line is deleted.

Recalculate the Emission Final Value

To recalculate the emission final value, click the button at the top left of the table.

The emissions calculation formula retrieves all the changes in emission factor values. The emission final value is changed.

Copy the Settings from One Year to Another

To copy the settings from one year to another:

  1. Select the Year, from which you want to copy the settings, from the POV. For example, 2022.

  2. Select the Entity and the Category from the POV as well.

  3. Click the button at the top left of the table.

    The Copy the settings to a target year pop-up panel appears with the Source year and the Current entity fields automatically filled in.

  4. Select the Target year from the drop-down menu. For example, 2023.

  5. Click OK.

  6. Select the Year, to which you copied the settings, from the POV. In our example, 2023.

    The copied settings appear in the table.

Import or Export Emission Factor Values

WARNING Importing new emission factor values will overwrite the current values for the selected entity and its child entities.

To export emission factor values:

  1. Click the button at the top left of the screen.

    The Export emission factor values pop-up window appears with a download link.

  2. Click the download link for the Excel file.

 

To import emission factor values:

  1. Export the emission factor values as mentioned above.

  2. Open the exported Excel file.

  3. Fill in the Excel template, then save your data.

    NOTE To help you fill in the Excel template, see the Fill In the Excel Template appendix.

  4. Back to the CSR Insight application, click the button at the top left of the screen.

    The Import pop-up windows appears.

  5. Choose a file.

  6. Click OK.
