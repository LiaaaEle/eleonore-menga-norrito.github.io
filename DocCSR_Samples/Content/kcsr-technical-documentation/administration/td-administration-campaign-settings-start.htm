Security Notes

Some actions, such as screen access, are permitted only for authorized users, that is, users with the appropriate profile. In other words, if the user does not have the right profile, the user cannot perform the action.

To configure this security (also called user rights), complete the following steps:

  1. Define the profiles in the Profile Management screen.

  2. Define users and attach one or more profiles to them in the User Management screen.

  3. Assign user rights to the desired profiles in the Profile Matrix screen.

Introduction

There are two approaches for launching your campaign:

  • Quick start: Launch immediately with automatic notification emails through the Campaign Settings screen.

  • Custom start: Review and customize the notification email before launching through this screen.

 

The notification email sent to participants is called the "campaign launch email".

 

The Send the Email screen provides the custom start approach. Use this screen when you need to review the email content, add attachments, or modify the message before launching the campaign. An export feature is also available.

 

For information about dynamic content variables, see Email Variables.

Edit the Email Template

You can edit the email template's title and content in all available languages in the CSR Insight application.

Procedure

To edit the email template:

  1. Double-click the cell you want to edit.

  2. Enter new content.

  3. Press the Enter key.

  4. Click Save to preserve your changes.

WARNING If you refresh the screen before saving, your changes are lost.

Email Variables

When composing your email template, you can insert the following variables:

  • User information:

    • {NAME}: Recipient's full name (first and last name)

    • {FIRSTNAME}: Recipient's first name

    • {SENDER_NAME}: Sender's full name (first and last name)

  • Campaign information:

    • {CAMPAIGN_YEAR}: Campaign year

    • {CAMPAIGN_PERIOD}: Campaign period

    • {CAMPAIGN_LABEL}: Campaign name

    • {CAMPAIGN_LIST}: List of campaigns that are included in the functional scope of the email recipient

  • Deadline information:

    • {INPUT_DATE}: Data entry deadline

    • {VALIDATION_DATE}: Data validation deadline

    • {CLOSING_DATE}: Data closure deadline

  • Organizational information:

    • {ORGANIZATION_LABEL}: Name of the current entity in the email context

    • {ORGANIZATION_LIST}: List of entities that are included in the functional scope of the email recipient

  • Indicator information:

    • {INDICATOR_LABEL}: Name of the indicator in the email context

    • {VALUE}: Value of the indicator in the email context

  • Import information:

    • {STATUS_IMPORT_DATA}: Status after data import on a campaign (success, error, alert, or done)

  • Chat room information:

    • {TOPIC_MESSAGE}: Question topic of the message chosen in the Chat Room (indicator, value, campaign, or free)

  • System information:

    • {CONTACT_ADRESS}: Support contact email address for recipient inquiries (Default: corp.sustainability_performance_team@kshuttle.com)

    • {REPORTING_SCREEN}: Link to the Data Collection Campaigns screen

    • {BREADCRUMB_REPORTING}: Breadcrumbs to the Data Collection Campaigns screen

    • {BREADCRUMB_ADJUSTMENT}: Breadcrumbs to the Details of Adjustment Requests screen

  • Action-specific information:

    • {ACTION_TODO}: Action carried out by the email sender or to be carried out by the email recipient (for example: relaunch, create an adjustment, and so on)

    • {ELEMENT_TO_CHECK}: Item the email recipient must check

 

These variables are available system-wide for all email types, though not all are applicable to campaign launch emails.

NOTE Some variables (such as {TOPIC_MESSAGE} for chat room or {STATUS_IMPORT_DATA} for imports) are populated only in specific contexts and will appear empty if used in campaign launch emails.

 

Variables are automatically replaced with actual values when the email is sent to recipients.

 

Type each variable exactly as shown, including the curly braces { }. You can combine multiple variables in your template. Example: "Hello {FIRSTNAME}, the {CAMPAIGN_LABEL} for {CAMPAIGN_YEAR} is now open. Please complete by {INPUT_DATE}."

NOTE Best Practice: For campaign launch emails, commonly used variables include:

  • {FIRSTNAME} or {NAME} for personalization

  • {CAMPAIGN_LABEL} and {CAMPAIGN_YEAR} for clarity

  • {INPUT_DATE} to emphasize deadlines

  • {REPORTING_SCREEN} to provide direct access to the Data Collection Campaigns screen.

For issues with variables, see Troubleshooting.

WARNING Remember to save your changes after inserting or modifying variables in the template. For issues with variables, see Troubleshooting.

Add and Download Attachments

You can add attachments in all available languages and download existing attachments.

Prerequisite

Before adding attachments, ensure the attachment feature is enabled in the Email Sending Settings screen.

In the Email Sending Settings table, locate the "Launch a campaign" row and select the checkbox in the Attachment column.

When enabled, the Attachments column in the Send the email screen becomes editable. When disabled, the column appears but cells cannot be modified.

Add Attachments to the Email

To add an attachment from the Attachments column:

  1. Right-click an empty cell.

    A drop-down menu appears.

  2. Click Select a file.

    The Open file dialog box appears.

  3. Choose a file.

  4. Click Open.

    Your file appears in the cell.

  5. Verify the filename is displayed correctly.

  6. Click Save.

Download Existing Attachments

To download attachments from the Attachments column:

  1. Right-click a cell that contains an attachment.

    A drop-down menu appears.

  2. Click Download.

    The attachment is automatically downloaded to your browser's default download folder.

Send the Email and Start the Campaign

WARNING Changes to the email template are temporary. Send the email immediately after saving, or your changes will revert to the template version when you exit the screen.

To send the email and start the campaign simultaneously:

  1. Click the button at the top left of the screen.

    The Start a campaign pop-up panel appears.

  2. Select one or multiple recipients from the drop-down menus:

    • First, Groups: Profiles of the users to which you want to send the email

    • Then, Users: Email recipients

      NOTE The Users list displays only members of the profiles selected in Groups. Select one or more profiles first to filter available recipients.

  3. Click OK.

    The campaign status changes to Started in the Campaign Settings screen and a confirmation message appears. The email is sent immediately to all selected recipients.

Export the Email Template

Export the email template to create a backup, share with stakeholders for review, or maintain records of campaign communications.

You can export the template at any time before or after sending the email. Export before sending to review the complete template with all configured languages, or export after sending to archive the version that was distributed.

 

To export the email, click the button in the toolbar at the top right of the screen.

An Excel file containing the email template content is automatically downloaded to your browser's default download folder. The exported file includes all configured language versions and shows variables in their template format (for example, {FIRSTNAME}), not their replaced values.

Troubleshooting

Error Solution

Variable not replaced in email

Ensure variable name is spelled exactly as shown, including curly braces.

Attachment upload fails

Verify file size is within limits and file type is supported.

Contact your administrator for file size and type restrictions.

Recipients list empty

Ensure at least one profile is selected to populate available users.
