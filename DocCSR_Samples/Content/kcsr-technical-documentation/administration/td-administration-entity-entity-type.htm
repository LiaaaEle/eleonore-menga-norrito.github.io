Security Notes

Some actions, such as screen access, are permitted only for authorized users, that is, users with the appropriate profile. In other words, if the user does not have the right profile, the user cannot perform the action.

To configure this security (also called user rights), complete the following steps:

  1. Define the profiles in the Profile Management screen.

  2. Define users and attach one or more profiles to them in the User Management screen.

  3. Assign user rights to the desired profiles in the Profile Matrix screen.

View and Manage an Entity Type

Each indicator is attached to an entity type, also called data collection point. This entity type contains a set of entities, also known as organizations, on which data will be collected by default for the indicator. When creating a data collection campaign, this indicator can be quickly associated to all entities with the same data collection point.

You can manage an entity type by using the following actions:

  • Create an Entity Type

  • Update an Entity Type

  • Delete an Entity Type

  • Activate Entity Type for Data Collection in Campaigns

  • View Linked Organizations

  • View Indicators Associated with an Entity Type

  • Add or Edit Comments

  • Export or Import Entity Types

Create an Entity Type

To create an entity type, you can use either of the following:

  • Through the Entity Management screen

  • Through this screen

 

To create an entity type through this screen:

  1. Click the button at the top left of the sceen.

    The Create entity type pop-up panel appears.

  2. Enter the entity type Label for each language available in the CSR Insight application.

  3. Click OK.

    You can view a new row with the new entity type Label you entered in the previous step.

Update an Entity Type

To update an entity type:

  1. Click the button at the beginning of the concerned line.

    The Update an entity type pop-up window appears.

  2. Enter the entity type Label for each language available in the CSR Insight application.

  3. Click OK.

Delete an Entity Type

To delete an entity type:

  1. Click the button at the beginning of the concerned line.

    The Delete entity type pop-up window appears to confirm the deletion.

  2. Click OK.

NOTE An entity type cannot be deleted when it contains entities that have collected data for campaigns.

Activate Entity Type for Data collection in Campaigns

Check the box available in the Collect activation column if you want to activate an entity type for data collection in campaigns.

Uncheck the box available in the Collect activation column if you want to disable an entity type for data collection in campaigns.

NOTE An entity type cannot be disabled when it contains entities that have collected data for campaigns.

A disabled entity type can no longer be used when setting up a campaign. For more information on campaign settings, see Campaign Settings, Campaign Settings: Indicators to Deploy, and Campaign Settings: Entities to Deploy for an Indicator.

If you search for an entity type and do not find it when setting up a campaign, check if this entity type was deleted or disabled. If disabled, activate the entity type in this screen as explained above.

View Linked Organizations

To view the organizations that are linked to an entity type:

  1. Click the corresponding number in the Linked organization column.

    A second window appears that lists all the linked organization with their Code and Label.

  2. Click the button to close the second window.

View Indicators Associated with an Entity Type

To view indicators associated with an entity type:

  1. Click the corresponding number in the indicators associated column.

    A second window appears that lists all associated indicators with their Indicator reference and Label.

  2. Click the button to close the second window.

Add or Edit Comments

The Comment column allows you to add or edit comments for entity types.

 

To add or edit a comment for an entity type:

  1. Click the Comment cell for the desired entity type.

    A Write a comment pop-up window appears.

  2. Enter or edit your comment.

  3. Click OK.

Export or Import Entity Types

To export entity types:

  1. Click the button at the top left of the screen.

    The Export entity type pop-up window appears.

  2. Click the download link for the Excel file.

    An Excel file is downloaded to your local computer.

 

To import entity types:

  1. Export the entity types as mentioned above.

  2. Open the exported Excel file.

  3. Fill in the Excel template, then save your data.

    NOTE To help you fill in the Excel template, see the Fill In the Excel template appendix.

  4. Back to the CSR Insight application, click the button at the top left of the screen.

    The Import entity type pop-up window appears.

  5. Choose a file.

  6. Click OK.

Description of the Table Columns

The screen contains the following identification columns for each entity type:

Item Description

Label

Entity type label. No duplicates are allowed. By default, displayed in the user language.

Collect activation

Activate or deactivate the entity type for data collection in campaigns.

Linked organizations

Entities linked to the entity type.

Indicators associated

Indicators associated with an entity type.

Comment

Comment on entity type.
