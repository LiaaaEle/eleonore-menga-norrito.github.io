Profile Management

SEARCH TIP  Press CTRL + F (Windows and Linux) or CMD + F (Mac) to search within this page.

To access this screen, click: Administration > User right management > Profile management.

Click the button to return to the Home Screen.

Security Notes

Some actions, for example screen access, are allowed to authorized users, that is users with the right profile. In other words, if the user does not have the right profile, the user cannot perform the action.

To set up this security (also called user rights):

  1. Define the profiles on the Profile Management screen (this documentation).

  2. Define users, and attach one or several profiles to them, on the User Management screen.

  3. Assign user rights to the desired profiles on the Profile Matrix screen.

You can view the actions of this screen that are attached to user rights, in the table below:

Introduction

STEP BY STEP

Defining profiles on this screen is the first step in setting up user rights in the CSR Insight application. Next steps are:

  • Defining users and attach profiles to them on the User Management screen

  • Assigning user rights to profiles on the Profile Matrix screen

This screen allows you to manage profiles. First create a profile, then define or not a restricted access to entities and/or functional scopes. You can also define to which alternative hierarchies the profile has access to.

 

Depending on the restricted accesses applied, selectable items in the point of view (POV) on Data Entry and Reporting screens, such as campaign, entity, hierarchy, or indicator, are different.

Description of the Table Columns

The table contains the following colums:

Column Description

Name

Profile label. By default, displayed in your user language.

You can update the profile label in all languages available in the CSR Insight application.

Description

Profile description. By default, displayed in your user language.

You can edit the profile description in all languages available in the CSR Insight application.

Restricted access

NOTE Restricted accesses are only applied on Data Entry and Reporting screens. No restricted access for Administration screens.

This column contains two sub-columns:

  • Entities

  • Scopes

From this column, you can restrict access to entities or functional scopes. See Define Restricted Accesses for a Profile.

Alternative visions

NOTE Restricted accesses are only applied on Reporting screens. No restricted access for Data Entry and Administration screens.

Alternative hierarchies to which your profile has access to. See Define Restricted Accesses for a Profile.

Create a Profile

To create a new profile:

  1. Click the button at the top left of the table.

    The Add a profile pop-up panel appears.

  2. Enter the label in all available languages.

  3. Optional: Enter the description in all available languages.

  4. Click OK.

Update a Profile

To edit a profile:

  1. Click the button at the beginning of the concerned line.

    The Update pop-up panel appears.

  2. Enter the new information.

  3. Click OK.

Delete a Profile

To delete a profile:

  1. Click the button at the beginning of the concerned line.

    The Delete this profile pop-up window appears to confirm the deletion.

  2. Click OK.

Define Restricted Accesses for a Profile

NOTE You cannot edit restricted accesses to entities and functional scopes for profiles assigned to at least one user. However, if you defined a restricted access to entities, you can still select alternative hierarchies the profiles will have access to.

A grayed-out cell indicates that no changes are possible.

Authorized users can defined restricted accesses for a profile. See Security Notes.

 

To define restricted accesses to entities and/or functional scopes, you can check and uncheck the boxes either of the sub-columns of the Restricted access column, namely Entities or Scopes, for each profile.

 

If you defined a restricted access to entities, you can also define to which alternative hierarchies the profile has access to. To do so:

  1. Double click a cell with a icon in the Alternative visions column.

    The Select one or more alternative visions column pop-up panel appears.

  2. Select one or more alternative hierarchies from the drop-down menu.

  3. Click OK.
