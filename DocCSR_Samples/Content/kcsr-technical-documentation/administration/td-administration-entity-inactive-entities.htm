Inactive Entity Management

SEARCH TIP  Press CTRL + F (Windows and Linux) or CMD + F (Mac) to search within this page.

To access this screen, click Administration > Entity management > Entity management, then hover over the button located at the top right end of the nested grid. Select the Inactive entities management option from the drop-down menu.

Security Notes

Some actions, such as screen access, are permitted only for authorized users, that is, users with the appropriate profile. In other words, if the user does not have the right profile, the user cannot perform the action.

To configure this security (also called user rights), complete the following steps:

  1. Define the profiles in the Profile Management screen.

  2. Define users and attach one or more profiles to them in the User Management screen.

  3. Assign user rights to the desired profiles in the Profile Matrix screen.

View and Manage Inactive Entities

Inactive entities are entities that are not used anywhere in the CSR Insight application. On this screen, you can view and manage inactive entities by using the following actions:

  • Change Parent to Reactivate an Entity

  • Edit an Inactive Entity

  • Export Inactive Entities

Change Parent to Reactivate an Entity

Changing the parent when the entity is inactive will reactivate the entity.

To do so:

  1. Click the button.

    The Move organization pop-up window appears.

  2. Select the new parent from the drop-down menu.

  3. Click OK.

    The entity is now reactivated and positioned under its new parent. The entity therefore no longer appears in the list of inactive entities.

Edit an Inactive Entity

To edit an inactive entity:

  1. Click the button.

    The Edit an organization pop-up window appears.

  2. Enter the desired Code.

  3. Enter the desired Label for all languages available in the CSR Insight application.

  4. Select an Entity type from the drop-down menu.

  5. Click OK.

Export Inactive Entities

To export inactive entities, click the button in the toolbar at the top right of the screen.

An Excel file is automatically downloaded to your computer.

Description of the Table Columns

The screen contains the following identification columns for each inactive entity:

Item Description

Code

Code used to identify the inactive entity uniquely. No duplicates are allowed.

This code contains letters and/or numbers. No spaces nor special characters are allowed.

Underscore and hyphen are allowed.

Label

Inactive entity label. No duplicates are allowed. By default, displayed in your user language.

Entity type

Data collection point. Refer to Entity Type Management for more details.

NOTE To manage entity types, see the Entity Type Management documentation.

You can also read the Entity Management: Three Dots Button to learn how to create an entity type.

Currency

Currency used within an inactive entity.
