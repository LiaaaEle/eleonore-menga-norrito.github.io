Currency Management

SEARCH TIP  Press CTRL + F (Windows and Linux) or CMD + F (Mac) to search within this page.

To access this screen, click: Administration > Data management > Currency management.

Click the button to return to the Home Screen.

Security Notes

Some actions, such as screen access, are permitted only for authorized users, that is, users with the appropriate profile. In other words, if the user does not have the right profile, the user cannot perform the action.

To configure this security (also called user rights), complete the following steps:

  1. Define the profiles in the Profile Management screen.

  2. Define users and attach one or more profiles to them in the User Management screen.

  3. Assign user rights to the desired profiles in the Profile Matrix screen.

The table below contains screen actions that are related to user rights:

Module Screen Action

Data Management

Currency management

Screen access

This screen allows you to:

  • Add, update, and delete currencies

  • Indicate the amount for the exchange rate depending on the rate type and the period (month, year)

NOTE You cannot edit or delete the currencies delivered by default in CSR Insight.

Point of View Items

The following items are available in the point of view (POV):

  • Rate type:

    • Average rate: Rate entered by the administrator, for example for the flow-type indicators.

    • Closing rate: Rate entered by the administrator to calculate an indicator, for example in the case of an investment or a stock.

  • Year: Year relative to the currency displayed on the screen.

Add a Currency

To add a currency:

  1. Click the button at the top left of the table.

    The Add currency pop-up panel appears.

  2. Enter the code and the label in all available languages.

  3. Click OK.

Update a Currency

To update a currency:

  1. Click the button at the beginning of the line of the currency you want.

    The Update this currency pop-up panel appears.

  2. Enter the new information.

  3. Click OK.

Delete a Currency

To delete a currency:

  1. Click the button at the beginning of the line of the currency you want.

    The Delete this currency pop-up window appears to confirm the deletion.

  2. Click OK.

Fill in the Exchange Rate

To fill in the exchange rate, two ways are possible: either through the CSR Insight application or through Excel.

Through the CSR Insight Application

To fill in the exchange rate through the CSR Insight application:

  1. Click the box of the Exchange rate column that you want to edit.

    The Update an exchange rate pop-up panel appears.

  2. Enter a value.

  3. Click OK.

Through Excel

To fill in the exchange rate through Excel:

  1. Click the button at the top left of the screen.

    The Export exchange rates pop-up window appears with a link to an Excel file.

  2. Click the download link for the Excel file.

    The document is downloaded in your Downloads local folder.

  3. Open the Excel file, then enter manually the rate value used.

  4. When entry is completed, save the file.

  5. Back to the CSR Insight application, click the button at the top left of the screen.

    The Import exchange rates pop-up window appears.

  6. Select the Excel file you want to import.

  7. Click OK.

    The table is updated in the CSR Insight application.

  8. Repeat the steps 1 to 7 for a different rate type or for a different year.
