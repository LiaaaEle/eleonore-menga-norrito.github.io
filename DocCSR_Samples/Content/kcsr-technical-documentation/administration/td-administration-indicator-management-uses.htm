Indicator Management: Indicator Uses Column

SEARCH TIP  Press CTRL + F (Windows and Linux) or CMD + F (Mac) to search within this page.

To access this screen, click: Administration > Indicator management > Indicator management.

Security Notes

Some actions, such as screen access, are permitted only for authorized users, that is, users with the appropriate profile. In other words, if the user does not have the right profile, the user cannot perform the action.

To configure this security (also called user rights), complete the following steps:

  1. Define the profiles in the Profile Management screen.

  2. Define users and attach one or more profiles to them in the User Management screen.

  3. Assign user rights to the desired profiles in the Profile Matrix screen.

Indicators can be deployed on campaigns and/or associated with strategy deployment levels (stakes, targets level 1, targets level 2, and actions). A quantitative target is a strategy deployment level bound to a quantitative indicator.

 

The Indicator uses column contains all the uses of the indicators in the CSR Insight application related to:

  • Data collection on indicators and quantitative targets

  • User access

 

The Indicator uses block in the Identity card has the same content as the Indicator uses column. To access the Identity card, see Edit an Indicator.

View and Manage Uses of Indicators Related to Data Collection

You can view and manage uses of indicators related to data collection on indicators and quantitative targets from the Indicator uses column, that is:

  • View Campaigns Related to an Indicator

  • Export Campaign Data of an Indicator

  • View Data of Quantitative Targets Related to an Indicator

  • Enable or Disable Data Collection for an Indicator

View Campaigns Related to an Indicator

The Related campaigns sub-column of the Indicator uses column displays the number of campaigns related to an indicator.

 

To view the list of campaigns related to an indicator:

  1. Position your cursor at the line of the indicator for which you want to view related campaigns.

  2. On this line, click the cell in the Related campaigns sub-column.

    A list of campaigns, in which the indicator is deployed, appears.

 

To view and collect data for a specific campaign related to the indicator, click the desired campaign name from this list.

The Data Collection Campaigns screen appears with your selected campaign displayed in the point of view (POV).

Export Campaign Data of an Indicator

To export campaign data of indicators related from the Indicator uses column:

  1. Position your cursor at the line of the indicator for which you want to export campaign data.

  2. On this line, click the cell in the Associated data sub-column.

    The Export pop-up window appears with a download link.

  3. Click the download link for the Excel file.

View Data of Quantitative Targets Related to an Indicator

The Associated objectives sub-column of the Indicator uses column displays the number of quantitative targets related to an indicator.

 

To view data of quantitative targets related to an indicator from the Indicator uses column:

  1. Position your cursor at the line of the indicator for which you want to view related quantitative target data.

  2. On this line, click the cell in the Associated objectives sub-column.

    A list of quantitative targets, related to the indicator, appears.

 

If you want to view and collect data for a specific quantitative target related to the indicator, click the desired quantitative target name from this list.

The Indicator Tracking screen appears with your desired indicator and quantitative target displayed in the POV.

Enable or Disable Data Collection for an Indicator

By default, the Available status is associated with the indicator. Data collection is enabled, but there is no data collected or calculated yet.

When data is entered or calculated, the status becomes automatically Active.

When the status becomes Inactive, data collection is disabled, but you can always view your already collected or calculated data from the Reporting screens.

 

To enable data collection for an indicator from the Indicator uses column:

  1. Position your cursor at the line of the indicator for which you want to enable data collection.

  2. On this line, select Active from the drop-down menu of the Status sub-column.

  3. Click the button at the top right of the nested grid.

 

To disable data collection for an indicator from the Indicator uses column:

  1. Position your cursor at the line of the indicator for which you want to disable data collection.

  2. On this line, select Inactive from the drop-down menu of the Status sub-column.

  3. Click the button at the top right of the nested grid.

 

You can also enable or disable data collection by switching on or off the switch button from the Identity card.

View User Access to Indicators

NOTE Access restrictions to indicators are set for each profile and user.

To set up the access restrictions to indicators for each profile, see the documentation on the Profile Management.

To set up the access restrictions to indicators for each user, see the documentation on the Functional Scope Management.

Users can only have access to indicators included in the functional scopes for which they are responsible.

 

The Functional scope sub-column of the Indicator uses column displays the number of functional scopes that includes the indicator.

 

To view the list of functional scopes associated with the indicator and the users responsible for these functional scopes:

  1. Position your cursor at the line of the indicator for which you want to view user access.

  2. On this line, click the cell in the Functional scope sub-column.

    The Functional Scope Management screen appears.
