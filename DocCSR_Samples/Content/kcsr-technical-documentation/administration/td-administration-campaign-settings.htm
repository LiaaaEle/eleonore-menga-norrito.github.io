Security Notes

Some actions, such as screen access, are permitted only for authorized users, that is, users with the appropriate profile. In other words, if the user does not have the right profile, the user cannot perform the action.

To configure this security (also called user rights), complete the following steps:

  1. Define the profiles in the Profile Management screen.

  2. Define users and attach one or more profiles to them in the User Management screen.

  3. Assign user rights to the desired profiles in the Profile Matrix screen.

Introduction

To start your data collection, you need first to create, then configure a campaign through this screen.

As long as the campaign is not started, you can update its information.

If you are a general supervisor administrator (also called an administrator with GS rights, that is a user with all user rights), you can delete a campaign regardless of its status.

You can also:

  • Initialize Campaigns with their Default Indicators and Entities

  • Copy Campaign Entities and Indicators

  • Export a Campaign List

 

A general supervisor (GS) administrator can audit campaign settings through this screen.

NOTE Throughout this documentation, "GS Administrator" refers to a user with all user rights.

Campaign Workflow Overview

Follow this sequence to create and manage campaigns:

  1. Create the campaign.

  2. Deploy indicators and entities for the campaign through the Campaign Settings: Indicators to Deploy and Campaign Settings: Entities to Deploy for an Indicator screens.

  3. Review launch email settings.

  4. Start the campaign to enable data collection.

    Users with access to the campaign's deployed indicators and entities receive a notification email.

    Starting options: See Configure a Campaign for details.

  5. Monitor progress through campaign tracking.

  6. Close the campaign when data collection is complete.

  7. Audit deployment settings (GS administrators only).

For detailed instructions on each step, see the corresponding sections below.

Campaign Configuration Rules

Before creating and configuring campaigns, understand these consistency rules to ensure proper indicator and entity deployment through the Campaign Settings: Indicators to Deploy and Campaign Settings: Entities to Deploy for an Indicator screens:

  • Uniqueness constraints:

    • Only one campaign can be created for each "year - period" data couple.

    • An "indicator - entity" data couple can only be deployed on one campaign per year and periodicity.

  • Deployment restrictions:

    • Indicators can only be deployed on active entities.

    • Indicators cannot be deployed on both a parent entity and its child entities simultaneously.

    • Indicators with a defined Collect level (data collection point) can only be deployed to entities within that data collection point.

      NOTE For more information, see Indicator Management: Data Typology Column and Entity Type Management.

Create a Campaign

To create a new campaign:

  1. Select the year for the campaign in the point of view (POV).

  2. Click the button at the top left of the table.

    The Create a campaign pop-up panel appears.

  3. Enter the following fields:

    Field Description

    English label

    English name for the campaign.

    French label

    French name for the campaign.

    Campaign type

    Campaign period

    Select the data collection frequency and corresponding period:

    • Yearly: Collect data once a year (period: Full year)

    • Semiannually: Collect data twice per year

      • HY1: First semester

      • HY2: Second semester

    • Quarterly: Collect data four times per year

      • Q1: First quarter

      • Q2: Second quarter

      • Q3: Third quarter

      • Q4: Fourth quarter

    • Monthly: Collect data twelve times per year (January through December).

    Proforma

    NOTE Proforma is a module of the CSR Insight application that records all changes related to past data over time. For more information on this key concept, see Proforma (Quick Start documentation).

    You can create two types of campaigns:

    • Historical campaigns: Proforma data collected by import through the Data Import screen

    • Nonhistorical campaigns: Data collected by manual entry through the Data Collection Campaigns screen

    To create a historical campaign, select Yes.

    To create a nonhistorical campaign, select No.

    Default display mode

    The display mode of the Data Collection Campaigns screen you will view by default for the campaign:

    • Survey view, or

    • Table view

    On the Data Collection Campaigns screen, you can always change later the display mode through the switch button.

    N-1 source

    Data source for the previous campaign year (N-1):

    • Published: Published data.

    • "Label" proforma version: Data comes from a proforma version created on the Proforma Version Management screen.

    Example: For a 2024 campaign, N-1 refers to 2023 data.

  4. Click OK.

Update Campaign Information (Before or During Active Collection)

To update campaign information:

  1. Click any cell displaying the icon:

    • Name

      NOTE You can only change the name of not-started and started campaigns.

    • N-1 source

    • Responsible

    Depending on which cell you clicked, the Update this campaign, Update source, or Set the campaign responsible pop-up panel appears.

  2. Update your information.

  3. Click OK.

Delete a Campaign

NOTE Only a GS administrator can delete a started or closed campaign.

To delete a campaign:

  1. Click the button at the left of the line of the campaign you want to delete.

    The Delete this campaign pop-up window appears to confirm the deletion.

  2. Click OK.

Initialize Campaigns with their Default Indicators and Entities

The button allows you to initialize the campaign by default, which performs the following actions:

  1. First, the campaign is configured with indicators that have the same collect frequency as the campaign. Therefore, indicators with another collect frequency are not included by default in the campaign.

  2. Then, those indicators are deployed on the corresponding collection levels (entities) by default.

 

For example:

  • If a campaign has been defined with a quarterly collection frequency, the default indicators will be all the quarterly indicators.

  • Moreover, all these quarterly indicators will be deployed on their corresponding collection level by default.

Copy Campaign Entities and Indicators

To copy the entities and indicators of an existing campaign:

  1. Click the button.

    The Copy campaign entities and indicators pop-up panel appears.

  2. Select the Source campaign, that is the campaign to copy.

  3. Select one or multiple Target campaign, that is the campaigns in which the entities and indicators will be copied-pasted.

  4. Click OK.

Export a Campaign List

To export a campaign list, click the button in the toolbar at the top right of the screen.

An Excel file is automatically downloaded to your computer.

Audit the Campaign Settings

NOTE This section is only for GS administrators.

You can audit the campaign settings. This involves checking the deployment of indicators and entities for all campaigns from the same year at once.

To audit the campaign settings:

  1. Click the button.

    A pop-up panel appears with a download link.

  2. Click the download link for the Excel file.

 

To check deployments for each campaign separately, go to the Campaign Settings: Indicators to Deploy and Campaign Settings: Entities to Deploy for an Indicator screens.
