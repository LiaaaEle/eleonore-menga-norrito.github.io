Calculation Functions

Introduction

Calculation functions enable you to create dynamic formulas that reference and manipulate indicator data across your entity's structure and time periods.

This appendix provides information on calculation functions used in the CSR Insight application. These functions are used in formulas for calculated indicators to retrieve other indicator values — whether collected or calculated — across different entities and time periods.

Data Collection

Data is collected on indicators periodically (yearly, half-yearly, quarterly, or monthly) and at specific levels of the entity hierarchy (parent and child entities).

Data Consolidation

On Reporting screens, data is consolidated in two ways:

  • Across time periods (period hierarchy)

  • Across organizational levels (entity hierarchy)

Find a Calculation Function

You can locate calculation functions in two ways:

  • By name: Use the alphabetical navigation in the On this page menu

  • By purpose: Browse the table of available calculation functions below, which includes brief definitions

Prerequisites

Before working with calculation functions, you should be familiar with:

  • Entity hierarchies: Your entity's parent-child structure

  • Indicator references: Unique identifiers used in formulas to reference specific indicators

  • Aggregation methods: How data is consolidated across organizational levels and time periods

  • Campaign deployment: Associating indicators with entities within data collection campaigns

    NOTE Deployment requirement: For aggregation calculation to work, indicators (whether calculated or collected) must be deployed on the same entity.

Carbon Footprint Functions Overview

The following functions retrieve different types of carbon footprint data.

Choose the function based on the level of detail you need:

  • BILAN_CARBON: Retrieve emissions from specific emission factors or all emission factors

  • EMISSION: Retrieve emissions from all emission factors within a sub-category

  • FACTOR: Retrieve emission factor values (not emissions)

  • REPORT_FINANCIAL/REPORT_OPERATED: Retrieve emissions by reporting standard (GHG Protocol, BEGES) and control approach

Definition

Use Case

Example

Scenario

Calculate the ratio of staff trained in fire protection for the Group entity in January 2024 from collected data.

 

Aggregation methods used:

  • Temporal aggregation: Sum

  • Entity aggregation: Recalculate at all levels

 

Data was collected on:

Indicator label Indicator reference Data collected

Fire protection (Women and Men)

FP_WM

Staff trained in fire protection

Staff_Women

STAFF_W

Women staff

Staff_Men

STAFF_M

Men staff

Challenge

Total staff data is missing for Group but available for subsidiaries (France and Belgium).

Solution

Use the Consolidate calculation function to aggregate subsidiary data.

Formula

FP_WM / (Consolidate (STAFF_M) + Consolidate (STAFF_W)):

Step-by-Step Calculation

  1. Staff trained (Group): 10

  2. Consolidate (STAFF_M) aggregates men staff from subsidiaries:

    • France: 60

    • Belgium: 30

    • Total: 60 + 30 = 90

  3. Consolidate (STAFF_W) aggregates women staff from subsidiaries:

    • France: 20

    • Belgium: 35

    • Total: 20 + 35 = 55

  4. Total staff: 90 + 55 = 145

  5. Final calculation: 10 / 145 = 0.07 (7%)

Related Functions

  • AutoConsolidate: Automatically applies Consolidate when configured by the project team. Use when you want automatic aggregation without explicit function calls.

    Use instead of Consolidate when your project team has enabled automatic aggregation and you're using the Compute at level 0 then aggregate aggregation method.

  • OrgaValue: Retrieve values from specific entities without aggregation. Use when you need data from a particular entity in your formula (for example, comparing subsidiary performance to group targets).

Common Errors and Solutions

Error Solution

Function not recognized

Verify the function name spelling and ensure it's available in your CSR Insight version. Check that any required configurations (like AutoConsolidate) are enabled by your project team.

Indicator not found

Verify the indicator reference on the Indicator Management screen.

Circular reference detected

Ensure your formula doesn't reference itself directly or indirectly.

Entity not found

Verify the entity reference on the Entity Management screen.

Carbon footprint reference not found

Verify the carbon footprint reference (emission factor, emission factor sub-category, emission post, emission scope, gas) in corresponding Carbon Footprint settings screens.

Division by zero

Check if denominator indicators have null or zero values. Use conditional logic or default values to prevent division by zero.

Data type mismatch

Ensure all indicators in arithmetic operations use compatible data types (for example, do not add numeric and text values).

Period mismatch

Ensure time-period-specific functions (RetrievePrevMonth, RetrievePrevYear) are used only in campaigns with matching periodicity (monthly, yearly).

Missing data in calculation

Verify that all referenced indicators have data for the selected entity and period. Missing data propagates through calculations.

Aggregation method conflict

Ensure temporal and entity aggregation methods are appropriate for your formula. For example, using Average when Sum is needed will produce incorrect results.

Insufficient permissions

If you cannot see calculation results, verify that you have read access to all indicators and entities referenced in the formula. Contact your administrator if needed.

Advanced Usage: Combine Mutiple Functions

You can nest and combine calculation functions to create sophisticated formulas for complex analysis.

NOTE Only the Consolidate calculation function can have nested calculation functions.

Example: Subsidiary Performance vs Group Target

Use case: Calculate each subsidiary's emissions as a percentage of the group's total emissions target to identify which locations need the most attention.

 

Scenario:

  • Group has set a total emissions target of 50,000 tCO2e.

  • Need to compare each subsidiary's actual emissions against their proportional share of the group target.

 

Formula: Consolidate(EMISSIONS_ACTUAL) / OrgaValue(EMISSIONS_TARGET, GROUP) * 100

 

How it works (with example values for France subsidiary):

  1. Consolidate(EMISSIONS_ACTUAL): Aggregates France's emissions including all its child entities (Paris office, Lyon office, and so on).

    • Result: 8,500 tCO₂e

  2. OrgaValue(EMISSIONS_TARGET, GROUP): Retrieves the Group-level emissions target.

    • Result: 50,000 tCO₂e

  3. Division: Calculates France's proportion of the group target.

    • Result: 8,500 / 50,000 = 0.17

  4. Multiplication: Converts to percentage.

    • Result: 0.17 × 100 = 17%

Final Result: France represents 17% of the group's total emissions target.

 

Why this is useful: This formula combines:

  1. Consolidate() to aggregate subsidiary-level data

  2. OrgaValue() to pull a specific target from the parent entity

  3. Arithmetic operations to create a meaningful ratio

 

This pattern works at any level of the hierarchy without hardcoding entity-specific values.

Best Practices for Complex Formulas

  1. Build incrementally: Test each function separately before combining.

  2. Document your logic: Use clear indicator labels and add comments in your formula documentation.

  3. Consider performance: Deeply nested functions may slow calculation times on large datasets.

  4. Validate results: Cross-check complex formulas against manual calculations for accuracy.

Common Combination Patterns

Pattern Formula Example When to Use

Percentage change with consolidation

(Consolidate(CURRENT) - Consolidate(PREVIOUS)) / Consolidate(PREVIOUS) * 100

Comparing consolidated values across time periods to show percentage growth or decline.

Consolidated value against group target

Consolidate(ACTUAL) / OrgaValue(TARGET, GROUP) * 100

Calculating a subsidiary's aggregated value as a percentage of a group-level target.

Cross-entity ratios

OrgaValue(INDICATOR_A, ENTITY1) / OrgaValue(INDICATOR_B, ENTITY2)

Calculating ratios between different entities.

Emission intensity

BILAN_CARBON_FE_ENERGY_EMITTED / Consolidate(REVENUE)

Calculating emissions per unit of business activity.
