Summary of Consolidations

SEARCH TIP  Press CTRL + F (Windows and Linux) or CMD + F (Mac) to search within this page.

To access this screen, click: Data entry > Audit and logs > Audit trail v1. The Audit Trail screen appears. Click the button above the table.

Security Notes

Some actions, such as screen access, are permitted only for authorized users, that is, users with the appropriate profile. In other words, if the user does not have the right profile, the user cannot perform the action.

To configure this security (also called user rights), complete the following steps:

  1. Define the profiles in the Profile Management screen.

  2. Define users and attach one or more profiles to them in the User Management screen.

  3. Assign user rights to the desired profiles in the Profile Matrix screen.

The table below contains screen actions that are related to user rights:

Module Screen Action

Audit and logs

Audit trail*

Screen access**

*Users who can access the Audit Trail screen can access the Summary of Consolidations screen.

**Data available (indicators, entities) depends on your functional scope — associated with your profile. For more details, see the following documentations:

  • Functional Scope Management: Create and manage functional scopes

  • Scope Indicators: Configure the functional scope content (indicators).

The Summary of Consolidations screen provides basic information on calculated and consolidated data, indicator by indicator, for auditing purposes.

NOTE You can only view information only for the data calculated and consolidated. To access an audit trail on collected data without calculation and consolidation, see View Collected Data.

Point of View (POV)

Users can filter audit trail information by selecting the following items in the POV:

  • Year: Select the reporting year

  • Period: Select the reporting period

  • Entity: Select the entity for which to view audit information

Related Screens

  • Audit Trail: View a comprehensive record of all data-related activities during collection campaigns, including data collection, validation, and adjustment — displays only the most recent action performed on collected indicators

  • Detailed Audit Trail: View a comprehensive audit trail view — the entire sequence of actions performed for each indicator by entity, period, and year throughout its entire lifecycle, not only the most recent one

Description of the Table Columns

The table contains the following columns:

Column Description

Indicator

Indicator label.

Unit

Indicator input unit: the unit of the data entered for the indicator.

Value

Indicator value obtained by calculation.

Indicator reference

Unique code identifying the indicator. This code is associated to the indicator by the administrator in the Indicator Management screen.

Indicator calculation formula

Calculation formula used for the indicator.

Description

Indicator description entered during data collection.

Export an Audit Trail on Calculated and Consolidated Data

To export the audit trail table in Excel format:

  1. Click the button above the table.

    The Export pop-up window appears with a download link.

  2. Click the download link for the Excel file.
