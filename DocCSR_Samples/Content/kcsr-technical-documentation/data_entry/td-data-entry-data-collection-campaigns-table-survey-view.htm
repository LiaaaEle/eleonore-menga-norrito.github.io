Security Notes

Some actions, such as screen access, are permitted only for authorized users, that is, users with the appropriate profile. In other words, if the user does not have the right profile, the user cannot perform the action.

To configure this security (also called user rights), complete the following steps:

  1. Define the profiles in the Profile Management screen.

  2. Define users and attach one or more profiles to them in the User Management screen.

  3. Assign user rights to the desired profiles in the Profile Matrix screen.

Change the Unit

In the CSR Insight application, you can use three types of units:

  • The default unit

  • The input unit: the unit of the data entered for the indicator

  • The preference unit: the unit your entered data will be converted to

 

By default, the Unit column (table view) or the cell next to the data entry cell (survey view) displays the default unit set up for the indicator on the Indicator Management screen.

 

If the unit is changeable, you can select a new input unit. If so, a drop-down menu appears in the cell.

 

You can also convert the indicator value to one or several preference units.

Unit drop-down menu

 

 

NOTE To enable unit change for an indicator, see the documentation on the Indicator Management screen. The unit can be changeable only for collected data.

To set up the units selectable in the drop-down menu, see the documentation on the Unit Management and the Unit Category Management screens. Only units with a conversion factor can be selected.

Select a New Input Unit

If the indicator has no data entered:

  1. Select the desired unit from the drop-down menu in the Unit column (table view) or in the cell next to the data entry cell (survey view).

  2. Save.

    The unit selected becomes the indicator input unit.

 

If the indicator has data entered:

  1. Select the desired unit from the drop-down menu in the Unit column (table view) or in the cell next to the data value cell (survey view).

    The indicator value is converted to the preference unit selected.

  2. Enter the new indicator value for this unit.

  3. Save.

    The preference unit becomes the input unit.

Convert Data to a Preference Unit

To convert the indicator value to the preference unit of your choice, select the unit from the drop-down menu in the Unit column (table view) or in the cell next to the data entry cell (survey view).

The indicator value is automatically converted to the preference unit selected.

View the Identity Card

NOTE On this screen, the identity card is read-only. To edit the identity card information, see the documentation on the Indicator Management.

By default, the Description, Label and Short label fields are displayed in your user language. To view these fields in other languages available in the CSR Insight application, click them.

 

The identity card allows you to view all information on the indicator.

 

To view the identity card:

  1. Click the button in the indicator line (table view), or in the indicator card (survey view).

  2. Click Identity card.

    Three dots drop-down menu

     

    The Identity card pop-up windows appears.

View the Validation Information

You can view validation information via:

  • The validation path

  • The validation history

View the Validation Path

The validation path allows you to view information, such as the date and the user name, for each workflow step from the campaign opening to the campaign locking.

 

NOTE To know more on workflow steps, see the Workflow Process section in the Data Collection Campaigns: Table View documentation, or in the Data Collection Campaigns: Survey View documentation.

 

To view the validation path:

  1. Click the button in the indicator line (table view), or in the indicator card (survey view).

  2. Click Validation path.

    Three dots drop-down menu

     

    The Validation path pop-up window appears.

 

To ask a question to the user who performed the action:

  1. Click the icon inside the workflow step card.

    The Ask a question pop-up panel appears.

  2. Apply the procedure written in the Ask and Answer a Question section below.

View the Validation History

To view the validation history for an indicator:

  1. Click the button at the right of the cell in the campaign current "Period - Year" column for the desired indicator (table view), or at the top right of the desired indicator card (survey view).

  2. Click Validation History.

    Three dots drop-down menu

     

    The Validation History screen appears.

Request Adjustment

You can request adjustment, that is make a request to modify data entered in a campaign that has been closed.

 

To request an indicator value adjustment:

  1. Click the button at the right of the cell in the campaign current "Period - Year" column for the desired indicator (table view), or at the top right of the desired indicator card (survey view).

  2. Click Request Adjustment.

    Three dots drop-down menu

     

    The Adjustment context pop-up panel appears.

     

    See the documentation on the Adjustment Requests Summary.

Ask and Answer a Question

There are two ways to ask and answer a question about an indicator:

  • Through this screen from the table view or the survey view

  • Through the Chat Room

 

For the first way, see below.

For the second way, see the documentation on the Chat Room.

 

Questions are classified by topics (indicator, value, campaign, free, and so on).

Ask a Question

To ask a question:

  1. Click the button in the Actions column of the indicator (table view), or at the top right of the indicator card (survey view).

    The Ask a question pop-up panel appears.

  2. Select the Topic, the Campaign, the Entity, and the Indicator.

    NOTE If you select Free as a topic, you do not need to select the Campaign, the Entity, and the Indicator.

  3. Select the Receiver of the question.

    NOTE If the topic is Indicator, the question is directly assigned to the indicator referent.

  4. Write your question.

    You can set the text font, size, and style.

    To add an hypertext link, click the button.

  5. Click Send.

Answer a Question

To answer a question:

  1. Click the button in the Actions column of the indicator (table view), or at the top right of the indicator card (survey view).

  2. Select Show conversation.

    Red chat drop-down menu

  3. Enter your comment.

    Comment entry zone

  4. Click the button.

Import and Export Data

You can import and export data, as well as track all your imports.

Import and Export Data

NOTE Only authorized users can import data. See the Security Notes above.

You can export, then import data through this screen.

Import data drop-down menu

Export Data

To export data:

  1. Click Export format and data from the Import data drop-down menu at the top right of the screen.

    The Data export pop-up window appears with the download link.

  2. Depending on the indicators and entities deployed on the campaign, select one or more items from the following drop-down menus:

    • Entity

    • Themes

    • Sections

  3. Select the Indicator search mode to determine how the system matches indicators in your Excel file to indicators in the CSR Insight application:

    • Label if your Excel file uses indicator names

    • Reference if your Excel file uses indicator codes

  4. Click OK.

  5. Click the download link for the Excel file.

Import Data

WARNING The import is carried out for all open campaigns listed in the import file.

Once the import is launched, please ensure not to initiate another import until you have verified its status in the Data Import screen or by clicking the button in the toolbar at the top right of the screen.

 

To import data:

  1. Export data, as mentioned above.

  2. Open the exported Excel file.

  3. Fill in the Excel template, then save your data.

    NOTE To help you fill in the Excel template, see the Fill In the Excel Template appendix.

  4. Back to the CSR Insight application, click Import data from the Import data drop-down menu at the top right of the screen.

    The Data import pop-up window appears.

  5. Select the Import mode:

    • Create and update (without deleting) if you want to add new data without deleting the data that already exist in the CSR Insight application. No data overwriting.

    • Create, update, and delete if you want to overwrite or clear the existing data in the CSR Insight application. Overwriting means that existing data is deleted and replaced with new data.

  6. Select the Indicator search mode to determine how the system matches indicators in your Excel file to indicators in the CSR Insight application:

    • Label if your Excel file uses indicator names

    • Reference if your Excel file uses indicator codes

  7. Choose a file.

  8. Click OK.

  9. Check if your import is successful or not. To do so, click the button in the toolbar at the top right of the screen.

    The Notifications pop-up window appears on the right.

    Notifications pop-up window

  10. If your import is successful, refresh the screen. Your new data appears on the screen. If not, read the next steps.

  11. If your import is unsuccessful, click the button to download an error file.

  12. Make corrections as needed, then import your file again.

    NOTE For more details on failed imports, see Fill In the Excel Template.
