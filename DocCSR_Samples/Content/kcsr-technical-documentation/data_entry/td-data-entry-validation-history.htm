Validation History

SEARCH TIP  Press CTRL + F (Windows and Linux) or CMD + F (Mac) to search within this page.

To access this screen, click: Data entry > Data collection campaigns.

The Data Collection Campaigns screen appears.

First, click the button at the right of the cell in the campaign Current year column for the desired indicator (table view), or at the top right of the desired indicator survey (survey view).

Then, click Validation History.

Click the button to return to the Home Screen.

Security Notes

Some actions, such as screen access, are permitted only for authorized users, that is, users with the appropriate profile. In other words, if the user does not have the right profile, the user cannot perform the action.

To configure this security (also called user rights), complete the following steps:

  1. Define the profiles in the Profile Management screen.

  2. Define users and attach one or more profiles to them in the User Management screen.

  3. Assign user rights to the desired profiles in the Profile Matrix screen.

Introduction

This screen allows you to view the history of actions performed on an indicator, that is:

  • A validation

  • An invalidation

  • A request adjustment

  • An adjustment

By default, the point of view (POV) displays the information for the indicator selected in the Data Collection Campaigns screen.

To view information for another indicator, select from the POV drop-down menus:

  • The Year

  • The Period

  • The Entity

  • The Indicator

Description of the Table Columns

The table contains the following columns:

Column Description

Type

The type of action performed in the Data Collection Campaigns screen or in the Details of Adjustment Requests screen:

  • Validation: A user validated the indicator.

  • Invalidation: A user rejected the indicator.

  • Request adjustment: A user requested an adjustment of the indicator value.

  • Adjustment: A user adjusted the indicator value.

NOTE You can request and make an adjustment only for indicators included in a closed campaign.

Date

The date for which the action was performed on the indicator.

Author

The user who performed the action on the indicator.

Value

Depending on the action performed, the value of the indicator that has been validated, invalidated, adjusted, or requested in an adjustment request.
