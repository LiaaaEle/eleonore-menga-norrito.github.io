To configure this security (also called user rights), complete the following steps:

  1. Define the profiles in the Profile Management screen.

  2. Define users and attach one or more profiles to them in the User Management screen.

  3. Assign user rights to the desired profiles in the Profile Matrix screen.

Display Lines

You can choose which lines you want to display or hide.

 

To display or hide lines depending on the indicator type, select one or multiple options from the Show lines drop-down menu:

  • Unavailable: Only indicators with unavailable data

  • Alerts: Only indicators with alerts

  • Extrapolated: Only indicators with extrapolated data

Enter Data

You can enter the indicator value, as well as additional information.

NOTE Entry rights depend on the user profile. See the Security Notes above, and the Workflow Process section below.

Enter the Indicator Value

To enter the indicator value without extrapolation for the indicator:

  1. Click the corresponding data entry cell in the indicator card.

    NOTE If the response type of your indicator is Choice list - simple choice or Choice list - multiple selection, select your data from a drop-down menu.

  2. Save your data, as mentioned in the Save and Submit Data for Validation section below.

 

To enter the indicator extrapolated value:

  1. Click the button in the indicator card, then Extrapolation.

    The Extrapolate value pop-up panel appears.

  2. Choose the Extrapolation method among the following methods:

    • For yearly campaigns:

      • Previous year: The indicator value is calculated based on the last year value.

      • Average of previous years: The indicator value is calculated based on the average of the previous years values.

      • Weighting: The indicator value is calculated based on the weight of a reference indicator over a chosen period.

      • Estimation: The indicator value is estimated. In other words, the user does not have a real value for an indicator, but can estimate this value.

       

    • For non-yearly campaigns:

      • Same period of last year: The indicator value is calculated based on the last year value at the same period

      • Previous period: The indicator value is calculated based on the last period value.

      • Average of previous periods: The indicator value is calculated based on the average of the previous period values.

      • The weight of a reference indicator over a period of your choice: The indicator value is calculated based on the weight of a reference indicator over a chosen period.

      • Estimation: The indicator value is estimated. In other words, the user does not have a real value for an indicator, but can estimate this value.

  3. Select a Unit.

    NOTE If the unit selected is not the default unit, the extrapolated value will be automatically converted into the default unit.

  4. If you chose Estimation as your extrapolation method, enter an Extrapolated value.

  5. Click OK.

    Extrapolated data is marked with a green line at the top of the cell.

  6. Save your data, as mentioned in the Save and Submit Data for Validation section below.

 

NOTE To follow up your extrapolated data, go to the Extrapolated Data Follow-Up screen.

Enter Carbon Footprint Information

Before following the procedures that will allow you to enter the carbon footprint information, read the prerequisites below.

 

Prerequisites

To enter carbon footprint information for an indicator, you need to enable the display and the entry of carbon footprint information beforehand.

 

To display carbon footprint information in the table view for an indicator, bind this indicator to an emission factor on the Association of Emission Factors with Activity Indicators screen.

 

To enable the entry of carbon footprint information for an indicator, see the documentation on the Indicator Management.

 

If the selection of the Financial control and the Operational control is enabled for an indicator on the Indicator Management screen, you must select one of the options available in each drop-down menu. If not, you cannot validate the indicator.

 

To set up the options for the Financial control and the Operational control drop-down menus:

  1. Create an emission factor category on the Management of Emission Factor Categories screen.

  2. Create an emission factor on the Emission Factors List screen and bind it to the emission factor category.

  3. Bind the emission factor to the indicator for which you want to edit the financial and the operational control, on the Association of Emission Factors with Activity Indicators screen.

 

Procedures to Follow

You can enter the value for the activity indicator like any other indicator.

 

To enter the Uncertainty:

  1. Click the button.

    The Edit the uncertainty pop-up panel appears.

  2. Drag your cursor across the bar to the desired percentage.

  3. Click Submit.

  4. Save.

 

To enter the Amortization period:

  1. Click the button.

    The Edit the amortization period pop-up panel appears.

  2. Enter the number of years desired.

  3. Click Submit.

  4. Save.

 

To enter the Partner:

  1. Select one of the options available in the drop-down menu.

  2. Save.

 

To enter the Financial control:

  1. Select one of the options available in the drop-down menu.

  2. Save.

 

To enter the Operational control:

  1. Select one of the options available in the drop-down menu.

  2. Save.

 

NOTE When the default uncertainty percentage, amortization period, partner, financial control, or operational control is defined for an indicator through the Indicator Management, Management of Default Control Modes, or the Details of Uncertainty screen, the labels displayed in the indicator card are:

  • Default uncertainty
  • Default amortization period
  • Default partner
  • Default financial control
  • Default operational control

When you define a new uncertainty percentage, amortization period, partner, financial control, or operational control on this screen, the labels change:

  • Uncertainty
  • Amortization period
  • Partner
  • Financial control
  • Operational control

Save and Submit Data for Validation

To save and submit the data you enter, click the button at the top right of the screen to save the data to the server.

 

NOTE By default, the button is gray. The button turns green when new data entry is made and needs to be saved.

Validate Data

NOTE Validation rights depend on the user profile. See the Security Notes above, and the Workflow Process section below.

To validate data for an indicator, click the button in the indicator card.

The indicator is validated.

 

To validate data for all the indicators at once:

  1. Click Validate all from the Workflow drop-down menu at the top right of the screen.

    The Validate all pop-up window appears.

  2. Click Validate all.

    All indicators are validated.

 

To validate data for selected indicators:

  1. Click Validate a selection from the Workflow drop-down menu at the top right of the screen.

  2. Select the box of one or multiple indicators you want to validate.

  3. Click the button that appears at the bottom of the screen.

    Selected indicators are validated.

 

Workflow drop-down menu

 

To close an indicator, click the button next to the button in the indicator card.

 

NOTE If activated on the Mail Settings screen, authorized users receive a notification email when one or multiple indicators have been validated or closed. See the Security Notes above.

No notification will be sent if the validated or closed indicators do not have a value entered or calculated.

Reject Data Validation

If you do not want to validate one or multiple indicators, you can reject validation.

 

To reject validation for an indicator:

  1. Click the button in the indicator card.

    The Unvalidate pop-up panel appears.

  2. Enter the reason for your refusal as a comment.

  3. Click OK.

    Validation is rejected for the indicator. Your reason for refusal appears in the comment entry cell.

 

To reject validation for all indicators at once:

  1. Click Invalidate all from the Workflow drop-down menu at the top right of the screen.

    The Invalidate all pop-up window appears.

  2. Enter the reason for your refusal as a comment.

  3. Click Invalidate all.

    Validation is rejected for all indicators. Your reason for refusal appears in the comment entry cell.

 

To reject validation for selected indicators:

  1. Click Invalidate a selection from the Workflow drop-down menu at the top right of the screen.

  2. Enter the reason for your refusal as a comment.

  3. Check the box of one or multiple indicators you want to validate.

  4. Click the button that appears at the bottom of the screen.

    The Invalidate all pop-up window appears.

  5. Click Invalidate all.

    Validation is rejected for selected indicators. Your reason for refusal appears in the comment entry cell.

 

Workflow drop-down menu

View the Indicator Status

The indicator status appears as a summary list on the left of the screen.

 

There are three different indicator status buttons:

  • In progress: The indicator is not yet validated by the authorized user.

  • Validated: The indicator is validated by the authorized user.

  • Closed: The indicator is closed by the authorized user.

 

When an alert is triggered:

  • On the summary list, the indicator is displayed in red.

    Summary list

  • On the indicator card, an alert icon and a red cell are displayed. When you hover over the alert icon, one or multiple warning messages appear.

    Indicator card

 

NOTE To know more on alerts, see the Alerts section below.

View the Campaign Deadline and Progress

Each campaign has deadlines for the entry, the validation, and the closure.

Campaign deadlines

 

NOTE To set these deadlines, go to the Campaign Set Up screen.

 

The color of the dots for each campaign phase provides information on the campaign progress given the deadline:

  • Blue: Nothing to report.

  • Orange: The time left is less than 10% of the total time allotted for the phase.

  • Red: The deadline is exceeded.

 

The current campaign progress through validation step is calculated based on the total number of indicators in the user's functional scope.

 

To view the percentage of the campaign progress for each workflow step, hover over the Started, Validated locally, or Closed bar.

The percentage appears on a chip:

  • Green: The campaign progress for the workflow step is greater than 84%.

  • Yellow: The campaign progress for the workflow step is between 15% and 85%.

  • Red: The campaign progress for the workflow step is under 15%.

    Campaign progression

View Additional Information

You can view additional information for:

  • Quantitative indicators

  • Qualitative indicators

For Quantitative Indicators

To view additional information for quantitative indicators, click the button to show the historical data, unit, and description of the indicator.

 

To hide the additional information, click the button.

 

The additional information include:

  • The input unit

  • The valuation table

    NOTE The valuation table contains a coefficient that allows you to modify the indicator weight.

    To view this information, you need to select a valuation table for the indicator. See the documentation on the Indicator Management and on Management of Valuation Tables.

  • The indicator description

    NOTE To enter, edit, or delete the indicator description, go to the Indicator Management screen.

  • The chart on the indicator value evolution over time

    NOTE By hovering over the blue columns, you can view the indicator value.

  • The chart on the action evolution over time

    NOTE This chart appears only for indicators bound to an action.

    Collected data on the indicator linked to the action is represented by the blue columns. The trajectory of the action, which includes all the targets set for the action, is represented by the orange line.

    By hovering over the blue columns, you can view the details about the achievement of the target.

Alerts

NOTE Alerts can only be attached to indicators included in nonhistorical campaigns.

For more information on historical and nonhistorical campaigns, see the Color Coding for the Indicator Value Cell section below.

 

You can view alerts if:

  • The indicator value entered does not respect the threshold or the consistency check set up.

  • The entry deadline has passed.

  • And so on.

 

When an alert is triggered:

  • The indicator value cell turns red.

  • An alert icon appears, as well as a warning message, when you hover over it.

  • Depending on the alert type, the comment cell, the carbon footprint information cells, and/or the button turns red.

  • On the summary list, the indicator is displayed in red.

 

Color Coding for the Indicator Value Cell

The indicator value cell changes color, as below:

Color Description

Yellow

Data is not saved yet. You have to save it in order to record it in the application.

White

If the cell is empty, the cell is editable. If the cell is filled in, the data is saved on the server.

Gray

A gray cell is a read-only cell. This is the case, if:

  • The indicator is calculated

  • The indicator is validated or closed

  • The campaign is locked by the administrator

  • The campaign is historical

    NOTE The CSR Insight application supports two types of campaigns:

    • Historical campaigns: Proforma data collected by import through the Data Import screen
    • Nonhistorical campaigns: Data collected by manual entry through the Data Collection Campaigns screen

    NOTE The CSR Insight application supports two types of campaigns:

    • Historical campaigns: Proforma data collected by import through the Data Import screen
    • Nonhistorical campaigns: Data collected by manual entry through the Data Collection Campaigns screen

    To create campaigns, see Campaign Set Up or Data Recovery.

White with green line

Extrapolated data.

Red

A threshold or a consistency check alert is triggered.
