Action Reports: Introduction

SEARCH TIP  Press CTRL + F (Windows and Linux) or CMD + F (Mac) to search within this page.

To access this screen, click: Strategy > My actions > Action Reports.

Security Notes

Some actions, such as screen access, are permitted only for authorized users, that is, users with the appropriate profile. In other words, if the user does not have the right profile, the user cannot perform the action.

To configure this security (also called user rights), complete the following steps:

  1. Define the profiles in the Profile Management screen.

  2. Define users and attach one or more profiles to them in the User Management screen.

  3. Assign user rights to the desired profiles in the Profile Matrix screen.

STEP BY STEP

After creating strategies on the Strategy Management screen, you need to deploy them, that is creating their deployment levels.

You can create actions (last deployment level) from the Strategy Deployment screen or this screen.

This screen allows you to view and manage all your actions. The actions can be attached or not to a strategy and a target.

NOTE Each strategy has different deployment levels:

  • Stake

  • For each stake, one or multiple Target level 1

  • For each target level 1, one or multiple Target level 2

  • For each target level 2, one or multiple Action


See the documentation on the Strategy Deployment.

To filter the actions you want to view:

  1. In the point of view (POV), select:

    • The Year

    • The Entity

    • The Periodicity

      NOTE When the periodicity selected is Yearly, you can view all actions.

      When the periodicity is Half-Yearly, you can view all actions except those that are yearly.

      When the periodicity selected is Quarterly, you can view all actions except those that are yearly and half-yearly.

      When the periodicity selected is Monthly, you can only view monthly actions.

    • The Period

  2. Optional: Select the Stake, the Target level 1, and the Target level 2 if possible.

    NOTE By default, you can view all the stakes and targets.

    See the documentation on the Strategy Deployment.

  3. Click Apply.

    The list of the actions corresponding to the items selected in the POV appears.

  4. Optional: To further filter, use the Status and/or Alert filters.

    Status and Alert filters

    A new action list appears.

    NOTE For more information on statuses and alerts, see the Action Reports: Statuses and Alerts documentation.
