Quantitative Target Synthesis

SEARCH TIP  Press CTRL + F (Windows and Linux) or CMD + F (Mac) to search within this page.

To access this screen, click: Strategy > Monitoring of strategies > Quantitative target synthesis.

Security Notes

Some actions, such as screen access, are permitted only for authorized users, that is, users with the appropriate profile. In other words, if the user does not have the right profile, the user cannot perform the action.

To configure this security (also called user rights), complete the following steps:

  1. Define the profiles in the Profile Management screen.

  2. Define users and attach one or more profiles to them in the User Management screen.

  3. Assign user rights to the desired profiles in the Profile Matrix screen.

Introduction

This screen allows you to manage your quantitative targets for a given:

  • Strategy

  • Reporting year

  • Organization

  • Periodicity

On this screen, you can:

  • Request an Alternative Value for a Quantitative Target

  • Export Quantitative Target Values

Description of the Table Columns

The table contains the following columns:

Column Description

Label

The deployment level label.

Type

The deployment level type, that is:

  • Stake

  • Target level 1

  • Target level 2

  • Action

NOTE To know more on deployment levels, see the Strategy Deployment documentation.

Indicator

The label of the indicator linked to the deployment level.

Reporting year

The "Reporting year" column contains one or multiple "Period" sub-columns.

The number and type of "Period" sub-columns depend on the Periodicity selected in the POV:

  • If the periodicity selected is Yearly, you can view: one Full year column.

  • If the periodicity selected is Semiannually, you can view:

    • A HY1 column, and

    • A HY2 column

  • If the periodicity selected is Quarterly, you can view by year:

    • A Q1 column

    • A Q2 column

    • A Q3 column, and

    • A Q4 column

  • If the periodicity selected is Monthly, you can view by year:

    • A January column

    • A February column

    • A March column

    • An April column

    • A May column

    • A June column

    • A July column

    • An August column

    • A September column

    • An October column

    • A November column, and

    • A December column

Request an Alternative Value for a Quantitative Target

NOTE You cannot make adjustment requests on parent entities when the input mode for the quantitative target is Bottom up.

To request an alternative value for a quantitative target:

  1. Click the button at the end of the desired line.

    An adjustment request grid appears at the bottom of the screen.

  2. Double-click the cell in the Target proposed line for the desired year.

  3. Enter the desired alternative value.

  4. Save.

The authorized user can then validate or reject the alternative value requested on the Indicator Tracking screen.

If the alternative value is validated, the alternative value becomes the new value you can view in the table.

If the alternative value is rejected, the displayed value does not change.

NOTE Depending on your profile, you can also copy and paste a quantitative target value from one cell to another.

To do so:

  1. Click the bottom right corner of the Group target cell from which you want to copy the quantitative target value, or use the Ctrl + C keyboard shortcut.

  2. Click the bottom right corner of the Target proposed cell in which you want to paste the quantitative target value, or use the Ctrl + V keyboard shortcut.

    The quantitative target value is copied and pasted into the desired cell.

Export Quantitative Target Values

To export the quantitative target value table:

  1. Click the export button at the top left of the table.

    The Scripts pop-up window appears with a download link.

  2. Click the download link.
