To access this screen, click: Strategy > My actions > Action Reports.

Security Notes

Some actions, such as screen access, are permitted only for authorized users, that is, users with the appropriate profile. In other words, if the user does not have the right profile, the user cannot perform the action.

To configure this security (also called user rights), complete the following steps:

  1. Define the profiles in the Profile Management screen.

  2. Define users and attach one or more profiles to them in the User Management screen.

  3. Assign user rights to the desired profiles in the Profile Matrix screen.

Every action is attached to a status for a given entity and period. Alerts inform you that there are one or several issues with your action.

You can filter actions by status and/or alert in both detailed and synthesis view modes, as mentioned in the Action Reports: Introduction documentation.

To change statuses and/or attach alerts to actions, go to the detailed view mode. To do so, click the switch button.

Status Presentation

NOTE To change the action status, the action periodicity must be the same as the periodicity selected in the POV.

In the action card, authorized users can change the action status in the Status block. See the Security Notes section above.

Every action is attached with a status for a given entity and period:

Status Description

Pending

The action is waiting for validation. This is the default status for all actions that need validation.

To approve the action, click the button.

To reject the action, click the button.

To abort the action, click the button.

Rejected

The pending action has been rejected.

To reject the action, click the button.

Approved

The pending action has been approved. This is the default status for all actions that do not need validation.

After approbation, you can either implement or abort the action.

To approve the action, click the button.

After approbation, you can implement or abort the action.

To implement the action:

  1. Click the button.

    The Start action pop-up window appears.

  2. Select one of the available options from the drop-down menu:

    • For all organizations: The action is implemented for all entities on which the action is deployed.

    • Only for the current organization: The action is implemented for the entity selected in the POV only.

    • For the current organization and its descendants: The action is implemented for the entity selected in the POV and its child entities.

  3. Click Submit.

    The action status becomes In progress.

To abort the action:

  1. Click the button.

  2. Select one of the available options from the drop-down menu:

    • For all organizations: The action is aborted for all entities on which the action is deployed.

    • Only for the current organization: The action is aborted for the entity selected in the POV only.

    • For the current organization and its descendants: The action is aborted for the entity selected in the POV and its child entities.

  3. Click Submit.

    The action status becomes Aborted.

In progress

The implemented action is in progress.

Select In progress from the drop-down menu.

On standby

The implemented action is on standby.

Select Stand-by from the drop-down menu.

Completed

The implemented action is completed.

Select Completed from the drop-down menu.

Aborted

The pending, approved, or implemented action has been aborted.

Color Coding

NOTE To view the status color coding for an action, the action periodicity must be the same as the periodicity selected in the POV.

The Action card changes color depending on the action status:

Color Description

Blue

The action is waiting for validation, approved or in progress.

Gray

The action is on standby, rejected or aborted.

Green

The action is completed.

The Status progression synthesis card also uses the same color coding.

For more information on this card, see Status Progression Synthesis Card.

Alerts

Alerts inform you that there are one or several issues with your action.

NOTE Authorized users can attach one or several alerts to the action. See the Security Notes section above.

To attach an alert to the action:

  1. Select one of the boxes in the Alerts block of the action card:

    • Budget: The alert is related to the action budget.

    • Deadline: The alert is related to the action deadline.

    • Other: The alert is not related to the action budget or deadline. The alert is related to another reason.

    The Please leave a comment (required) pop-up panel appears.

  2. Enter a comment.

  3. Click Submit.

 

To view a comment, click the button.

To edit a comment:

  • Click the button.
