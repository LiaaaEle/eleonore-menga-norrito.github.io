CSR Insight New Features

What's New

The Strategy module has been improved:

  • Enrichment of strategy settings with the redesign of the screens for creating and editing strategy deployment levels.

 

As part of these developments, new screens have been developed:

  • Budget Definition: to provide information on budgets allocated to action plans

  • Detailed Financial Data for Actions by Entity

  • Summary of Contributions to MDRs: to automate the generation of regulatory reports with information relating to the strategies or policies implemented

 

Several screens are impacted by these changes:

  • Audit Trail of Targets

  • Action Reports

  • Generation of Regulatory Reports

  • Indicator Tracking: Formerly named Quantitative Target Definition, this screen has been redesigned to allow the user to define a trajectory using mechanisms to assist in entering quantitative targets.

 

Moreover, new languages has been added to the application's user preferences in the 2.12 version of the CSR Insight application: Portuguese and Italian.

 

Besides, other improvements have been made:

  • Possibility of import and export on the Choice List Management screen to facilitate the setting of choice lists, particularly in the context of the setting of indicators and links to ESRS

  • Improved filters on the Data Collection Campaigns screen to refine results on the screen

  • Direct access to a documentation portal from the application, screen by screen

 

Note that new user rights have been added to the Profile Matrix screen.

 

NOTE For more information, see the New Features page.
