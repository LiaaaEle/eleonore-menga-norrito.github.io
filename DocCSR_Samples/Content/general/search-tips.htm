Tips to Improve Search Results

Tip 1: Double Quotation Marks

Try enclosing search terms in double quotation marks. This is useful for restricting a search to locate terms that appear in a exact order.

For example, you might want to search for a phrase such as "data entry".

If you use the double quotation marks, you will get search results that contain the entire phrase in the exact order you entered it.

If you do not use the double quotation marks, you will get search results that contain "data", "entry", "data entry" and/or "entry data".

Tip 2: Search Filters

Display results based on a selected filter. Each filter narrows the search to documentation pages related to a specific module.

For example, you might want to search terms only related to the Carbon Footprint module.

By selecting the Carbon Footprint search filter, your search will only be carried out within the documentation pages related to the Carbon Footprint module.
