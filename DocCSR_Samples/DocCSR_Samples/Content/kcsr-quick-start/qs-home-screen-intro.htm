To access this screen, click Home.

Security Notes

Some actions, such as screen access, are permitted only for authorized users, that is, users with the appropriate profile. In other words, if the user does not have the right profile, the user cannot perform the action.

To configure this security (also called user rights), complete the following steps:

  1. Define the profiles in the Profile Management screen.

  2. Define users and attach one or more profiles to them in the User Management screen.

  3. Assign user rights to the desired profiles in the Profile Matrix screen.

The table below contains screen actions that are related to user rights:

After you log into the CSR Insight application, you can directly access the home screen.

To access the home screen from another screen, click the Home button in the top menu bar.

To help you navigate through your campaigns, strategies and their deployment levels (stakes, targets, actions) by entity, the home screen gives general information in different tabs. To do so, select the Entity in the point of view (POV).

For more details, several links are available to access the concerned screens.

NOTE You can only select the organizations included in the perimeter for which you are responsible.

To manage organizations, see the documentation on the Entity Management.

Then, to set up the access restrictions to organizations for each profile, see the documentation on the Profile Management.

Lastly, to set up the access restrictions to organizations for each user, see the documentation on the User Management.

Depending on your user rights, the home screen contains four or five tabs:

  • The Overview tab

  • The Campaign follow-up tab

  • The Performance tab

  • The Action Portfolio tab

  • The Resources tab
