Home Screen: Performance Tab

SEARCH TIP  Press CTRL + F (Windows and Linux) or CMD + F (Mac) to search within this page.

To access this screen, click Home.

NOTE This documentation presents you the Performance tab and its different features.

For more information on this screen, see the following documentations:

  • Home Screen: Introduction

  • Home Screen: Overview Tab

  • Home Screen: Campaign Follow-Up Tab

  • Home Screen: Action Portfolio Tab

  • Home Screen: Resources Tab

On the Performance tab, you can view the performance of the entity selected in the point of view (POV), based on the Strategy, the Year and the Deployment level of the strategy, selected from the drop-down-menus.

NOTE Each strategy can contain different deployment levels:

  • Stakes

  • For each stake, one or multiple targets level 1

  • For each target level 1, one or multiple targets level 2

  • For each target level 2, one or multiple actions


See the documentation on the Strategy Deployment.

For each deployment level, pinned to the home screen via the Strategy Deployment screen, you can view:

  • The value for the selected year, and for the two previous years

  • The variation in percentage between the values of the two previous years

  • The percentage progress for the selected year against the current year's target
