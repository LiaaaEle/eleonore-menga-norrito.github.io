To configure this security (also called user rights), complete the following steps:

  2. Define users and attach one or more profiles to them in the User Management screen.

Introduction

STEP BY STEP

Once the configuration of the carbon footprint is complete, perform an audit to check that no mandatory settings are missing and to verify that the configured data is correct.

 

After auditing the carbon footprint on this screen, you can carry out additional checks and verifications on other Reporting screens:

  • Analytical Reporting by Emission Factor

  • Details of Emission Posts by Entity

  • Emission Post Export

  • Carbon Footprint Assessment

 

Once you have completed all checks and verifications, you can proceed with publishing a regulatory carbon footprint. Export the data on the Carbon Footprint Assessment screen.

 

This screen enables you to audit a carbon footprint by year and entity. The audit process includes:

  • Tracking all calculations performed

  • Checking that all mandatory settings exist

  • Verifying the accuracy of these settings

 

More specifically, this screen contains all the information related to the version, emission category, emission factor, and the associated activity indicator. This screen alerts you when settings are missing or incorrect and then redirects you to relevant settings screens.

 

The data source of the carbon footprint can be:

  • The Published: Official and validated dataset

  • A proforma version: Adjusted or rectified data

  • A forecast: Projected future data

When data is available for the forecast but not for the emission factor in a given year, the emission factor values used will be those for the year closest in the past to the start year of the forecast.

 

Example:

  • Forecast data is entered from 2025 to 2030.

  • Emission factor values are available for 2025 and 2026, but not from 2027 to 2030.

  • Available values will be used when calculating emissions in 2025 and 2026.

  • As there is no value available from 2027 to 2030, values from the closest previous year will be used to calculate emissions for that period. In this case, the year 2026 will be referenced.

 

NOTE The Carbon Footprint Audit screen automatically recalculates carbon data with each refresh, while the Carbon Footprint Assessment screen displays results from the last user-initiated manual calculation.

Description of the Screen Content

After a quick reference, this section provides you with detailed information about each item of the point of view (POV) and each column in the table.

POV and Table Quick Reference

The items available for selection in the POV are:

  • Hierarchy

  • Entity

  • Year

  • Consolidation type

  • Version

  • View

  • Unit

  • Source

 

The columns displayed in the table are:

  • Version

  • Emission category

  • Emission factor

  • Activity indicator

 

Detailed descriptions of each POV item and table column follow below.

Description of the Items in the POV

The POV contains the following items:

Item Description

Hierarchy

Hierarchies correspond to different ways of organizing entities in relation to each other.

Example 1

A vision by parent entities and child entities (group, sibling entities at the regional level, sibling entities at the country level).

Example 2

A vision by product (product 1, product 2, product 3).

You can define hierarchies on the Hierarchy Management screen. Read also the Entity Management: Active Hierarchies Column documentation.

NOTE Hierarchies available for selection depend on access restrictions to alternative hierarchies defined in the profile attached to the user.

For more information, see Profile Management and User Management.

Entity

Entity on which the carbon footprint data is deployed.

You can only select entities included in the hierarchy selected in the POV.

Year

Year in which the carbon footprint data was collected (when data source is the Published), rectified (when data source is a proforma version), or forecasted (when data source is a forecast).

Consolidation type

Control mode associated with the emission factor and activity indicator:

  • Financial control, or

  • Operational control

NOTE For more information on control modes, read Financial and Operational Controls.

Version

Emission reporting formats, also called versions in the CSR Insight application, are the regulations on which the carbon footprint must be based:

  • BEGES V4, or

  • BEGES V5, or

  • GHG protocol

NOTE For more information on versions, read Emission Reporting Formats.

View

Data view mode:

  • Synthesis: Displays the total emissions, including all gases

  • Details: Displays the total emissions, including all gases, as well as the breakdown of emissions by gas, the CO2 avoided and the emission uncertainty

Unit

CO2e unit in which the carbon footprint data is displayed.

Source

Data source of the carbon footprint:

  • The Published, or

  • A proforma version, or

  • A forecast

Description of the Table Columns

The main table contains the following columns:

Column Description

Version

The "Version" column label depends on the version selected from the POV:

  • GHG Protocol, or

  • BEGES V4, or

  • BEGES V5

 

This column tells you if the emissions are bound to an emission post. If yes, you can find out to which one they are bound. Otherwise, Unaffected is displayed.

 

NOTE An emission corresponds to an emission category and sub-category.

To bind an emission to an emission post, go to the Regulatory Framework Management screen.

Emission category

Information related to the emission category in the unit selected from the POV.

 

When you select the Synthesis view mode, you can view the following information:

  • Emission category

  • Emission sub-category

  • Interco

  • Control mode

  • Total of emissions, all gases included

 

When you select the Details view mode, you can also view the following information:

  • Total of emissions for the emission category, gas by gas:

    • CO2

    • CH4

    • N2O

    • HFCs

    • PFCs

    • SF6

    • CO2 b

    • Others

  • Total of CO2 avoided

  • Total of Emission uncertainty

 

NOTE For more information on carbon footprint key concepts, read The Three Main Concepts and The Other Key Concepts.

Emission factor

Information related to the emission factor in the unit selected from the POV.

 

When you select the Synthesis view mode, you can view the following information:

  • EF category, that is the emission factor category

  • EF sub-category, that is the emission factor sub-category

  • Emission factor

  • Unit composed of two units: Numerator unit (the one selected in the POV) / Denominator unit (usually the same as the activity indicator unit)

  • Control mode

  • Total of E.F., that is the total of emissions for the emission factor, all gases included

  • Base: Location based or market based

  • Comment

 

When you select the Details view mode, you can also view the following information:

  • Total of emissions for the emission factor, gas by gas:

    • CO2

    • CH4

    • N2O

    • HFCs

    • PFCs

    • SF6

    • CO2 b

    • Others

  • Total of CO2 avoided

  • Total of EF uncertainty, that is the total of emission factor uncertainty

 

NOTE For more information on carbon footprint key concepts, read The Three Main Concepts and The Other Key Concepts.

Activity indicator

Information related to the activity indicator bound to the emission factor:

  • Activity indicator

  • Value and its Unit: total of data collected (when data source is the Published), rectified (when data source is a proforma version), or forecasted (when data source is a forecast)

  • Valorization, that is the valuation table value

  • Amortization period

  • Control mode

  • Indicator uncertainty

  • Year and Period on which data was collected (when data source is the Published), rectified (when data source is a proforma version), or forecasted (when the data source is a forecast)

  • Entity and Campaign on which the activity indicator is deployed

NOTE For more information on carbon footprint key concepts, read The Three Main Concepts and The Other Key Concepts.

The total of location-based emissions, market-based emissions, and emissions not bound to an emission post are separated into three small tables.

Identify Missing and Incorrect Settings

When required carbon footprint settings are missing, the screen displays an alert message above the table, as well as icons within the table.

 

There are two types of alerts:

  • An indicator is identified as being used in the Carbon Footprint on the Indicator Management screen but is not bound to an emission factor

  • No control mode is associated with the indicator

 

TIP  Locate alerts using sub-column filters. Select Empty as a filter for the Emission factor and/or Control sub-column (the one included in the Activity indicator column).

 

When emissions are not bound to an emission post, Unaffected is displayed in the Scope and Post sub-columns of the "Version" column.

 

To identify missing and incorrect carbon footprint values, select the Details view mode in the POV to verify data gas by gas.

Configure Missing Settings and Correct Incorrect Data

To configure missing settings and correct incorrect data, this screen redirects you to the relevant Administration screens:

  • Regulatory Framework Management to bind an emission to an emission post or update links

  • Emission Factor Valuation to enter or update emission factor values

  • Association of Emission Factors with Activity Indicators to bind an emission factor to an indicator or update links

  • Data Collection Campaigns to enter or update indicator information within campaigns

 

To be redirected to the desired screen, click the button located next to data you want to correct or for which settings are missing.

Example Scenario: Missing Emission Factor

What you see:

  • icon next to the Emission factor column

  • Alert message in tooltip: "An indicator is identified as being used in the carbon footprint. Click on the magnifying glass to associate it with an emission factor."

  • Empty cell in the Emission factor sub-column

 

What this means:

  • An activity indicator exists and has data, but the system cannot calculate emissions because no emission factor is bound to it.

 

How to fix:

  1. Click the button next to the alert.

    You are redirected to the Association of Emission Factors with Activity Indicators screen.

  2. Bind an emission factor to the activity indicator.

  3. Return to the audit screen and refresh.

  4. Verify the alert is resolved.
