Security Notes

Some actions, such as screen access, are permitted only for authorized users, that is, users with the appropriate profile. In other words, if the user does not have the right profile, the user cannot perform the action.

To configure this security (also called user rights), complete the following steps:

Introduction

 

NOTE The Generation of Regulatory Reportsscreen is currently used for mapping between CSRD standard and CSR Insight items. Therefore, the information provided by this documentation is related to the CSRD feature. For more information on this feature, see Corporate Sustainability Reporting Directive (CSRD).

This documentation provides you information on how to create custom data points and data parts not in the CSRD standard.

Related documentations:

  • Generation of Regulatory Reports: Introduction: Screen overview and navigation (read this first if you are new to this screen)

  • Generation of Regulatory Reports: Links: Connecting CSRD data points and data parts to your existing CSR Insight data

  • Generation of Regulatory Reports: Word Report: Generating and customizing your final CSRD report

 

The CSR Insight application provides you all mandatory and voluntary data points and data parts included in the CSRD standard.

You can create your own data points and data parts as needed. These are called specific data points and data parts.

In this documentation, you can learn how to manage specific data points and data parts, that is to carry out the following actions:

  • Create a Specific Data Point or Data Part

  • Update a Specific Data Point or Data Part

  • Import or Export Specific Data Points and Data Parts

 

To add, update, delete, import or export links, follow the same procedures as for data points and data parts. See Generation of Regulatory Reports: Links.

For each ESRS, you can view all your specific data points and data parts inside the DP_Specific section at the end of the nested grid.

Create a Specific Data Point or Data Part

As a specific data point or data part is not required by the standard, users can fully customize its code, label, and type.

 

To create a specific data point:

  1. Click the button at the top left of the nested grid.

    The Create a specific data point pop-up panel appears.

  2. Enter the specific data point code, as well as its label in all languages available in the CSR Insight application.

  3. Select the type of the specific data point from the Type drop-down menu: Quantitative, Narrative, or Semi narrative.

  4. Click OK.

 

To create a specific data part:

  1. Click the button at the end of the line for the specific data point in which you want to create a specific data part.

  2. Click Create a specific data part.

    The Create a specific data part pop-up panel appears with the Parent field automatically filled in.

  3. Enter the specific data part code, as well as its label in all languages available in the CSR Insight application.

  4. Select the type of specific data part from the Type drop-down menu: Quantitative, Narrative, or Semi narrative.

  5. Click OK.

Update a Specific Data Point or Data Part

To update a specific data point or data part:

  1. Click the button at the end of the line for the specific data point or data part you want to edit.

  2. Click Update specific data point or Update specific data part.

    The Update specific data point or Update specific data part pop-up panel appears.

  3. Edit information as needed.

  4. Click OK.

Import or Export Specific Data Points and Data Parts

NOTE Specific data points and data parts are in two different Excel files. These files do not contain links.

Data points and data parts provided by kShuttle are in another file. See Import or Export Links.

To export specific data points or data parts:

  1. Click the button at the top right of the nested grid.

  2. Click Export specific data points or Export specific data parts.

    An Excel is automatically downloaded on your computer.

 

To import specific data points or data parts:

  1. Export specific data points or data parts, as mentioned above.

  2. Open the exported Excel file.

  3. Fill in the Excel template, then save your data.

    NOTE To help you fill in the Excel template, see the Fill In the Excel Template appendix.

  4. In the CSR Insight application, click the button at the top right of the nested grid.

  5. Click Import specific data points or Import specific data parts.

    The Import specific data points or Import specific data parts pop-up window appears.

  6. Choose a file.

  7. Click OK.
