Security Notes

Some actions, such as screen access, are permitted only for authorized users, that is, users with the appropriate profile. In other words, if the user does not have the right profile, the user cannot perform the action.

To configure this security (also called user rights), complete the following steps:

  1. Define the profiles in the Profile Management screen.

  2. Define users and attach one or more profiles to them in the User Management screen.

  3. Assign user rights to the desired profiles in the Profile Matrix screen.

Introduction

Data extrapolation is used during data collection when data is not known but can be inferred using an extrapolation method selected in the Data Collection Campaigns screen.

You can track extrapolated data for a given campaign on the Extrapolated Data Follow-Up screen. Using this screen, you can also:

  • Convert Extrapolated Data into Final Data

  • Enter a New Value for the Final Data

  • Export Extrapolated Data

You can only access extrapolated data for indicators that are within your functional scope (assigned to your user profile).

To display extrapolated data for closed campaigns, select Yes from the Show closed campaigns drop-down menu in the point of view (POV).

Description of the Table Columns

The table contains the following columns:

Column Description

Entity

Entity on which the indicator is deployed.

Indicator

Indicator label.

Extrapolation method

Extrapolation method used for calculating the indicator value on the Data Collection Campaigns screen.

Five extrapolation methods are available. Four methods apply to both yearly and non-yearly campaigns, while the specific calculation basis differs between campaign types as detailed in the Extrapolation Methods section below.

Calcul

Details on the extrapolated value calculation:

  • If the extrapolation method is Previous year/period, the column displays the current year and the previous year/period.

  • If the extrapolation method is Average of previous years/periods, the column displays the calculation formula with the values used.

  • If the extrapolation method is Weighting/The weight of a reference indicator over a period of your choice, the column displays the reference indicator and period.

  • If the extrapolation method is Estimation, the column remains empty because no calculation formula applies; the value is user-estimated.

NOTE Calculation details are not stored in the CSR Insight application for data extrapolations performed on versions prior to version 2.7.

Value

Indicator value obtained by extrapolation.

Default unit

Default unit of extrapolated data.

Comment

Last comment entered for the indicator.

Workflow

Indicator status:

  • Not started: Data is not collected or calculated yet for this indicator by the authorized user.

  • Started: Data has been collected or calculated for this indicator by the authorized user.

  • Validated: Data has been validated for this indicator by the authorized user.

  • Closed: You can no longer enter or calculate data for this indicator.

NOTE Users with appropriate permissions can convert extrapolated data to final data when the indicator is in Not Started, Started, Validated, or Closed status. See Security Notes.

Color Coding

Extrapolated data rows are displayed from the most recent to the oldest.

The color coding for rows is as follows:

  • Gray: Indicator data has been converted to final data or manually edited.

  • White: Indicator data remains unconverted to final data or unedited.

Extrapolation Methods

For yearly campaigns:

  • Previous year: The indicator value is calculated based on the previous year value.

  • Average of previous years: The indicator value is calculated based on the average of the previous year values.

  • Weighting: The indicator value is calculated based on the weight of a reference indicator over a chosen period.

 

For non-yearly campaigns:

  • Same period of last year: The indicator value is calculated based on the last year value at the same period.

  • Previous period: The indicator value is calculated based on the previous period value.

  • Average of previous periods: The indicator value is calculated based on the average of the previous period values.

  • The weight of a reference indicator over a period of your choice: The indicator value is calculated based on the weight of a reference indicator over a chosen period.

 

For both campaign types:

  • Estimation: The indicator value is estimated. In other words, the user does not have a real value for an indicator, but can estimate this value.

Convert Extrapolated Data into Final Data

This section explains conversion impacts and describe how to convert extrapolated data into final data for a single entity or multiple entities.

Conversion Impacts

  • The indicator becomes editable in the Data Collection Campaigns screen, allowing you to replace the converted value with manually entered data.

    NOTE This applies only to open campaigns; closed campaigns cannot be edited.

  • The user who originally entered the extrapolated data receives an email notification.

    NOTE This email contains information on the indicator, the year, the period, and the campaign concerned. From this email, you can directly access the Extrapolated Data Follow-Up screen.

  • In the table, the row becomes gray.

Convert Extrapolated Data into Final Data for a Single Entity

To convert extrapolated data into final data for a single entity:

  1. Click the button at the end of the desired row.

    The Convert to final data pop-up window appears.

  2. Click OK.

Convert Extrapolated Data into Final Data for Multiple Entities

To convert extrapolated data into final data for multiple entities:

  1. Check the desired boxes to select one or more entities.

  2. Click the button.

    The Convert to final data pop-up window appears.

  3. Click Apply.

Enter a New Value for the Final Data

Entering a new value in the Data Collection Campaigns screen replaces the converted extrapolated value with user-provided data for the indicator.

To do so:

  1. Click the button at the end of the row of the desired converted extrapolated data.

    The Data Collection Campaigns screen appears.

  2. Enter a new value in the table view or in the survey view as instructed in the Enter the Indicator Value (table view) or Enter the Indicator Value (survey view) section.

Export Extrapolated Data

To export the currently displayed extrapolated data to an Excel file:

  1. Click the export button at the top left of the table.

    The Scripts pop-up window appears with a download link.

  2. Click the download link for the Excel file.
