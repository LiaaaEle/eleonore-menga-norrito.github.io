Introduction

NOTE The Generation of Regulatory Reports screen is currently used for mapping between the items required by the CSRD standard and the items available in the CSR Insight application. Therefore, the information provided by this documentation is related to the CSRD feature. For more information on this feature, see Corporate Sustainability Reporting Directive (CSRD).

This documentation explains how to connect CSRD data points and data parts to your existing CSR Insight data.

Related documentations:

  • Generation of Regulatory Reports: Introduction: Screen overview and navigation (read this first if you are new to this screen)

  • Generation of Regulatory Reports: Specific Data Points and Data Parts: Creating custom data points and data parts not in the CSRD standard

  • Generation of Regulatory Reports: Word Report: Generating and customizing your final CSRD report

Mapping between the items required by the CSRD standard and the items available in the CSR Insight application is carried out at the data point or data part level using links.

 

The CSR Insight items concerned are:

  • Indicators

  • Emission posts

  • Emissions

  • Scopes

  • Stakes, targets level 1, targets level 2, and/or actions

 

In this documentation, you can learn how to manage links, that is, how to carry out the following actions:

  • Add a Link

  • Update a Link

  • Delete a Link

  • Copy Links

  • Import or Export Links

Quick Reference

Quick Actions:

  • Add link: Three dots button (at end of the row) → Add a link

  • Update link: Three dots button (at end of the row) → Update link

  • Delete link: Three dots button (at end of the row) → Delete link

  • Copy to other years: Three dots (top right of grid) → Copy links

  • Import/Export: Three dots (top right of grid) → Export/Import links

Understanding Links

  • What is a link? A link connects CSRD-required data points to the actual data sources in the CSR Insight application where values are stored.

    Example: If the CSRD standard requires reporting "Absolute value of Scope 1 Greenhouse gas emissions reduction":

    • CSRD data point: E1.4_06 - Absolute value of Scope 1 Greenhouse gas emissions reduction

    • Link type: Scope

    • Data point source: Scope 1

    • Result: Your report automatically displays the actual Scope 1 emission value from the CSR Insight application.

  • Why link data points? Linking ensures your CSRD report automatically pulls correct, up-to-date values from your existing data. Without links, data points appear as "not linked" and generate empty fields in reports.

  • Link behavior:

    • Once linked, the data point retrieves its value from the specified source whenever you generate a report.

    • Changing a link affects future reports but does not modify historical data.

    • Each data point can have only one active link at a time.

Add a Link

A common procedure is used for CSR Insight items. A specific one for Strategy items.

Common Procedure

To add a link between a data point or data part and a CSR Insight item:

  1. Click the button at the end of a data point or data part row.

  2. Click Add a link.

    The Bind a data point pop-up panel appears.

  3. Select the CSR Insight item you want to link to your data point or data part from the Link to drop-down menu.

  4. Depending on the CSR Insight item selected, the fields you must select are different:

    NOTE Throughout this procedure, Vision refers to organizational hierarchies. For detailed information, see Entity Management: Active Hierarchies Column or Hierarchy Management.

    CSR Insight Item Required Fields

    Indicator

    • Hierarchy: Main or alternative hierarchy

    • Entity

    • Chapter

    • Theme

    • Section

    • Indicator to which you want to link the data point or data part

      NOTE The indicator unit is automatically displayed.

    • Data type: Actual or Target.

       

      NOTE To know what Actual and Target are, read one of the following documentations:

      • Details of Entities by Target
      • Details of Actions by Entity
      • Details of Entities by Action


      If you selected an alternative hierarchy, Data type automatically defaults to Actual because targets cannot be defined on alternative hierarchies.

       

    Emission post

    • Hierarchy: Main or alternative hierarchy

    • Entity

    • Version: Emission reporting format

    • Control type: Financial or operational control

    • Emission Scope

    • Emission post to which you want to link the data point or data part

    Emission

    • Hierarchy: Main or alternative hierarchy

    • Entity

    • Control type: Financial or operational control

    • Emission category

    • Emission sub-category to which you want to link the data point or data part

    Scope

    • Hierarchy: Main or alternative hierarchy

    • Entity

    • Version: Emission reporting format

    • Control type: Financial or operational control

    • Emission Scope to which you want to link the data point or data part

  5. Click OK.

NOTE To know more on carbon footprint key concepts, see the Carbon Footprint documentation.

Specific Procedure for Strategy Items

Strategy items (stakes, targets level 1, targets level 2, and actions) use a different linking process than other item types:

  1. When creating or editing a Strategy item through the Strategy Deployment or Action Reports screen, link it to one or multiple ESRS and enter summaries for each MDR that item contributes to.

  2. Edit or enter new summaries through the Summary of Contributions to MDRs screen.

    The CSR Insight application automatically creates the corresponding link on the Generation of Regulatory Reports screen.

    NOTE If a data point is already linked to a different item type (indicator, emission, and so on), the automatic Strategy link will not be created. You must first delete the existing link to allow the Strategy link.

Link Restrictions

  • Each data point or data part can have only one active link at a time.

  • If you create a new link on an already-linked data point, you must first delete or update the existing link.

Verify Your Links

After creating links, verify they work correctly:

  1. Check the Data point source column in the nested grid. It should display the linked item label and related information (such as data type, control type, or version).

  2. Generate a Word report for a single ESRS to test your links. See Generation of Regulatory Reports: Word Report.

  3. Review the report to confirm data appears correctly.

  4. If data is missing:

    • Linked item has data: Verify the linked item contains data for the selected year. If not, enter data before regenerating the report.

    • Entity matches scope: Check that the entity selected matches your reporting entity. Update the link if needed.

    • Hierarchy is correct: Confirm the vision (hierarchy) contains the correct entity structure. See Hierarchy Management documentation if needed.

Update a Link

Updating a link means changing its information or changing the link type.

 

To update a link between a data point or data part and a CSR Insight item:

  1. Click the button at the end of a data point or data part row .

  2. Click Update link.

    The Update link pop-up panel appears.

  3. Edit the information as desired.

  4. Click OK.

 

To update a link between a data point or data part and Strategy items, follow the same specific procedure as described in the section above.

The link will be automatically updated on the Generation of Regulatory Reports screen.

Delete a Link

WARNING Deleting a link removes the connection between the data point and its data source.

The data point will appear as "not linked" and will not populate with data in generated reports until you create a new link.

This action cannot be undone. Consider exporting your current link configuration as a backup before making bulk changes.

 

To delete a link between a data point or data part and a CSR Insight item:

  1. Click the button at the end of a data point or data part row.

  2. Click Delete link.

    The Delete link pop-up window appears to confirm the deletion.

  3. Click OK.

 

To delete a link between a data point or data part to Strategy items, you can either follow the above procedure or remove it when editing the Strategy items through the Strategy Deployment or Action Reports screen.

Copy Links

TIP  Use this feature to avoid manual repetitions and minimize errors.

To use this feature, you must have the Data point settings permission. See Security Notes above.

This copies all link configurations from one year to another, preserving the connections between data points and CSR Insight items.

 

To copy links:

  1. Click the button at the top right of the nested grid.

  2. Click Copy links.

    The Copy links pop-up window appears. The Source year and Entity fields are automatically filled with the point of view (POV) data.

  3. Select one or more Target years to which you want to copy the links.

  4. Click OK.

    The system checks for existing links in the target years:

    Scenario What Happens

    Target year has no existing links.

    All links copy automatically.

    Target year has some existing links.

    Overwrite pop-up window appears; choose to replace or keep existing links.

    NOTE "Existing links" means the target year already has data points or data parts linked to CSR Insight items.

Import or Export Links

NOTE The exported file contains links for data points and data parts included in the ESRS selected, as well as non-linked data points and data parts included in all ESRS.

Specific data points or data parts are in other files. See Import or Export Specific Data Points and Data Parts.

To export links:

  1. Click the button at the top right of the nested grid.

  2. Click Export links.

    The Export links pop-up window appears.

  3. Select one or multiple CSR Insight items from the drop-down menu to choose what type of links you want to export.

  4. Click OK.

    A download link appears.

  5. Click the download link for the Excel file.

    Your exported Excel file contains:

    • One sheet per selected item type (such as Indicator or Emission) with their current link configurations

    • Not linked sheet: Lists all data points without connections to CSR Insight data sources. Use this sheet to identify gaps in your CSRD mapping.

 

To import links:

  1. Export links, as mentioned above.

  2. Open the exported Excel file.

  3. Fill in the Excel template, then save your data.

    NOTE To help you fill in the Excel template, see the Fill In the Excel Template appendix.

  4. Back in the CSR Insight application, click the button at the top right of the nested grid.

  5. Click Import links.

    The Import links pop-up window appears.

  6. Select the Import mode:

    • Create and update (without deleting), or

    • Create, update, and delete

    NOTE For more details on these import modes, see the Things to Know Before Filling Out the Sheets sections in the Fill In the Excel Template appendix.

  7. Select one or multiple CSR Insight items from the drop-down menu to choose what type of links you want to import.

  8. Choose a file.

  9. Click OK.

Best Practices

Before Creating Links:

  • Review the CSRD requirements to understand which data points need linking.

  • Verify that your CSR Insight data sources (indicators, emissions, and so on) contain data for your reporting period.

  • Familiarize yourself with your entity hierarchy structure (vision).

When Creating Links:

  • Start with a small test set (one ESRS) before linking all data points.

  • Use consistent naming conventions if creating custom indicators.

  • Document any non-obvious linking decisions for your team.

After Creating Links:

  • Verify links immediately using the steps in the Verify Your Links section above.

  • Generate a test Word report for a single ESRS before proceeding to full reporting. See Generation of Regulatory Reports: Word Report.

  • Export your link configuration as a backup before making bulk changes.

Maintaining Links:

  • Export configurations regularly as a backup (monthly or before major changes).

  • Review the Not linked sheet when exporting to identify gaps.

  • Use the Copy Links feature for subsequent years rather than recreating manually.

  • Re-verify links after any system updates or data structure changes.
