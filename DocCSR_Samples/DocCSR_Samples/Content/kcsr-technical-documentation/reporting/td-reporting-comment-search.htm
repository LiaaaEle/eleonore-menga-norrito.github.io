Security Notes

Some actions, such as screen access, are permitted only for authorized users, that is, users with the appropriate profile. In other words, if the user does not have the right profile, the user cannot perform the action.

To configure this security (also called user rights), complete the following steps:

  1. Define the profiles in the Profile Management screen.

  2. Define users and attach one or more profiles to them in the User Management screen.

  3. Assign user rights to the desired profiles in the Profile Matrix screen.

Introduction

This screen allows you to search for one or more comments entered for indicators deployed within a campaign from the Data Collection Campaigns screen.

TIP  This feature helps you avoid searching campaign by campaign for the desired comment(s) in the Data Collection Campaigns screen, which is useful if you no longer remember where you entered a particular comment.

Search for a Comment for an Indicator

To search for a comment for an indicator:

  1. In the Comment Search dialog box, enter the keyword that you are searching for in the Keywords field.

    Search Rules

    • Enter at least one letter or number.

    • No case sensitivity.

    • No arithmetic operands allowed. Only letters or numbers.

    • Multiple keywords and spaces allowed.

  2. Click Submit.

    Search results will be displayed with the associated indicator details.

Access the Associated Data Collection Campaign

To access the associated data collection campaign, click the button available in the leftmost column of each indicator displayed in the search results.

 

For more details, see the Data Collection Campaigns screen.

Description of the Table Columns

The table contains the following columns:

Column Description

Year

Year in which the indicator data was collected.

Period

Period in which the indicator data was collected.

Chapter

Indicator chapter.

NOTE To learn more on chapters, see the Breakdown by Chapter and Theme documentation.

Theme

Indicator theme.

NOTE To learn more on themes, see the Breakdown by Chapter and Theme documentation.

Section

Indicator section.

NOTE To learn more on sections, see the Indicator Management documentation.

Indicator

Indicator label.

Entity

Entity for which the indicator data was collected.

NOTE To learn more on entities, see the Entity Management documentation.

Unit

Indicator input unit, that is, the unit of the data entered for the indicator on the Data Collection Campaigns screen.

Value

Indicator value.

Comment

Comment of the indicator that contains the searched keyword.
