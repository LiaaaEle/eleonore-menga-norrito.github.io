Security Notes

Some actions, such as screen access, are permitted only for authorized users, that is, users with the appropriate profile. In other words, if the user does not have the right profile, the user cannot perform the action.

To configure this security (also called user rights), complete the following steps:

  1. Define the profiles in the Profile Management screen.

  2. Define users and attach one or more profiles to them in the User Management screen.

  3. Assign user rights to the desired profiles in the Profile Matrix screen.

Introduction

NOTE The Generation of Regulatory Reports screen is currently used for mapping between the items required by the CSRD standard and the items available in the CSR Insight application. Therefore, the information provided by this documentation is related to the CSRD feature. For more information on this feature, see Corporate Sustainability Reporting Directive (CSRD).

This documentation provides you with an overview of the screen and explanations on how to search for a data point or data part (read this first if you are new to this screen).

Related documentations:

  • Generation of Regulatory Reports: Links: Connecting CSRD data points and data parts to your existing CSR Insight data

  • Generation of Regulatory Reports: Specific Data Points and Data Parts: Creating custom data points and data parts not in the CSRD standard

  • Generation of Regulatory Reports: Word Report: Generating and customizing your final CSRD report

On this screen, you can map the items required by the CSRD standard with the items available in the CSR Insight application, by year and organization, then generate a report in Word format. Mapping items is carried out using links.

The CSR Insight application provides you all mandatory and voluntary data points and data parts included in the CSRD standard.

You can create your own data points and data parts as needed. These are called specific data points and data parts.

Screen Overview

NOTE To know more on the mapping key concepts for the CSRD standard, see Corporate Sustainability Reporting Directive (CSRD).

The screen displays a nested grid that contains all data points, data parts, specific data points and data parts, included in the European Sustainability Reporting Standard (ESRS) you selected. To know how to select an ESRS, see Search by ESRS below.

This section contains the following subsections:

  • Description of the Nested Grid Columns

Description of the Nested Grid Columns

The nested grid contains the following columns:

Column Description

Data point code

Code used to identify the data point uniquely. No duplicates are allowed.

This code contains letters and/or numbers. No spaces or special characters are allowed.

Underscores, hyphens, and periods are allowed.

 

NOTE This code is internal to the application. It does not change even if regulations change.

 

Data point

List of all data points and data parts included in the ESRS you selected. These are classified by disclosure requirement.

Type

Type of data bound to the data point or data part:

  • Quantitative: Numerical data

  • Narrative: Textual data

  • Semi-narrative: Simple or multiple choice list data

Requirement

Requirement type for the data point or data part:

  • Mandatory: The data point or data part is required by the CSRD standard.

  • Voluntary: The data point or data part is not required by the CSRD standard but can be included voluntarily in your report.

  • Specific: The data point or data part is specific to your own needs.

Linked to

Type of CSR Insight item to which your data point or data part is linked:

  • Indicator

  • Emission Post

  • Emission

  • Scope

  • Strategy

NOTE Linking a data point or data part to a Strategy means linking it to the strategy items, that is stakes, targets level 1, targets level 2, and/or actions.

 

For example, linking a data point to an Indicator retrieves the actual value recorded for that indicator.

Indicator reference

Code used to identify the indicator uniquely. Only displayed when a data point or data part is linked to an indicator.

For other types of links, this column remains empty.

Data point source

Label of the CSR Insight item to which your data point or data part is linked, and in parentheses information that depends on the item type:

  • Data type if the item type is Indicator: Actual or Target

     

    NOTE To know what Actuals and Targets are, read one of the following documentations:

    • Details of Entities by Target
    • Details of Actions by Entity
    • Details of Entities by Action

     

  • Control type if the item type is Emission or Emission Post

  • Control type and version if the item type is Scope

 

If the item type is Strategy, you can view the number of strategy items that contribute to MDRs, and then their labels if you hover over this number. Click the number to access the Summary of Contributions to MDRs screen.

Hierarchy

Hierarchy that contains the entity from which the CSR Insight item value is retrieved.

By default, main hierarchy. You can select an alternative hierarchy when linking a data point, data part, specific data point, or specific data part to a CSR Insight item. See Generation of Regulatory Reports: Links.

If you choose an alternative hierarchy, the Word report will retrieve consolidated data.

NOTE To know more on hierarchies, see Entity Management: Active Hierarchies Column or Hierarchy Management.

Entity

Entity from which the CSR Insight item value is retrieved.

Display or Hide Content

By default, you can view all data points and data parts included in the ESRS 2 General disclosure. To view data points and data parts included in another ESRS, see Search by ESRS below.

Moreover, by default, all columns are displayed.

Display or Hide Rows

To hide data points contained in one or more disclosure requirements, click the button located at the end of disclosure requirement rows. To display these data points again, click the button.

 

To hide data parts contained in one or more data points, click the gray row of the data point. To display these data parts again, click the gray row of the data point again.

Display or Hide Columns

You can display or hide one or more columns except the Data point and Type columns.

 

To hide columns:

  1. Click the Show columns drop-down menu next to the search box.

  2. Uncheck one or more boxes to hide the desired columns.

    NOTE You can also click Hide all to hide all columns.

 

To display columns:

  1. Click the Show columns drop-down menu next to the search box.

  2. Check one or more boxes to display the desired columns.

    NOTE You can also click Show all to display all columns.

Resize Columns

To resize a column, click and drag the bottom right corner of the column label, that is the button, to the right to enlarge the column or to the left to shrink the column.

Search for a Data Point or Data Part

To search for a data point or data part:

  1. Fist: Select your ESRS.

  2. Then: Use search box or filters to narrow results.

Search by ESRS

To search for a data point or data part, you need first to select the ESRS, to which this data point or data part is connected, from the drop-down menu next to the search box.

Search Through the Search Box

The search box allows you to do a global search over the entire nested grid.

To search using the search box, type one or more letters or keywords.

As you type, the nested grid content changes, and the letters or keywords are displayed in bold and highlighted in yellow.

Filter Columns

To search for a data point or data part, you can filter one or more columns. To do so:

  1. Click the button next to the label of the column you want to filter.

    A drop-down menu appears.

  2. Check one ore more boxes.

    As you check, the nested grid content changes.

 

To reset filters, click the button at the end of the header row.
