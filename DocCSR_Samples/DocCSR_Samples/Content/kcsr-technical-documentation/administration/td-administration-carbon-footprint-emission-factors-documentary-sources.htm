Security Notes

Some actions, such as screen access, are permitted only for authorized users, that is, users with the appropriate profile. In other words, if the user does not have the right profile, the user cannot perform the action.

To configure this security (also called user rights), complete the following steps:

  1. Define the profiles in the Profile Management screen.

  2. Define users and attach one or more profiles to them in the User Management screen.

  3. Assign user rights to the desired profiles in the Profile Matrix screen.

Introduction

A documentary source is an organization from which you can collect regulatory information to set up your carbon footprint. This is the source that you can use to create the emission factor.

On this screen, you can view and manage all the documentary sources of emission factors.

NOTE To set up your carbon footprint, this screen is optional.

For more information on the process of setting up the carbon footprint, see the Carry Out your Carbon Footprint section in the Carbon Footprint documentation.

WARNING Only a supervisor administrator (also called an administrator with GS rights, that is a user with all user rights) can create, edit and delete the AIE (Agence Internationale de l’Energie) or IEA (International Energy Agency) source.

Add a Documentary Source

To add a documentary source:

  1. Click the button at the top left of the screen.

    The Create pop-up panel appears.

  2. Enter the FR Label and the EN Label.

  3. Click Submit.

    A new line appears in the table.

  4. Click the button at the top right of the screen.

Delete a Documentary Source

To delete a documentary source:

  1. Click the button at the end of the line for the documentary source you want to delete.

    A pop-up window appears to confirm the deletion.

  2. Click Yes.

Search for a Documentary Source

To search for a documentary source:

  1. Click the at the top of the table.

  2. Type one or more letters or keywords.

    As you type, the list of documentary sources changes.

Import or Export Documentary Sources

To export documentary sources:

  1. Hover over the button at the top right of the screen.

    The Scripts pop-up window appears with a download link.

  2. Click the download link for the Excel file.

To import documentary sources:

  1. Export the documentary sources, as mentioned above.

  2. Open the exported Excel file.

  3. Fill in the Excel template, then save your data.

    NOTE To help you fill in the Excel template, see the Fill In the Excel template appendix.

  4. In the CSR Insight application, hover over the button at the top right of the screen.

    The Import documentary sources pop-up window appears.

  5. Choose a file.

  6. Click OK.
