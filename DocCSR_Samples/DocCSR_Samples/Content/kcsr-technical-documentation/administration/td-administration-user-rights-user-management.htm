Security Notes

Some actions, for example screen access, are allowed to authorized users, that is users with the right profile. In other words, if the user does not have the right profile, the user cannot perform the action.

To set up this security (also called user rights):

  1. Define the profiles in the Profile Management screen.

  2. Define users, and attach one or several profiles to them, in the User Management screen (this documentation).

  3. Assign user rights to the desired profiles in the Profile Matrix screen.

Introduction

STEP BY STEP

Defining users and attach profiles on this screen is the second step in setting up user rights in the CSR Insight application.

Previous step is defining profiles on the Profile Management screen.

Next step is assigning user rights to profiles on the Profile Matrix screen.

This screen allows you to create and view the different users of the application and their associated profiles. First, create a user, then attach one or multiple profiles to this user.

 

The table displays user information: logins, first names, names, emails, languages, login methodologies, last connection date, and the number of profiles.

 

When attaching a profile to a user, restricted accesses defined for this profile are applied to the user. These accesses are then further restricted to only one entity and functional scope at the user level.

 

Depending on the restricted accesses applied, selectable items in the point of view (POV) on Data Entry and Reporting screens, such as campaign, entity, hierarchy, or indicator, are different.

 

Note that you can access the content of a functional scope from this screen.

Description of the Table Columns

The table contains the following columns:

Column Description

Login

Login used by the user to log in the CSR Insight application.

No duplicates are allowed. Commonly called username.

First name

First name of the user.

Name

Last name of the user.

Email

Email used by the user to log in the CSR Insight application.

No duplicates are allowed.

Language

Default language used by the user in the CSR Insight application.

Login method

Login method used by the user to log in the CSR Insight application:

  • FusionAuth, or

  • SSO

Last connection date

Date the user last logged into the CSR Insight application.

Number of profiles

Number of profiles attached to the user.

Create a User

To create a new user:

  1. Click the button at the top left of the table.

    The Create a user pop-up panel appears.

  2. Enter the login, the first name, the name, the email, and the language.

  3. Optional: Select the login methodology (SSO or Extern).

  4. Click OK.

Update a User

To update a user:

  1. Click the button at the beginning of the concerned line.

    The Update a user pop-up panel appears.

  2. Enter the new information.

  3. Click OK.

NOTE To edit the login and the email, you need to delete the user, then create a new one.

Delete a User

To delete a user:

  1. Click the button at the beginning of the concerned line.

    The Delete this user pop-up window appears to confirm the deletion.

  2. Click OK.

NOTE You cannot delete users associated with one or more profiles.

Attach Profiles to a User

To access the different types of profiles for a user, click the button at the beginning of the concerned line.

A pop-up panel appears at the bottom of the screen.

Add a Profile

To add a new profile for a user:

  1. Click the button at the top left of the table.

    The Add profile pop-up panel appears.

  2. Select the desired profile.

  3. If restricted access to entities or functional scopes is defined for the profile, on the Profile Management screen, select the Entity and/or the Scope you want the user to access.

    NOTE You can only access active entities, as defined on the Indicator Management screen.

    If the profile can only access specific alternative hierarchies, only the entities included in those alternative hierarchies can be selected from the Entity drop-down menu.

  4. Click OK.

NOTE Depending on the organization and functional scope the user has access to, the selectable items in the point of view (POV) through the CSR Insight application, such as the campaign, the organization, or the indicator, are different.

To learn more, consult the Security Notes.

Update a Profile

To update a profile:

  1. Click the button at the beginning of the concerned line.

    The Update a profile pop-up panel appears.

  2. Select the desired new profile.

  3. Click OK.

Delete a Profile

To delete a profile:

  1. Click the button at the beginning of the concerned line.

    The Delete this profile pop-up window appears to confirm the deletion.

  2. Click OK.

Access Functional Scope Indicators

When a profile is associated with a specific functional scope, you can access the indicator list for this functional scope. To do so:

  1. Click right on the Scope cell corresponding to the desired functional scope.

  2. Click the See functional scope indicators option from the drop-down menu.

    The Scope Indicators screen opens in a new tab.

Copy the Profiles from One User to Other Users

To copy the profiles from one user to other users:

  1. Click the button.

    The Copy user rights pop-up panel appears.

  2. Select from the drop-down menus:

    • The Source user: The user whose profile you want to copy

    • The Target user(s): The users you want to paste the profile to

  3. Click OK.

Import or Export Users or User Profiles

You can:

  • Import or Export Users

  • Import or Export User Profiles

Import or Export Users

To export users:

  1. Click the button at the top left of the screen.

    The Export users / user rights pop-up window appears with a download link.

  2. Click Users as Export type, then OK.

  3. Click the download link for the Excel file that appears.

 

To import users:

  1. Export the users as mentioned above.

  2. Open the exported Excel file.

  3. Fill in the Excel template, then save your data.

    NOTE To help you fill in the Excel template, see the Fill In the Excel Template appendix.

  4. Back to the CSR Insight application, click the button at the top left of the screen.

    The Import users / user rights pop-up window appears.

  5. Click Import users as Import type.

  6. Choose a file.

  7. Click OK.

Import or Export User Profiles

To export user profiles:

  1. Click the button at the top left of the screen.

    The Export users / user rights pop-up window appears with a download link.

  2. Click Access rights as Export type, then OK.

  3. Click the download link for the Excel file that appears.

 

To import user profiles:

  1. Export the user profiles as mentioned above.

  2. Open the exported Excel file.

  3. Fill in the Excel template, then save your data.

    NOTE To help you fill in the Excel template, see the Fill In the Excel Template appendix.

  4. Back to the CSR Insight application, click the button at the top left of the screen.

    The Import users / user rights pop-up window appears.

  5. Click Import access rights as Import type.

  6. Choose a file.

  7. Click OK.
