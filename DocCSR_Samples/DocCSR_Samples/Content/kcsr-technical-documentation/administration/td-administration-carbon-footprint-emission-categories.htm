Security Notes

Some actions, such as screen access, are permitted only for authorized users, that is, users with the appropriate profile. In other words, if the user does not have the right profile, the user cannot perform the action.

To configure this security (also called user rights), complete the following steps:

  1. Define the profiles in the Profile Management screen.

  2. Define users and attach one or more profiles to them in the User Management screen.

  3. Assign user rights to the desired profiles in the Profile Matrix screen.

Introduction

This screen allows you to view and manage emission categories and sub-categories.

Description of the Table Columns

The table contains the following columns:

Column Description

Hierarchy

This column displays all the emission categories and sub-categories in a nested grid.

The chip next to the label of the emission category indicates the number of emission sub-categories inside the category.

To view all the emission sub-categories, click the button next to the label of the emission category.

To hide all the emission sub-categories, click the button next to the label of the emission category.

Labels

In this column, there are two sub-columns:

  • Label FR: The French label of the emission category or sub-category.

  • Label EN: The English label of the emission category or sub-category.

Create an Emission Category and Sub-Category

To create an emission category:

  1. Click the button next to the Hierarchy column label.

    The Add a category pop-up panel appears.

  2. Enter the French and English labels.

  3. Click OK.

    A new emission category appears in the Hierarchy column.

To create an emission sub-category:

  1. Right-click on the label of the emission category for which you want to add an emission sub-category.

  2. Click Create a sub category of emission.

    The Create sub-category pop-up panel appears with the Parent field automatically filled in.

  3. Enter the French label in the first input box.

  4. Enter the English label in the second input box.

  5. Click Save.

    A new emission sub-category appears in the Hierarchy column just below the corresponding emission category.

Move an Emission Sub-Category

You can rearrange the emission sub-categories within a category, or move a sub-category from one category to another.

To move an emission sub-category, drag-and-drop the line of the emission sub-category you want to move.

Edit an Emission Category or Sub-Category

To edit the labels of the emission category or sub-category:

  1. Double-click the desired label in the Label FR or Label EN sub-columns.

  2. Enter the new label.

  3. Click the Enter key.

  4. Click the button at the top right of the screen.

Delete an Emission Category or Sub-Category

NOTE You can only delete emission categories without emission sub-categories.

To delete an emission category or sub-category:

  1. Right-click on the label of the emission category or sub-category you want to delete.

  2. Click Delete the emission category or Delete the emission sub-category.

    A pop-up window appears to confirm the deletion.

  3. Click Validate.

    The desired emission category or sub-category is deleted.

Search for an Emission Category or Sub-Category

To search for an emission category or sub-category:

  1. Click the button at the top of the table.

  2. Type one or more letters or keywords.

    As you type, chips appears next to the label of the emission categories. The number indicates the result number in the category.

Import or Export an Emission Category and Sub-Category

To export emission categories and sub-categories:

  1. Click the button at the top right of the screen.

  2. Click Export data.

    The Export data pop-up window appears with a download link.

  3. Click the download link to download the Excel file.

To import emission categories and sub-categories:

  1. Export the emission categories and sub-categories as mentioned above.

  2. Open the exported Excel file.

  3. Fill in the Excel template, then save your data.

    NOTE To help you fill in the Excel template, see the Fill In the Excel template appendix.

  4. In the CSR Insight application, hover over the button at the top right of the screen.

  5. Click Import data.

    The Import data pop-up windows appears.

  6. Choose a file.

  7. Click OK.
