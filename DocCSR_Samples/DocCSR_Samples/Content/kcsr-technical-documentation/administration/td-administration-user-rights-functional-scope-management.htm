Security Notes

Some actions, such as screen access, are permitted only for authorized users, that is, users with the appropriate profile. In other words, if the user does not have the right profile, the user cannot perform the action.

To configure this security (also called user rights), complete the following steps:

  1. Define the profiles in the Profile Management screen.

  2. Define users and attach one or more profiles to them in the User Management screen.

  3. Assign user rights to the desired profiles in the Profile Matrix screen.

The table below contains screen actions that are related to user rights:

Module Screen Action

User rights management

Functional scope management

Screen access

Access indicator settings

This screen allows you to manage functional scopes.

A functional scope is a grouping of indicators, which contains one or multiple indicators for which users are responsible.

You can only access to the indicators of the functional scope for which you are responsible. Therefore, depending on the functional scope, the selectable items in the point of view (POV) through the CSR Insight application, such as the campaign, the organization, or the indicator, are different.

NOTE To set up the access restrictions to functional scopes for each profile, see the documentation on the Profile Management.

Then, to set up the access restrictions to functional scopes for each user, see the documentation on the User Management.

For more details, see the Security Notes.

Create a Functional Scope

To create a new functional scope:

  1. Click the button at the top left of the table.

    The Create a functional scope pop-up panel appears.

  2. Enter the label in all available languages.

  3. Optional: Enter the description in all available languages.

  4. Click OK.

Update a Functional Scope

To update a functional scope:

  1. Click the button at the beginning of the concerned line.

    The Update a functional scope pop-up panel appears.

  2. Enter the new information.

  3. Click OK.

Delete a Functional Scope

To delete a functional scope:

  1. Click the button at the beginning of the concerned line.

    The Delete this functional scope pop-up window appears to confirm the deletion.

  2. Click OK.

Import or Export Functional Scopes or Functional Scope Indicators

You can:

  • Import or Export Functional Scopes

  • Import or Export Functional Scope Indicators

Import or Export Functional Scopes

To export functional scopes:

  1. Click the button at the top left of the screen.

    The Export functional scopes / functional scope indicators pop-up window appears with a download link.

  2. Click Functional scopes as Export type, then OK.

  3. Click the download link for the Excel file that appears.

 

To import functional scopes:

  1. Export the functional scopes as mentioned above.

  2. Open the exported Excel file.

  3. Fill in the Excel template, then save your data.

    NOTE To help you fill in the Excel template, see the Fill In the Excel Template appendix.

  4. Back to the CSR Insight application, click the button at the top left of the screen.

    The Import functional scopes / functional scope indicators pop-up window appears.

  5. Click Functional scopes as Import type.

  6. Choose a file.

  7. Click OK.

Import or Export Functional Scope Indicators

To export indicators in a functional scope:

  1. Click the button at the top left of the screen.

    The Export functional scopes / functional scope indicators pop-up window appears with a download link.

  2. Click Functional scope indicators as Export type, then OK.

  3. Click the download link for the Excel file that appears.

 

To import indicators in a functional scope:

  1. Export the indicators, as mentioned above.

  2. Open the exported Excel file.

  3. Fill in the Excel template, then save your data.

  4. Back to the CSR Insight application, click the button at the top left of the screen.

    The Import functional scopes / functional scope indicators pop-up window appears.

  5. Click Functional scope indicators as Import type.

  6. Select the import mode:

    • Create and update (without deleting): if you want to add new data without deleting the existing data in the CSR Insight

    • Create, update, and delete: if you want to delete existing data, that is, overwrite or clear the data in the CSR Insight application

  7. Choose a file.

  8. Click OK.
