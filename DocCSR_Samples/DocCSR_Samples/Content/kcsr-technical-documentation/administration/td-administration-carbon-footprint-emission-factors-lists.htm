Security Notes

Some actions, such as screen access, are permitted only for authorized users, that is, users with the appropriate profile. In other words, if the user does not have the right profile, the user cannot perform the action.

To configure this security (also called user rights), complete the following steps:

  1. Define the profiles in the Profile Management screen.

  2. Define users and attach one or more profiles to them in the User Management screen.

  3. Assign user rights to the desired profiles in the Profile Matrix screen.

Introduction

This screen allows you to manage emission factors.

More precisely, you can:

  • Create, edit, and delete emission factors

  • Enable and disable emission factors

  • Import or delete a file for an emission factor

  • Import or export emission factors

Description of the Table Columns

The table contains the following columns:

Column Description

EF category

The name of the emission factor (EF) category.

NOTE To manage emission factor categories, see the Management of Emission Factor Categories documentation.

EF sub-category

The name of the emission factor (EF) sub-category.

NOTE To manage emission factor sub-categories, see the Management of Emission Factor Categories documentation.

EF code

Code used to identify the emission factor (EF) uniquely. No duplicates are allowed.

No spaces nor arithmetic operands are allowed.

Underscore is allowed.

This code is especially used in the calculation formulas of the carbon footprint.

This code contains letters and/or numbers.

Emission factor

The emission factor name.

Numerator unit

The emission category unit, also called CO2e unit, used in numerator for the emission factor.

Denominator unit

The unit used in denominator for the emission factor.

NOTE When binding an emission factor to an activity indicator on the Association of Emission Factors with Activity Indicators screen, the denominator unit of the emission factor and the activity indicator unit must be the same.

Base

NOTE For BEGES V4 and BEGES V5, the required calculation method is Location based.

For GHG protocol, you can choose between the Location based and Market based calculation methods, or use both.

Calculation method of scope 2 emissions associated with the emission factor:

  • Location based, or

  • Market based

By default, if the cell is empty, the calculation method will be Location based.

For more information on scopes and scope 2 calculation methods, see the following sections in the Carbon Footprint documentation:

  • Emission Reporting Formats

  • Location Based and Market Based

Emission category

The name of the emission category.

NOTE To manage emission categories, see the Management of Emission Categories documentation.

Emission sub-category

The name of the emission sub-category.

NOTE To manage emission sub-categories, see the Management of Emission Categories documentation.

Import file

In this column, you can import or delete a File.

Active

This column informs you if the emission factor is active or not, that is if the emission factor is used or not in your carbon footprint.

For more information, see the Enable or Disable an Emission Factor section below.

Create an Emission Factor

NOTE An emission factor can be linked to only one emission factor category and sub-category. Therefore, no label duplicates are allowed for emission factors.

An emission category and sub-category can contain multiple emission factors. Therefore, duplicates are allowed for emission categories and sub-categories.

To create an emission factor:

  1. Click the button at the top left of the table.

    The Add an emission factor pop-up panel appears.

  2. Enter the Code and the label in all available languages for the emission factor.

  3. Select from the drop-down menus:

    • The EF category

    • The EF sub-category

    • The Emission category

    • The Emission sub-category

    • The Numerator unit and Denominator unit of the emission factor

       

      NOTE On this screen, the emission factor unit is displayed into two parts to ensure consistency of emission factor units, and between emission factor units and activity indicators units: Numerator unit and Denominator unit.

      On the Emission Factor Valuation screen and on the Reporting screens dedicated to carbon footprint, you will view a single unit composed of the numerator and denominator units.

      When binding an emission factor to an activity indicator on the Association of Emission Factors with Activity Indicators screen, it is recommended to have the same unit for the activity indicator and the denominator unit of the emission factor unit.

       

    • The Base of the emission factor: Location Based, Market Based, or blank.

      NOTE For BEGES V4 and BEGES V5, the required calculation base is Location based.

      For GHG protocol, you can choose between the Location based and Market based calculation methods.

      If you select the blank option, the calculation method will be Location based by default.

  4. Click OK.

    A new emission factor line is added to the table.

Update an Emission Factor

To update an emission factor:

  1. Click the button at the beginning of the line of the emission factor you want to edit.

    The Update an emission factor pop-up panel appears.

  2. Edit the information as desired.

  3. Click OK.

    The emission factor is edited.

 

To only edit the base of your emission factor:

  1. Click the cell in the Base column.

    The Select the base pop-up window appears.

  2. Select the base from the drop-down menu:

    • Location based, or

    • Marked based, or

    • Blank

  3. Click OK.

Delete an Emission Factor

You can delete emission factors if not used.

To delete an emission factor:

  1. Click the button at the beginning of the line of the emission factor you want to delete.

    The Delete EF pop-up window appears to confirm the deletion.

  2. Click OK.

    The emission factor is deleted.

Enable or Disable an Emission Factor

When disabled, the emission factor is not visible in the Emission Factor Valuation screen.

 

By default, the newly created emission factor is active.

 

To disable the emission factor, click the button.

The Enable/Disable an emission factor pop-up windows appears to confirm the deactivation.

 

To reactivate the emission factor, click the button.

The Enable/Disable an emission factor pop-up windows appears to confirm the reactivation.

Import or Delete a File

To import a file:

  1. Click the button.

    The Import file pop-up windows appears.

  2. Choose a file.

  3. Click OK.

    A file is imported into the table.

 

To delete an imported file, click the button.

The imported file is automatically deleted.

Import or Export an Emission Factor

To export emission factors:

  1. Click the button at the top left of the screen.

    The Export emission factors pop-up window appears with a download link.

  2. Click the download link for the Excel file.

 

To import emission factors:

  1. Export the emission factors as mentioned above.

  2. Open the exported Excel file.

  3. Fill in the Excel template, then save your data.

    NOTE To help you fill in the Excel template, see the Fill In the Excel Template appendix.

  4. Back to the CSR Insight application, click the button at the top left of the screen.

    The Import emission factors pop-up windows appears.

  5. Choose a file.

  6. Click OK.

View the Emission Factor Use

You can see where the emission factor is used, that is, have access to the following screens:

  • Analytical Restitution by Emission Factor

  • Emission Factor Valuation

  • Association of Emission Factors with Activity Indicators

To do that, click the button, then the name of the screen you want to go to.
