Introduction

The Proforma feature records all changes to historical data over time. As part of this feature, the Proforma Version Management screen enables you to manage proforma versions for tracking these data changes. Using this screen, you can:

  • Create, update, and delete proforma versions for the year selected in the point of view (POV)

    NOTE You can only select years for which data collection campaigns are deployed.

  • Close a Proforma Version

  • Calculate All Proforma Restatements, also called effects or corrections

  • Update the Reference Version Data

  • Export Proforma Versions

STEP BY STEP

This screen is the first step of the proforma configuration process:

  1. Current step: Create proforma versions.

  2. Optional step: View emission factor variations on the Variation of Emission Factors screen to support your proforma configuration.

  3. Next step: Configure restatements in other Proforma screens.

 

For the complete workflow, see Carry Out your Proforma in the Proforma documentation.

Description of the Table Columns

The table contains the following columns:

Column Description

Proforma versions

Proforma version label.

Reference version

Set of baseline data used to calculate restatements within a proforma version.

 

The reference version contains either:

  • Published data (default option)

  • Proforma data

 

After creating your first proforma version, you can select it as the reference version for subsequent versions.

Created on

Date on which the proforma version has been created.

Created by

User who created the proforma version.

Inflation

Indicates whether the proforma version applies inflation adjustments to calculations:

  • Enabled: Inflation effects are included in proforma calculations; requires selecting an Inflation target year

  • Disabled: No inflation adjustments are applied

Values on reporting screens vary based on this setting.

Target year

Year up to which inflation rates will be applied.

 

Example: For a proforma created in 2024 with target year 2026:

  • 2024 inflation rate applies to 2024 data.

  • 2025 inflation rate applies to 2025 data.

  • 2026 inflation rate applies to 2026 data.

 

Inflation rates are configured on the Inflation Effect Settings screen.

Status

Proforma version status:

  • Opened: The proforma version is editable. You can modify settings and recalculate restatements.

  • Closed: The proforma version is read-only. No modifications are permitted, but the version can still be deleted.

 

New proforma versions are created with status Opened by default. See Close a Proforma Version for closure procedures.

Comment

Comment on the proforma version.

Create a Proforma Version

NOTE Prerequisite: Ensure a data collection campaign is deployed for your target year.

To create a proforma version:

  1. Click the button at the top left of the table.

    The Add a proforma pop-up panel appears.

  2. Enter the proforma version label in all available languages.

  3. Select the Reference version.

    NOTE For your first proforma version, Published is automatically selected.

  4. Choose whether to enable inflation from the Inflation drop-down menu.

  5. If inflation is enabled, select the Inflation target year.

    NOTE Only years with configured inflation rates (set on the Inflation Effect Settings screen) are available for selection.

  6. Optional: Enter a comment.

  7. Click OK.

    The proforma version is created with status Opened and appears in the table.

Update a Proforma Version

NOTE Important constraints:

  • You cannot modify the reference version after creation. To use a different reference version, create a new proforma version.
  • If you enable or disable inflation, you must recalculate proforma restatements (see Calculate All Proforma Restatements).

To update a proforma version:

  1. Click the button at the beginning of the corresponding row.

    The Update a proforma pop-up panel appears.

  2. Modify the desired information.

  3. Click OK.

Delete a Proforma Version

To delete a proforma version, whether it is open or closed:

  1. Click the button at the beginning of the corresponding row.

    The Delete a proforma pop-up window appears to confirm the deletion.

  2. Click OK.

Close a Proforma Version

Impact of closing: Once closed, the proforma version and its restatements become read-only:

  • No editing on this screen or related setting screens

  • Cannot calculate proforma restatements in reporting or setting screens

  • Can still be deleted if needed

NOTE Closing automatically recalculates all proforma restatements.

 

To close a proforma version:

  1. Click the button at the beginning of the corresponding row.

    The Close a proforma pop-up window appears to confirm the closure.

  2. Click OK.

    The proforma version status changes to Closed.

Calculate All Proforma Restatements

To recalculate all proforma restatements and ensure the latest changes are reflected:

  1. Click the button at the beginning of the corresponding row.

    The Calculate the proforma effects pop-up window appears.

  2. Click OK.

    All proforma restatements are recalculated and the proforma version data is up to date.

Update the Reference Version Data

Use this function when the source data in your reference version has changed and you need to refresh the proforma calculations.

To update the reference version data:

  1. Click the button at the beginning of the corresponding row.

    The Update reference data pop-up window appears.

  2. Click OK.

    The reference version data is synchronized and the proforma version reflects the latest source data.

Export Proforma Versions

Export proforma version data to Excel for external analysis or record-keeping.

To export proforma versions: Click the button in the toolbar at the top right of the screen.

An Excel file containing all proforma versions for the selected POV year downloads automatically to your computer.
