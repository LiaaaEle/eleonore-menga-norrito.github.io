Introduction

Emission factors are coefficients used to convert activity data into emissions in CO2e. They are classified into a two-level hierarchy of categories and sub-categories, organizing emission factors by type and source of activities. Proper categorization ensures accurate data collection and reporting.

The Management of Emission Factor Categories enables you to view and manage these categories and sub-categories.

STEP BY STEP

This screen is part of the carbon footprint configuration process:

  1. Current step: Create emission factor categories and sub-categories.

  2. Next step: Create emission categories in the Management of Emission Categories screen.

  3. Then: Bind emission factor categories to emission categories in the Emission Factor List screen to create emission factors.

  4. Optional step: Define control modes for indicators in campaigns using the Data Collection Campaigns screen.

    NOTE The control modes you define in this screen determine the available options during data collection. For more information, see the Control modes column description.

 

For the complete workflow, see Carry Out your Carbon Footprint in the Carbon Footprint documentation.
Quick Reference

  • To create a category: Click next to Hierarchy → Enter labels → Select controls → OK

  • To create a sub-category: Right-click category → Create sub-category → Enter labels → Save

  • To edit labels: Double-click label → Edit → Enter → Click Save button

  • To move sub-category: Drag and drop to new position

  • To delete: Right-click → Delete → Validate (must meet deletion prerequisites)

  • To search: Click → Type keywords

  • To export: Hover over → Export data → Click download link

  • To import: Hover over → Import data → Choose file → OK

Description of the Table Columns

The table contains the following columns:

Column Description

Hierarchy

Emission factors are classified into a two-level hierarchy:

  • Categories (parent level): Broad groupings of emission sources

  • Sub-categories (child level): Specific types within each category

Each category can contain multiple sub-categories, but sub-categories cannot contain additional levels.

 

The chip next to the category label indicates the number of sub-categories inside the category.

 

To view all sub-categories, click the button next to the category label.

To hide all sub-categories, click the button next to the category label.

Control modes

In this column, there are two sub-columns:

  • Supported financial controls: Defines which financial control mode can be applied when using emission factors from this category. These controls determine how emissions are allocated across organizational boundaries.

  • Supported operational controls: Defines which operational control mode can be applied when using emission factors from this category. These controls determine how emissions are allocated across organizational boundaries.

How Control Modes Affect Data Collection

When you bind an emission factor to an activity indicator in the Association of Emission Factors with Activity Indicators screen, the control modes you define in this screen determine the available options during data collection.

Specifically, in the Data Collection Campaigns screen, the Financial control and Operational control drop-down menus display only the control modes that are supported by the emission factor category.

WARNING Modifying control modes for a category that is already in use may affect existing data collection campaigns. Ensure you understand the impact before making changes.

For more information on control modes, see Financial and Operational Controls (section from the Carbon Footprint documentation) and Management of Default Control Modes.

Label

Label of the emission factor category or sub-category. Labels must be unique within their respective levels. By default, labels are displayed in your user language.

Search for an Emission Factor Category or Sub-Category

To search for an emission factor category or sub-category:

  1. Click the button at the top of the table.

  2. Type one or more letters or keywords in the search field.

    As you type, number chips appear next to the label of matching categories. The number indicates how many sub-categories within that category match your search term. For example, a chip showing "2" means two sub-categories in that category match your search.

NOTE The search is case-insensitive. To clear your search, delete all search text.

Create an Emission Factor Category and Sub-Category

NOTE Each emission factor category must have at least one emission factor sub-category. Before creating a sub-category, you must first create a parent category.

Category and sub-category labels must be unique within their respective levels. The system will display an error message if you attempt to create a duplicate label.

 

To create an emission factor category:

  1. Click the button next to the Hierarchy column label.

    The Add a category pop-up panel appears.

  2. Enter the label in all languages available in the CSR Insight application.

  3. Select one or more Financial controls and Operational controls.

  4. Click OK.

    The new category is saved immediately and appears in the Hierarchy column. You can now create sub-categories within this category.

 

To create an emission factor sub-category:

  1. Right-click the label of the emission factor category for which you want to add an emission factor sub-category.

  2. Click Create an emission factor sub-category.

    The Create a sub-category pop-up panel appears with the Parent field automatically filled in.

  3. Enter the label in all languages available in the CSR Insight application.

  4. Click Save.

    The new sub-category is saved immediately and appears below its parent category in the Hierarchy column. You can create additional sub-categories by repeating this process.

Edit an Emission Factor Category or Sub-Category

This section covers editing labels and control modes for emission factor categories and sub-categories.

NOTE When editing data in this screen, press Enter to confirm your entry in the field, then click the button to persist all changes to the database. If you navigate away from the screen without clicking this button, your changes will be lost.

 

To edit the label of the emission factor category or sub-category:

  1. Double-click the desired label in the Label column.

  2. Enter a new label in all languages available in the CSR Insight application.

  3. Press the Enter key.

  4. Click the button at the top right of the screen.

 

To add new financial or operational control modes for an emission factor category:

  1. Double-click the Supported financial controls or the Supported operational controls cell for the desired emission factor category.

  2. Click the button to display the drop-down menu.

  3. Select the financial or operational control you want to add from the drop-down menu.

  4. Press the Enter key.

  5. Click the button at the top right of the screen.

 

To delete a financial or operational control mode for an emission factor category:

  1. Double-click the Supported financial controls or the Supported operational controls cell for the desired emission factor category.

  2. Click the button next to the label of the financial or operational control mode you want to delete.

  3. Press the Enter key.

  4. Click the button at the top right of the screen.

Delete an Emission Factor Category or Sub-Category

NOTE You can only delete emission factor categories without emission factor sub-categories. Before deleting a category, you must first delete or reassign all sub-categories.

You can only delete emission factor sub-categories that are not bound to an emission factor. Before deleting a sub-category, you must unbind it from any emission factors.

 

To delete an emission factor category or sub-category:

  1. Right-click the label of the emission factor category or sub-category you want to delete.

  2. Click Delete the emission factor category or Delete the emission factor sub-category.

    A pop-up window appears to confirm the deletion.

  3. Click Validate.

    The desired emission factor category or sub-category is deleted.

 

Troubleshooting Deletion Issues

Cannot delete category:

  • Click the button next to the category label to view all sub-categories.

  • Verify that all sub-categories have been deleted first.

  • The system prevents deletion of categories that contain sub-categories.

Cannot delete sub-category:

  • The sub-category may be bound to emission factors.

  • Navigate to the Emission Factor List screen to view and remove bindings before deletion.

Important: Deletions cannot be undone. Consider exporting your data before performing deletions to maintain a backup.

Move an Emission Factor Sub-Category

You can change the order of sub-categories inside a category, or move a sub-category from one category to another.

To move an emission factor sub-category:

  1. Click and hold the sub-category row you want to move.

  2. Drag the row to the desired position:

    • To reorder within the same category: Drop between existing sub-categories.

    • To move to a different category: Drop below the target category name.

  3. Release the mouse button to complete the move.

    The change is saved automatically.

NOTE You cannot move parent categories, only sub-categories. To reorganize parent categories, you must delete and recreate them.

Import or Export an Emission Factor Category and Sub-Category

NOTE Before importing data, export the current categories and sub-categories to obtain the correct Excel template format. This ensures your import file has the proper structure and column headers required by the system.

 

To export emission factor categories and sub-categories:

  1. Hover over the button at the top right of the screen.

  2. Click Export data.

    The Export data pop-up window appears with a download link.

  3. Click the download link for the Excel file.

 

To import emission factor categories and sub-categories:

  1. Export the emission factor categories and sub-categories as mentioned above.

  2. Open the exported Excel file.

  3. Fill in the Excel template, then save your data.

    NOTE To help you fill in the Excel template, see the Fill In the Excel Template appendix.

  4. Back in the CSR Insight application, hover over the button at the top right of the screen.

  5. Click Import data.

    The Import data pop-up window appears.

  6. Choose a file.

  7. Click OK.

Common Use Cases

The following examples illustrate typical scenarios where you would create and configure emission factor categories:

  • Organizing emission sources by business function: Create categories like "Transportation," "Energy," "Waste" with sub-categories for specific sources. For example:

    • Transportation > Company Vehicles, Transportation > Employee Commute

    • Energy > Electricity, Natural Gas, Diesel Fuel

    • Waste > Solid Waste, Wastewater Treatment, Recycling

  • Aligning with reporting standards: Structure categories to match GHG Protocol scopes (Scope 1, Scope 2, Scope 3) for easier reporting and compliance.

  • Managing multi-site entities: Use control modes to differentiate between fully-owned facilities (100% operational control) and joint ventures or partnerships (partial control).

  • Bulk updates for annual recalculations: Export categories at year-end, update control modes or labels based on organizational changes, then import to apply changes across all campaigns.
