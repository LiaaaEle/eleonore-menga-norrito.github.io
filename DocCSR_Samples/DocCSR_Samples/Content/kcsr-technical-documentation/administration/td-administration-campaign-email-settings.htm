Email Sending Settings

SEARCH TIP  Press CTRL + F (Windows and Linux) or CMD + F (Mac) to search within this page.

To access this screen, click: Administration > Campaign management > Email sending settings.

Security Notes

Some actions, such as screen access, are permitted only for authorized users, that is, users with the appropriate profile. In other words, if the user does not have the right profile, the user cannot perform the action.

To configure this security (also called user rights), complete the following steps:

  1. Define the profiles in the Profile Management screen.

  2. Define users and attach one or more profiles to them in the User Management screen.

  3. Assign user rights to the desired profiles in the Profile Matrix screen.

The table below contains screen actions that are related to user rights:

Module Screen Action

Campaign management

Email sending settings

Screen access

Introduction

This screen enables you to manage the content of the email settings sent based on the request made or the information given to the user who receives the email.

Description of the Table Columns

The table contains the following columns:

Column Description

Module

Module name:

  • Reporting: The email concerns the reporting.

  • Strategy: The email concerns strategies.

  • Restitution: The email concerns the restitution.

  • Administration: The email concerns an action that can be performed by the administrator.

Action

Email object: Action of the email sender or recipient that triggers the sending of the email.

Disable

Check the box to not send the email.

Email description

Customized email object and content.

 

Number and label of "Email description" columns depends on languages available in the CSR Insight application.

 

For more details, see Customize Email Object and Content.

Recipients

To select the profiles that will receive the email, click the button.

A pop-up window appears at the bottom of the screen.

Attachment

The box is checked if there is an attachment in the mail.

Customize Email Object and Content

To view or edit the email object and content in your desired language, click the button in the corresponding "Email description" column.

To customize the email object and content, the following variables can be incorporated:

  • User information:

    • {NAME}: Recipient's full name (first and last name)

    • {FIRSTNAME}: Recipient's first name

    • {SENDER_NAME}: Sender's full name (first and last name)

  • Campaign information:

    • {CAMPAIGN_YEAR}: Campaign year

    • {CAMPAIGN_PERIOD}: Campaign period

    • {CAMPAIGN_LABEL}: Campaign name

    • {CAMPAIGN_LIST}: List of campaigns that are included in the functional scope of the email recipient

  • Deadline information:

    • {INPUT_DATE}: Data entry deadline

    • {VALIDATION_DATE}: Data validation deadline

    • {CLOSING_DATE}: Data closure deadline

  • Organizational information:

    • {ORGANIZATION_LABEL}: Name of the current entity in the email context

    • {ORGANIZATION_LIST}: List of entities that are included in the functional scope of the email recipient

  • Indicator information:

    • {INDICATOR_LABEL}: Name of the indicator in the email context

    • {VALUE}: Value of the indicator in the email context

  • Import information:

    • {STATUS_IMPORT_DATA}: Status after data import on a campaign (success, error, alert, or done)

  • Chat room information:

    • {TOPIC_MESSAGE}: Question topic of the message chosen in the Chat Room (indicator, value, campaign, or free)

  • System information:

    • {CONTACT_ADRESS}: Support contact email address for recipient inquiries (Default: corp.sustainability_performance_team@kshuttle.com)

    • {REPORTING_SCREEN}: Link to the Data Collection Campaigns screen

    • {BREADCRUMB_REPORTING}: Breadcrumbs to the Data Collection Campaigns screen

    • {BREADCRUMB_ADJUSTMENT}: Breadcrumbs to the Details of Adjustment Requests screen

  • Action-specific information:

    • {ACTION_TODO}: Action carried out by the email sender or to be carried out by the email recipient (for example: relaunch, create an adjustment, and so on)

    • {ELEMENT_TO_CHECK}: Item the email recipient must check

     

    These variables are automatically replaced with actual values when the email is sent to recipients. Type the variable exactly as shown, including the curly braces { }.
