Indicator Management: Hierarchy Column

SEARCH TIP  Press CTRL + F (Windows and Linux) or CMD + F (Mac) to search within this page.

To access this screen, click: Administration > Indicator management > Indicator management.

Security Notes

Some actions, such as screen access, are permitted only for authorized users, that is, users with the appropriate profile. In other words, if the user does not have the right profile, the user cannot perform the action.

To configure this security (also called user rights), complete the following steps:

  1. Define the profiles in the Profile Management screen.

  2. Define users and attach one or more profiles to them in the User Management screen.

  3. Assign user rights to the desired profiles in the Profile Matrix screen.

The table below contains screen actions that are related to user rights:

Module Screen Action

Indicator management

Indicator management

Screen access

Create, update, or disable an indicator

Recalculate the KPI based on past years*

*Enables you to update the indicator calculation formula and then to apply this calculation to all past years.

The Hierarchy column contains a list of indicators included in the chapter and the theme selected from the point of view (POV).

Indicators defined in the CSR Insight application are divided into chapters, themes, and sections, by nesting.

NOTE To know more on indicator classification , see the Indicator Management: Introduction documentation.

 

From the Hierarchy column, you can:

  • Create a Section or an Indicator

  • Edit a Section or an Indicator

  • Move a Section or an Indicator

  • Delete a Section

  • Disable an Indicator

  • Recalculate an Indicator Value

Create a Section or an Indicator

You can create a section or an indicator within a section from the Hierarchy column.

Create a Section

To create a section:

  1. Click the button next to the label of the Hierarchy column.

    The Add a section pop-up panel appears.

  2. Enter the following information:

    • The Reference

    • The English label

    • The French label

  3. Click OK.

Create an Indicator within a Section

NOTE To help you fill out each field in the Identity card, see the following documentations:

  • Indicator Management: Indicator Identification Column for fields in the Indicator identification block
  • Indicator Management: Data Typology Column for fields in the Data typology block
  • Indicator Management: Dashboards & Extractions Column for fields in the Dashboards & Extractions block
  • Indicator Management: Carbon Footprint Column for fields in the Carbon footprint block

 

To create an indicator within a section:

  1. Right click on the section in which you want to create the indicator in the Hierarchy column.

    A drop-down menu appears.

  2. Click Create indicator from the drop-down menu.

    The Identity card appears.

  3. Fill in the following fields in the Indicator identification block:

    • Label FR

    • Label EN

    • Reference

  4. Select from the drop-down menus in the Data typology block:

    • The Response type

    • If the Response type selected is Choice list - simple choice or Choice list - multiple selection:

      • the List of choices

      • the Frequency

    • If the Response type selected is Numerical data:

      • the Unit

      • the Temporal aggregation

      • the Frequency

      • the Data source: Collected or Calculated

      • If the Data source selected is Calculated, the Entity aggregation

  5. Optional: Fill in the other information available in the Indicator identification and the Data typology blocks.

  6. Optional: Enter descriptions in French and in English in the Description block.

  7. Optional: Fill in some or all information from the following blocks:

    • Dashboards & Extractions

    • Carbon footprint

  8. Click Save at the top right of the Identity card.

Edit a Section or an Indicator

You can edit a section or an indicator from the Hierarchy column.

Edit a Section

To edit a section:

  1. Right click on the section in which you want to create the indicator in the Hierarchy column.

    A drop-down menu appears.

  2. Click Edit section from the drop-down menu.

    The Edit a section pop-up panel appears.

  3. Edit the information as desired.

  4. Click OK.

Edit an Indicator

To edit an indicator:

  1. Right click on the indicator that you want edit in the Hierarchy column.

    A drop-down menu appears.

  2. Click Edit indicator from the drop-down menu.

    The Identity card appears.

  3. Edit the information as desired.

  4. Click Save at the top right of the Identity card.

Move a Section or an Indicator

From the Hierarchy column, you can :

  • Move an Indicator within a Section

  • Move a Section

  • Change the Chapter, Theme, or Section of an Indicator

Move an Indicator within a Section

You can rearrange indicators among themselves within a section.

To do so:

  1. Drag and drop the line of the indicator you want to move up or down within the section.

    The Move section pop-up window appears to confirm the move.

  2. Click OK.

Move a Section

You can rearrange sections among themselves within a chapter and a theme, or move sections to another chapter and/or theme.

To do so:

  1. Right click on the section for which you want to move in the Hierarchy column.

    A drop-down menu appears.

  2. Click Move section from the drop-down menu.

    The Move section pop-up panel appears.

  3. Select from the drop-down menus:

    • The Chapter

    • The Theme

  4. Select the location of the section within the chosen chapter and theme. You can choose to place the section either before the X or Y section, or at last position.

  5. Click OK.

Change the Chapter, Theme, or Section of an Indicator

To change the chapter, theme, or section of an indicator:

  1. Right click on the indicator for which you want to change the chapter, theme, or section in the Hierarchy column.

    A drop-down menu appears.

  2. Click Move indicator from the drop-down menu.

    The Move this indicator pop-up panel appears.

  3. Select from the drop-down menus:

    • The Chapter

    • The Theme

    • The Section

  4. Click OK.

Delete a Section

NOTE You can only delete sections that do not contain indicators.

To delete a section from the Hierarchy column:

  1. Right click on the section that you want to delete.

    A drop-down menu appears.

  2. Click Delete section from the drop-down menu.

    The Removal of the section pop-up window appears to confirm your deletion.

  3. Click Validate.

Disable an Indicator

NOTE You can only disable collected indicators with no entered data.

Disable an indicator means make this indicator inactive. An inactive indicator can no longer be used in the CSR Insight application.

If you only want to disable data collection, and not exclude the indicator from any use in the application, see the Indicator Management: Indicator Uses Column documentation.

 

To disable an indicator from the Hierarchy column:

  1. Right click on the indicator that you want to disable in the Hierarchy column.

    A drop-down menu appears.

  2. Click Disable indicator from the drop-down menu.

    The Deactivation of the indicator pop-up windows appears to confirm the deactivation.

  3. Click Validate.

Recalculate an Indicator Value

This feature allows you to recalculate the value of an indicator calculated via a formula.

To recalculate an indicator value:

  1. Right click on the calculated indicator for which you want to recalculate its value in the Hierarchy column.

    A drop-down menu appears.

  2. Click Recalculate indicator from the drop-down menu.

    The calculation formula of the calculated indicator retrieves all changes to the values ​​of the indicators used in the calculation formula. The value of the calculated indicator is changed.

NOTE You can also recalculate values for all calculated indicators by using the button. See the Indicator Management: Three Dots Button documentation.
