To access this screen, click: Administration > Proforma > Configuration of the inflation effect.

Click the button to return to the Home Screen.

Security Notes

Some actions, such as screen access, are permitted only for authorized users, that is, users with the appropriate profile. In other words, if the user does not have the right profile, the user cannot perform the action.

To configure this security (also called user rights), complete the following steps:

  1. Define the profiles in the Profile Management screen.

  2. Define users and attach one or more profiles to them in the User Management screen.

  3. Assign user rights to the desired profiles in the Profile Matrix screen.

The table below contains screen actions that are related to user rights:

Configuration of the inflation effect

Screen access

Introduction

This screen allows you to view and manage inflation effects, for all proforma versions, by entity and year. The year is selectable from the point of view (POV).

On the Proforma version management screen, you can activate or disable inflation for one or multiple proforma versions. If activated, you can define the target year. To know more on inflation settings, see the Proforma Version Management documentation.

Description of the Table Columns

The table contains the following columns:

Column Description

Reference

Code of the entity.

Entity

List of entities that exists in the CSR Insight application.

Currency

Default currency of each entity.

Rate

Inflation rate between two years set up for each entity.

Example: The year selected in the POV is 2026. Therefore, the inflation rate set up in 2026 will be applied on 2026 data.

Set Up Inflation Rates

NOTE To ensure that all your proforma restatements made have been taken into account, calculate all proforma restatements each time you make a change.

To set up an inflation rate:

  1. Double-click the Rate cell of the desired entity.

  2. Enter an inflation rate.

  3. Click the button in the toolbar at the top right of the screen.

The inflation rate for the desired entity is now set.

Export Inflation Rates

To export inflation rates, click the button in the toolbar at the top right of the screen.

An Excel file is automatically downloaded to your computer.
