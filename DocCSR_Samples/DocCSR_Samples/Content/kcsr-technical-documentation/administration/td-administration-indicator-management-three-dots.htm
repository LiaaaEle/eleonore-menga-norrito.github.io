To access this screen, click: Administration > Indicator management > Indicator management.

Security Notes

Some actions, such as screen access, are permitted only for authorized users, that is, users with the appropriate profile. In other words, if the user does not have the right profile, the user cannot perform the action.

To configure this security (also called user rights), complete the following steps:

  1. Define the profiles in the Profile Management screen.

  2. Define users and attach one or more profiles to them in the User Management screen.

  3. Assign user rights to the desired profiles in the Profile Matrix screen.

Import or Export Indicators

You can import or export indicators, whether collected or calculated.

The dependencies between indicators are managed in a single import operation. This means you can import a calculated indicator and the collected indicators used in its calculation formula in one go.

 

To export indicators:

  1. Hover over the button.

  2. Click Export indicators from the drop-down menu.

    The Export pop-up window appears with a download link.

  3. Click the download link for the Excel file.

 

To import indicators:

  1. Export the indicators as mentioned above.

  2. Open the exported Excel file.

  3. Fill in the Excel template, then save your data.

    NOTE To help you fill in the Excel template, see the Fill In the Excel Template appendix.

  4. In the CSR Insight application, hover over the button.

  5. Click Import indicators from the drop-down menu.

    The Import indicators pop-up window appears.

  6. Choose a file.

  7. Click OK.

Recalculate Indicator Values

This feature allows you to recalculate the values of all indicators calculated via a formula.

To recalculate indicator values:

  1. Hover over the button.

  2. Click Recalculate indicators from the drop-down menu.

    The Recalculate indicators pop-up window appears to confirm your action.

  3. Click Validate.

    The calculation formula for each calculated indicator retrieves all changes to the values ​​of the indicators used in the calculation formula. All calculated indicator values are changed.
