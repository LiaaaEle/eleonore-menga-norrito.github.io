Security Notes

Some actions, such as screen access, are permitted only for authorized users, that is, users with the appropriate profile. In other words, if the user does not have the right profile, the user cannot perform the action.

To configure this security (also called user rights), complete the following steps:

  1. Define the profiles in the Profile Management screen.

  2. Define users and attach one or more profiles to them in the User Management screen.

  3. Assign user rights to the desired profiles in the Profile Matrix screen.

From the Thresholds and consistency checks column, you can set up thresholds and consistency checks that need to be respected for one or multiple indicators.

 

A threshold consists of defining a constant value to respect for a numerical indicator: for example, less or greater than 50, 100, between 0 and 1, and so on.

 

From this screen, thresholds are defined for an indicator on all deployed entities.

 

From the Usage column on the Entity Management screen, thresholds are defined for indicators deployed on an entity. See the Entity Management: Usage Column documentation.

 

A consistency check consists of defining the value of an indicator in relation to another entered value: for another period/year, for another indicator in the same period/year, and so on. Besides, you can enable conditional display of indicators by setting consistency checks.

You can set up consistency check only for indicators associated with one of the following response types:

  • Numerical data

  • Choice list – simple choice

  • Choice list – multiple selection

 

The Thresholds and consistency checks block in the Identity card has the same content as the Thresholds and consistency checks column. To access the Identity card, see Edit an Indicator.

Set Up Thresholds for an Indicator

To set up thresholds for an indicator from the Thresholds and consistency checks column, you need to follow three steps:

  1. Select a threshold type.

  2. Select an action triggered if the threshold is not respected.

  3. Enter threshold values for one or multiple entities on which the indicator is deployed.

Step 1: Select a Threshold Type

To select a threshold type:

  1. Position your cursor at the line of the indicator for which you want to select a threshold type.

  2. Double-click the cell in the Threshold type sub-column from the Thresholds and consistency checks column.

  3. Select one of the following options from the drop-down menu:

    • Strict minimum: Data entered for an indicator must be greater than the threshold value.

    • Minimum: Data entered for an indicator must be greater than or equal to the threshold value.

    • Strict maximum: Data entered for an indicator must be less than the threshold value.

    • Maximum: Data entered for an indicator must be less than or equal to the threshold value.

  4. Click the button at the top right of the nested grid.

Step 2: Select a Triggered Action

To select an action triggered if the threshold is not respected for an indicator:

  1. Position your cursor at the line of the indicator for which you want to select a triggered action.

  2. Double-click the cell in the Action if threshold reached sub-column from the Thresholds and consistency checks column.

  3. Select one of the following options from the drop-down menu:

    • Warn: When the threshold is not respected for an indicator, an alert is triggered on the Data Collection Campaigns screen in both table and survey views.

    • Comment: When the threshold is not respected for an indicator, you must write a comment on the Data Collection Campaigns screen.

    • Freeze validation: When the threshold is not respected for an indicator, data validation is frozen on the Data Collection Campaigns screen.

  4. Click the button at the top right of the nested grid.

Step 3: Enter Threshold Values

To enter threshold values for one or multiple entities on which the indicator is deployed:

  1. Position your cursor at the line of the indicator for which you want to enter threshold values.

  2. Click the button in the Thresholds sub-column from the Thresholds and consistency checks column.

    The Threshold Management screen appears.

Set Up Consistency Checks for an Indicator

You can view the number of consistency checks set for an indicator in the Number of controls sub-column from the Thresholds and consistency checks column.

 

To set consistency checks for an indicator:

  1. Position your cursor at the line of the indicator for which you want to set up consistency checks.

  2. Click the button in the Consistency checks sub-column from the Thresholds and consistency checks column.

    The Consistency Check Management screen appears.

Specific Procedure for Conditional Display of Indicators

 

NOTE Conditional display of indicators includes:

  • A Choice list - simple choice indicator

  • One or multiple indicators displayed or hidden depending on the choice selected on the Data Collection Campaigns screen for the Choice list - simple choice indicator

  • A consistency check that defines which choice displays or hides these indicators.

 

To set up the conditional display of indicators:

  1. Set up a consistency check for a Choice list - simple choice indicator.

    NOTE See the procedure above as well as the one mentioned in the Consistency Check Management screen.

  2. Enable conditional display for indicators you want to conditionally display.

    To do so, select Yes in the Hidden by default sub-column from the Thresholds and consistency checks column.

  3. Set up, then start a campaign containing the indicators to display on the Campaign Set Up, Campaign Settings: Indicators to Deploy and Campaign Settings: Entities to Deploy for an Indicator screen.

    You can now display hidden indicators on the Data Collection Campaigns screen.

 

To display hidden indicators on the Data Collection Campaigns screen:

  1. Select the choice, that enables display of the hidden indicators, from the drop-down menu available on the Choice list - simple choice indicator card (Survey view) or on the table (Table view).

  2. Click the button at the top right of the screen.

    Hidden indicators appear.
