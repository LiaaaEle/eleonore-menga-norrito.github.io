Security Notes

Some actions, such as screen access, are permitted only for authorized users, that is, users with the appropriate profile. In other words, if the user does not have the right profile, the user cannot perform the action.

To configure this security (also called user rights), complete the following steps:

  1. Define the profiles in the Profile Management screen.

  2. Define users and attach one or more profiles to them in the User Management screen.

  3. Assign user rights to the desired profiles in the Profile Matrix screen.

Introduction

STEP BY STEP

Recovering historical data means integrating existing data to the CSR Insight application.

 

To recover historical data by import:

  1. Create campaigns with external data from the Data Recovery screen.

    TIP  Use this screen during the project phase to carry out bulk imports — up to 52 megabytes — at once. No need to go through either the campaign setting screens or the data collection screen.

     

  2. Add existing indicators to already created campaigns from this screen.

     

    TIP  Using this screen for historical campaigns are mandatory. These are campaigns that can only contain imported data.

 

This screen is mainly used to recover data, namely indicators, from campaigns created in a previous CSR Insight application version, not external data. More precisely:

  1. Make sure you exported campaign data from a previous CSR Insight application version.

  2. Create an historical campaign in your current CSR Insight application version through the Campaign Settings screen.

  3. Import the exported campaign data in your historical campaign through this screen.

 

Consistency rules are the same as for deploying indicators and entities on campaigns, respectively from the Campaign Settings: Indicators to Deploy and Campaign Settings: Entities to Deploy for an Indicator screens:

  • An "indicator - entity" data couple can only be deployed on one campaign for a particular year and periodicity.

  • Indicator deployment can only be done on active entities.

  • An indicator cannot be deployed on a parent entity and its child entities.

  • An indicator associated with a data collection point, called Collect level in the CSR Insight application, can only be deployed to entities belonging to that data collection point.

    NOTE For more information, see Indicator Management: Data Typology Column and Entity Type Management.

Add Indicators to Campaigns by Import

To add indicators to campaigns by import, you must follow several steps:

  1. Export and fill in the template file.

  2. Import this file.

    Indicators are added in existing campaigns. You can view them on the Campaign Indicators screen, as well as on the Data Collection Campaigns screen for started campaigns.

Export and Fill In the Template File

To export the template file:

  1. Click the button at the top left of the screen.

    The Export format data pop-up window appears with a download link.

  2. Click the download link for the Excel file.

 

To help you fill in the Excel template, see the Fill In the Excel Template appendix. After filling in the template file, save your data.

Import the Template File

To import the template file you filled in:

  1. Click the button at the top left of the screen.

    The Data import pop-up window appears.

  2. Select the Import mode:

    • Create and update (without deleting) if you want to add new data without deleting the data that already exists in the CSR Insight application. No data overwriting.

    • Create, update, and delete if you want to overwrite or clear the existing data in the CSR Insight application. Overwriting means that existing data is deleted and replaced with new data.

  3. Select the Indicator search mode to determine how the system matches indicators in your Excel file to indicators in the CSR Insight application:

    • Label if your Excel file uses indicator names

    • Indicator reference if your Excel file uses indicator codes

  4. Select the Organization search mode to determine how the system matches entities in your Excel file to indicators in the CSR Insight application:

    • Label if your Excel file uses entity names

    • Entity reference if your Excel file uses entity codes

  5. Choose a file.

    WARNING Import only the file you exported and filled in. Otherwise, the import will fail.

  6. Click OK.

    Indicators are added in existing campaigns. You can view them on the Campaign Indicators screen and on the Data Collection Campaigns screen for started campaigns.

 

TIP  For big data verification, export the imported file and check row per row that the indicators are imported in the correct campaign on the Campaign Settings: Indicators to Deploy screen.

Check also if all imported indicator information is correct on the Data Collection Campaigns screen for started campaigns or on the Indicator Management screen for non-started campaigns.

If you are missing indicators in your campaign or indicator information is incorrect, do a new import through this screen.

If your campaign does not contain the correct indicators, remove them from the Campaign Settings: Indicators to Deploy screen.

Description of the Table Columns

The table contains the following columns:

Column Description

Author

User who initiated the import.

Date

Import date.

Status

Import status:

  • Import in progress: File is being processed. Refresh the page to check for completion. You may use other screens while waiting.

  • Import with success: All data is successfully imported. Indicators are added in existing campaigns. You can view them on the Campaign Settings: Indicators to Deploy screen and on the Data Collection Campaigns screen for started campaigns.

  • Import in error: Your imported file contains errors, that is, required fields were not completed or were not completed correctly. Valid data was imported; only erroneous rows were rejected. Export the Error file to identify and correct errors, then import it.

 

Error file

When your imported file contains errors, an Error file is automatically created. Click the button to export this file.

NOTE This file contains for each row the reason for the import failure in the last column.

Comment

Comment associated to the imported file.

File name

Imported file name.

Imported file

Click the button to export the Imported file.
