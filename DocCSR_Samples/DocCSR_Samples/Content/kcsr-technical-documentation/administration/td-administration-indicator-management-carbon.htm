Security Notes

Some actions, such as screen access, are permitted only for authorized users, that is, users with the appropriate profile. In other words, if the user does not have the right profile, the user cannot perform the action.

To configure this security (also called user rights), complete the following steps:

  1. Define the profiles in the Profile Management screen.

  2. Define users and attach one or more profiles to them in the User Management screen.

  3. Assign user rights to the desired profiles in the Profile Matrix screen.

STEP BY STEP

Setting up the carbon footprint data for indicators is the first step in carrying out your carbon footprint:

  1. Determine which indicators will be used in your carbon footprint on this screen.

    NOTE If you have bound an indicator to an emission factor on the Association of Emission Factors with Activity Indicators screen, this indicator will be automatically marked as Indicator used in the carbon footprint on this screen.

  2. Enable or disable the entry of carbon information either on the Data Collection Campaigns screen or on this screen.

  3. Set up default carbon footprint information, regardless of the campaign, on this screen.

  4. Set up carbon footprint information in campaigns on the Data Collection Campaigns screen.

The Carbon footprint column contains default carbon footprint information related to indicators regardless of the campaign:

  • Uncertainty

  • Amortization period

  • Financial control

  • Operational control

  • Valuation table

  • Partner

NOTE For more information on these concepts, see the Carbon Footprint documentation.

 

From this column, you can:

  • Enable or Disable the Entry of Carbon Footprint Information for an Indicator

  • Choose the Indicators Used in the Carbon Footprint

  • Set Up Default Carbon Footprint Information for an Indicator

 

 

The Carbon footprint block in the Identity card has the same content as the Carbon footprint column. To access the Identity card, see Edit an Indicator.

Choose the Indicators Used in the Carbon Footprint

Once you have determined which indicators will be used in the carbon footprint, you will be able to know which ones require a carbon footprint setting.

 

For these indicators, carbon footprint setting includes:

  • Filling in the carbon footprint information either on the Data Collection Campaigns screen or on this screen

  • Binding each indicator to one or more emission factors on the Association of Emission Factors with Activity Indicators screen

    NOTE All indicators marked as Indicator used in the carbon footprint on this screen must be bound to emission factors. If not, alerts will be displayed on the Carbon Footprint Audit screen.

 

There are two ways to choose indicators used in the carbon footprint:

  • From the Identity Card

  • From the Carbon Footprint Column

From the Identity Card

To choose indicators used in the carbon footprint from the Identity card:

  1. Make the Identity card appears for the desired indicator as indicated in the Edit an Indicator section.

  2. Go to the Carbon footprint block.

  3. Switch on or off the button.

  4. Click Save at the top right of the Identity card.

From the Carbon Footprint Column

To choose indicators used in the carbon footprint from the Carbon footprint column:

  1. Position your cursor at the line of the indicator for which you want to choose whether or not it is used in the carbon footprint.

  2. Double-click the cell in the Indicator used in the carbon footprint sub-column from the Carbon footprint column.

  3. Select Yes for used indicators or No for unused indicators.

  4. Click the button at the top right of the nested grid.

Enable or Disable the Entry of Carbon Footprint Information for an Indicator

NOTE To set up a valuation table for an indicator, skip this section.

To enter carbon footprint information for an indicator, either on the Data Collection Campaigns screen or on this screen, you need to enable the display and the entry of carbon footprint information beforehand.

There are two ways to enable or disable the entry of carbon footprint information for an indicator:

  • From the Identity Card

  • From the Carbon Footprint Column

From the Identity Card

To enable or disable the entry of carbon footprint information from the Identity card:

  1. Make the Identity card appears for the desired indicator as indicated in the Edit an Indicator section.

  2. Go to the Carbon footprint block.

  3. Switch on or off the following buttons:

  4. Click Save at the top right of the Identity card.

From the Carbon Footprint Column

To enable or disable the entry of carbon footprint information from the Carbon footprint column:

  1. Position your cursor at the line of the indicator for which you want to enable or disable the entry of carbon footprint information.

  2. Double-click the cell in the Editable uncertainty, Editable amortization period, Partner input, and/or Selection of the control mode sub-column from the Carbon footprint column.

  3. Select Yes to enable data entry or No to disable data entry.

  4. Click the button at the top right of the nested grid.

Set Up Default Carbon Footprint Information for an Indicator

NOTE You can set up default carbon footprint information for an indicator regardless of the campaign only after enabling data entry.

To set up carbon footprint information for an indicator in a given campaign, access the desired campaign from the Identity card or from the Indicator uses column (see View Campaigns Related to an Indicator).

The Data Collection Campaigns appears.

There are two ways to set up default carbon footprint information for an indicator regardless of the campaign:

  • From the Identity Card

  • From the Carbon Footprint Column

From the Identity Card

To set up default carbon footprint information for an indicator from the Identity card:

  1. Make the Identity card appears for the desired indicator as indicated in the Edit an Indicator section.

  2. Go to the Carbon footprint block.

  3. Fill in the Uncertainty and/or the Default amortization period field.

  4. Select a Partner and/or a Valuation table from the drop-down menus.

  5. Click the Default financial control or the Default operational control button.

    The Management of Default Control Modes screen appears.

  6. Click Save at the top right of the Identity card.

From the Carbon Footprint Column

To set up default carbon footprint information for an indicator from the Carbon footprint column:

  1. Position your cursor at the line of the indicator for which you want to set up default carbon footprint information.

  2. Set up the default uncertainty for this indicator:

    1. Double-click the cell in the Uncertainty sub-column from the Carbon footprint column.

       

      A bar appears.

       

    2. Drag your cursor across the bar to the desired percentage.

    3. Click the Enter key.

    4. Click the button at the top right of the nested grid.

  3. Set up the valuation table:

    1. Double-click the cell in the Valuation table sub-column from the Carbon footprint column.

       

      A drop-down menu appears.

       

    2. Select a valuation table from the drop-down menu.

      NOTE To enable the selection of a valuation table, you need to create at least one valuation table on the Management of Valuation Tables screen.

    3. Click the button at the top right of the nested grid.

  4. Set up the default amortization period:

    1. Double-click the cell in the Default amortization period sub-column from the Carbon footprint column.

       

      An input zone appears.

       

    2. Enter the default amortization period in the input zone.

    3. Click the Enter key.

    4. Click the button at the top right of the nested grid.

  5. Set up the default partner:

    1. Double-click the cell in the Default partner sub-column from the Carbon footprint column.

       

      A drop-down menu appears.

       

    2. Select a default partner from the drop-down menu.

    3. Click the button at the top right of the nested grid.

  6. Set up the default financial and/or operational control mode.

    To do so, click the button in the Default financial control mode and/or in the Default operational control mode sub-column from the Carbon footprint column.

    The Management of Default Control Modes screen appears.
