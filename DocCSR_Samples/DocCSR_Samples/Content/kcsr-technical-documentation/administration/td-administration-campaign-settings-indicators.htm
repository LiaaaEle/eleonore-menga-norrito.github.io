To access this screen, click Administration > Campaign Management > Campaign settings, then click the button (Campaign indicators) for the desired campaign.

Security Notes

Some actions, such as screen access, are permitted only for authorized users, that is, users with the appropriate profile. In other words, if the user does not have the right profile, the user cannot perform the action.

To configure this security (also called user rights), complete the following steps:

  1. Define the profiles in the Profile Management screen.

  2. Define users and attach one or more profiles to them in the User Management screen.

  3. Assign user rights to the desired profiles in the Profile Matrix screen.

This screen allows you to select the indicators included in the campaign.

You can also import or export campaign indicators.

The campaign selected on the Campaign Settings screen, on which the indicators are set up, and the campaign year, are locked in the point of view (POV).

Check consistency rules before deploying indicators in a campaign.

Description of the Table Columns

The table contains the following columns:

Column Description

Reference

Unique code used to identify the indicator. This code is especially used in the formulas for calculated indicators and when loading data.

Example: For interfaces created with other upstream tools, use references instead of labels. References are shorter and contain no special characters.

Label

Indicator name.
Response type

Type of data that can be collected for the indicator:

  • Numerical data: Collected data is numeric.

    NOTE Data is always numerical for calculated indicators.

  • Choice list – simple choice: One value from a choice list can be selected for the indicator. Collected data is numeric or textual.

    NOTE Predefined lists of choices are created on the List Management screen.

  • Choice list – multiple selection: Multiple values from a choice list can be selected for the indicator. Collected data is numeric or textual.

    NOTE Predefined lists of choices are created on the List Management screen.

  • Text: Collected data is textual.

  • File: Collected data is a file.
Data source

Data source of an indicator:

  • Collected: Indicator data is collected on the Data Collection Campaigns screen.

  • Calculated: Indicator data is calculated via a formula.

Collect frequency

NOTE Before deploying an indicator in a campaign, verify that the periodicity of the indicator data corresponds to the periodicity of the campaign set on the Campaign Settings screen.

Periodicity of indicator data set up on the Indicator Management screen:

  • Yearly: Data is collected or calculated once a year (period: Full year).

  • Semiannually: Data is collected or calculated twice per year:

    • HY1: First semester

    • HY2: Second semester

  • Quarterly: Data is collected or calculated four times per year:

    • Q1: First quarter

    • Q2: Second quarter

    • Q3: Third quarter

    • Q4: Fourth quarter

  • Monthly: Data is collected or calculated per year (January through December).

Deployment of the indicator

Check the box if you want to include the indicator in the campaign.

NOTE You cannot clear this checkbox if data exists for an already deployed entity or indicator. This prevents data loss. To undeploy the indicator, you must first delete all associated data.

Number of data entry nodes

Number of entities in which the indicator is deployed.

Data gathered during the campaign

This field displays only two states: grayed-out (no data collected) or YES (data exists). The field cannot be manually edited; it updates automatically based on data entry activity.

Click the button at the end of the line to deploy indicators on entities. See the Indicator Entities documentation.

Import or Export Campaign Indicators

To export campaign indicators:

  1. Click the button at the top left of the screen.

  2. Click Campaign setup export.

    The Campaign setup export pop-up window appears with a download link.

  3. Click the link to download the Excel file.

 

To import campaign indicators:

  1. Export the campaign indicators as described above.

  2. Open the exported Excel file.

  3. Fill in the Excel template, then save your data.

    NOTE To help you fill in the Excel template, see the Fill In the Excel Template appendix.

  4. Back in the CSR Insight application, click the button at the top left of the screen.

  5. Click Campaign setup import.

    The Campaign setup import pop-up window appears.

  6. Choose a file.

  7. Click OK.
