Click the button to return to the Home Screen.

Security Notes

Some actions, such as screen access, are permitted only for authorized users, that is, users with the appropriate profile. In other words, if the user does not have the right profile, the user cannot perform the action.

To configure this security (also called user rights), complete the following steps:

  1. Define the profiles in the Profile Management screen.

  2. Define users and attach one or more profiles to them in the User Management screen.

  3. Assign user rights to the desired profiles in the Profile Matrix screen.

Access the theme list

This screen allows you to manage the breakdown by chapter and theme.

Indicators defined in CSR Insight are divided into chapters, themes, and sections, by nesting. Each chapter contains one or multiple themes. Each theme contains one or multiple sections. Each section contains one or multiple indicators.

In other words, from the largest box to the smallest box, we have the following nesting: chapters > themes > sections > indicators.

Therefore, to define indicators, you need first to define chapters, then themes, and finally sections.

NOTE After defining chapters, then themes, on this screen , go to the Indicator Management screen to create sections, then indicators.

Chapter Management

Create a Chapter

To create a new chapter:

  1. Click the button at the top left of the table.

    The Create a chapter pop-up panel appears.

  2. Enter the label in all available languages and the Reference.

  3. Click OK.

Update a Chapter

To update a chapter:

  1. Click the button at the beginning of the concerned line.

    The Update a chapter pop-up panel appears.

  2. Enter the new information.

  3. Optional: Click Choose a file to add an attachment.

  4. Click OK.

Delete a Chapter

To delete a chapter:

  1. Click the button at the beginning of the concerned line.

    The Delete this chapter pop-up window appears to confirm the deletion.

  2. Click OK.

NOTE You cannot delete chapters that contains indicators.

Import or Export a Chapter

To export chapters:

  1. Click the button at the top left of the screen.

    The Export chapters pop-up window appears with a download link.

  2. Click the download link for the Excel file.

 

To import chapters:

  1. Export the chapters, as mentioned above.

  2. Open the exported Excel file.

  3. Fill in the Excel template, then save your data.

  4. Back to the CSR Insight application, click the button at the top left of the screen.

    The Import chapters pop-up window appears.

  5. Choose a file.

  6. Click OK.
