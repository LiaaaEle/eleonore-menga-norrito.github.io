Security Notes

Some actions, such as screen access, are permitted only for authorized users, that is, users with the appropriate profile. In other words, if the user does not have the right profile, the user cannot perform the action.

To configure this security (also called user rights), complete the following steps:

  1. Define the profiles in the Profile Management screen.

  2. Define users and attach one or more profiles to them in the User Management screen.

  3. Assign user rights to the desired profiles in the Profile Matrix screen.

Import or Export Entities

You can export and import entities from the main hierarchy or from an alternative hierarchy.

However, if your entity is active in the main hierarchy, you cannot modify it by importing from an alternative hierarchy.

Moreover, any change of parent entity for a child entity by import will modify data already consolidated on the alternative hierarchy.

 

To export entities:

  1. Hover over the button.

  2. Click Export entities from the drop-down menu.

    The Export entities pop-up window appears.

  3. Select the Vision (Hierarchy) from the drop-down menu.

  4. Click OK.

    A download link appears.

  5. Click the download link for the Excel file.

 

To import entities:

  1. Export the entities as mentioned above.

  2. Open the exported Excel file.

  3. Fill in the Excel template, then save your data.

    NOTE To help you fill in the Excel template, see the Fill In the Excel template appendix.

  4. In the CSR Insight application, hover over the button.

  5. Click Import entities from the drop-down menu.

    The Import entities pop-up window appears.

  6. Select the Vision (Hierarchy) from the drop-down menu.

  7. Choose a file.

  8. Click OK.

Create an Alternative Hierarchy

To create an alternative hierarchy, there are two ways:

  • Through the Hierarchy Management screen

  • Through this screen

 

To create an alternative hierarchy through this screen:

  1. Hover over the button.

  2. Click Create a hierarchy from the drop-down menu.

    The Create an alternative hierarchy pop-up panel appears.

  3. Enter the label in all available languages.

  4. Optional: Enter a description in all available languages.

  5. Click OK.

    A new sub-column appears in the Active hierarchies column.

Create an Entity Type

To create an entity type, there are two ways:

  • Through the Entity Type Management screen

  • Through this screen

 

To create an entity type through this screen:

  1. Hover over the button.

  2. Click Create entity type from the drop-down menu.

    The Create entity type pop-up panel appears.

  3. Enter the English and French labels for the entity type you want to create.

  4. Click OK.

    A new entity type can be selected for an entity from the Entity type sub-column in the Entity identification column.

Copy Campaign Setup of an Entity

Copying a campaign setup from one entity to another means copying the campaign setup done on the Campaign Management, Campaign Settings: Indicators to Deploy and Campaign Settings: Entities to Deploy for an Indicator screens.

 

The source entity will share with the target entity:

  • Deployment of indicators on campaigns, and/or

  • Emission factor data, and/or

  • Threshold data

 

To copy a campaign setup from a source entity to a target entity:

  1. Hover over the button.

  2. Click Copy Entity Setup from the drop-down menu.

    The Copy the setup of an entity pop-up panel appears.

    Select from the drop-down menus:

    • Copy mode:

      • Copy with prior deletion of the existing if you want to overwrite or clear the existing data in the CSR Insight application. Overwriting means that existing data is deleted and replaced with new data.

      • Copy without deletion if you want to add new data without deleting the data that already exists in the CSR Insight application. No data overwriting.

    • Elements to copy: deployment of indicators of campaigns, thresholds, and/or emission factors

    • Source entity

    • One or more Target Entity

  3. Click OK.

View Inactive Entities

Inactive entities are entities that are not used anywhere in the CSR Insight application.

To view inactive entities:

  1. Hover over the button.

  2. Click Inactive entities management from the drop-down menu.

    The Inactive Entity Management screen appears.
