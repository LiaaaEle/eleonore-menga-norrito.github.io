Introduction

STEP BY STEP

Associating emission factors with activity indicators is the 8th step in carrying out your carbon footprint (the 6th or 7th step if you skip the previous optional steps).

 

Before carrying out this step, check that the desired emission factors and activity indicators have been set up correctly.

 

All indicators marked as Indicator used in the carbon footprint on the Indicator Management screen must be bound to emission factors. If not, alerts will be displayed on the Carbon Footprint Audit screen.

This screen allows you to associate emission factors with activity indicators for a given year and organization.

That means:

  • An emission factor can be associated with multiple activity indicators.

  • An activity indicator can be associated with multiple emission factors.

 

The associated emission factor and activity indicator are linked to an emission category and sub-category.

NOTE To change the emission category and sub-category linked to the emission factor, see the Emission Factor List screen.

 

Associating an emission factor with an activity indicator means associating the values of both. These values are part of the formula for calculating emissions:

TIP  When no value is defined for an associated emission factor, a icon is displayed in the Alert column at the end of the line of the concerned association. Click the button to be redirected to Emission Factor Valuation screen.

Description of the Table Columns

The table contains the following columns:

Column Description

Reference

Code used to identify the activity indicator uniquely.

This code is especially used in the calculation formulas for the carbon footprint.

This code contains letters and/or numbers.

Activity indicator

The activity indicator name.

Indicator unit

The indicator unit.

Code

Code used to identify the emission factor uniquely.

This code is especially used in the calculation formulas of the carbon footprint.

This code contains letters and/or numbers.

Emission factor

The emission factor name.

Emission factor unit

The emission factor unit composed of two units set up on the Emission Factor List screen:

  • Numerator unit

  • Denominator unit

If the denominator unit of the emission factor unit and the activity indicator unit are not the same, a icon appears next to the emission factor unit.

NOTE When binding an emission factor to an activity indicator on this screen, it is recommended to have the same unit for the activity indicator and the denominator unit of the emission factor unit.

Emission category

The emission category name.

NOTE To manage emission categories, see the Management of Emission Categories documentation.

Emission sub-category

The emission sub-category name.

NOTE To manage emission sub-categories, see the Management of Emission Categories documentation.

Alert

A icon is displayed in this column when no value is defined for an associated emission factor.

Click the button at the beginning of the concerned line to be redirected to Emission Factor Valuation screen.

Bind an Emission Factor to an Activity Indicator

To bind an emission factor to an activity indicator:

  1. Click the button at the top left of the table.

    The Bind an indicator to an emission factor pop-up panel appears.

  2. Select the activity indicator information from the drop-down menus:

    • The Chapter

    • The Theme

    • The Section

    • The Indicator, that is the activity indicator label

    • The Unit

      TIP  If you know the name of your indicator, but do not remember where it is located, select All from the Chapter, Theme and/or Section drop-down menus:

      • If all chapters are selected, all themes are displayed.

      • If all themes are selected, all sections are displayed.

      • If a chapter is selected, all indicators included in this chapter are displayed.

      • If a theme is selected, all indicators included in this theme are displayed.

      • If a section is selected, all indicators included in this section are displayed.

  3. Choose whether or not you want to restrict the list of selectable emission factors using the Limit the emission factors corresponding to the unit in denominator drop-down menu:

    • Yes: Selectable emission factors have a denominator unit identical to the activity indicator unit.

    • No: Selectable emission factors have a denominator unit identical to or different from the activity indicator unit.

      NOTE When binding an emission factor to an activity indicator, it is recommended to have the same unit for the activity indicator and the denominator unit of the emission factor unit.

  4. Select the emission factor information from the drop-down menus:

    • The EF category: the emission factor category

    • The EF sub-category: the emission factor sub-category

    • The Emission category

    • The Emission factor: the emission factor label

       

      The Unit and Denominator unit fields are automatically filled in.

      NOTE The Unit is the numerator unit of the emission factor unit.

  5. Click OK.

    A new line appears in the table with the newly-made association.

Unbind the Emission Factor from the Activity Indicator

To unbind the emission factor from the activity indicator:

  1. Click the button at the beginning of the line for the association you want to break.

    The Unbind an indicator from an emission factor pop-up windows appears to confirm your action.

  2. Click OK.

    The emission factor and the activity indicator are unbinded.

Copy the Settings from One Year to Another

To copy the settings from one year to another:

  1. Select the Year, from which you want to copy the settings, from the point of view (POV). For example, 2022.

  2. Select the Entity from the POV as well.

  3. Click the button at the top left of the table.

    The Copy the settings to a target year pop-up panel appears with the Source year and the Current organization fields automatically filled in.

  4. Select the Target year from the drop-down menu. For example, 2023.

  5. Click OK.

  6. Select the Year, to which you copied the settings, from the POV. In our example, 2023.

    The copied settings appears in the table.

Import or Export the Associations between the Emission Factors and the Activity Indicators

To export the associations between the emission factors and the activity indicators:

  1. Click the button at the top left of the screen.

    The Export pop-up window appears with a download link.

  2. Click the download link for the Excel file.

 

To import the associations between the emission factors and the activity indicators:

  1. Export the associations between the emission factors and the activity indicators as mentioned above.

  2. Open the exported Excel file.

  3. Fill in the Excel template, then save your data.

    NOTE To help you fill in the Excel template, see the Fill In the Excel template appendix.

  4. Back to the CSR Insight application, click the button at the top left of the screen.

    The Import pop-up windows appears.

  5. Choose a file.

  6. Click OK.
