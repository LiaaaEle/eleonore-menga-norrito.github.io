Security Notes

Some actions, such as screen access, are permitted only for authorized users, that is, users with the appropriate profile. In other words, if the user does not have the right profile, the user cannot perform the action.

To configure this security (also called user rights), complete the following steps:

  1. Define the profiles in the Profile Management screen.

  2. Define users and attach one or more profiles to them in the User Management screen.

  3. Assign user rights to the desired profiles in the Profile Matrix screen.

NOTE This documentation provides an overview of the Data Collection Campaigns screen.

For more information on this screen, see the following documentations:

  • Data Collection Campaigns: Table View

  • Data Collection Campaigns: Survey View

  • Data Collection Campaigns: Table and Survey Views

 

This screen is dedicated to:

  • Data input for indicators: input values, check for variations, add comments or attachments, ask a question

  • Data validation: submit data input, validate indicators

  • Data view on all data collection campaigns you have access to

 

To access data for a campaign X deployed on an entity Y, there are four conditions:

  • User has access to this screen. If not, screen is empty. See the Security Notes above.

  • Entity Y and indicators deployed on entity Y are included to your functional scope.

    NOTE This screen only displays the entities and indicators to which you have access, that is to say those included in the functional scope for which you are responsible.

    To manage functional scopes, see the documentation on the Functional Scope Management.

    Then, to set up the access restrictions to functional scopes for each profile, see the documentation on the Profile Management.

    Lastly, to set up the access restrictions to functional scopes for each user, see the documentation on the User Management.

  • The entity exist date must be greater than or equal to the campaign start date. If not, an error message appears on the screen.

  • The entity entry date must be less than or equal to the campaign end date. If not, an error message appears on the screen.

 

Through a switch button, you can view the data in:

  • Table View

  • Survey View
