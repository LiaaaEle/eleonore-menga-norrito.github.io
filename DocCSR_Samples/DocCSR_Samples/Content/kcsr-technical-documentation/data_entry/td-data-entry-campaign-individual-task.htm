Individual Task List

SEARCH TIP  Press CTRL + F (Windows and Linux) or CMD + F (Mac) to search within this page.

To access this screen, click: Data entry > Campaign tracking > Individual task list.

Security Notes

Some actions, such as screen access, are permitted only for authorized users, that is, users with the appropriate profile. In other words, if the user does not have the right profile, the user cannot perform the action.

To configure this security (also called user rights), complete the following steps:

  1. Define the profiles in the Profile Management screen.

  2. Define users and attach one or more profiles to them in the User Management screen.

  3. Assign user rights to the desired profiles in the Profile Matrix screen.

The table below contains screen actions that are related to user rights:

Module Screen Action

Campaign tracking

Individual task list

Screen access

See all users

Introduction

In the CSR Insight application, you can track campaign progress by indicator, entity, or user:

  • Tracking by indicator or entity provides users with an overview — without identifying individual user responsibilities and their fulfillment. Use the Campaign Tracking - By Indicator and Campaign Tracking - By Entity screen.

  • Tracking by user enables you to access a detailed user view. Use the Individual Task List screen.

 

This screen provides users with a clear view of the actions they can or must take within campaigns (such as entering, validating, or closing indicators). It also enables administrators to supervise user task lists and identify bottlenecks during campaigns.

 

The screen displays the number of completed and remaining tasks by workflow step for each active user and for one or all open campaigns. Select a User and a Campaign in the point of view (POV).

Description of the Table Columns

The table contains the following columns:

Column Description

User

NOTE Appears only when All users is selected in the POV.

Name of the user who has tasks to complete or already completed within data collection campaigns.

Entity

NOTE Appears only when a single campaign is selected in the POV.

Entity on which the indicator has been deployed within the campaign.

Campaign

NOTE Appears only when All campaigns is selected in the POV.

Campaign in which a user has tasks to complete or already completed.

Completed

Displays items within the user’s permission scope that have been completed:

  • Started: Number of indicators for which data was entered by the user but not yet validated

  • Validated locally: Number of indicators for which data has been validated by the user

  • Closed: Number of validated indicators that have been closed by the user. Data entry is no longer possible.

Remaining

Displays items on which the user on which can still act upon:

  • To input: Number of indicators awaiting user data entry

  • To validate: Number of indicators awaiting user validation

  • To close: Number of validated indicators awaiting user closure

Access to Indicator List

For each completed or remaining task, you can access a list of indicators by workflow step. Right-click a cell in one of the sub-columns of the Completed or Remaining column, then click Details - Table.

Another table appears at the bottom of the screen, displaying the following information:

Column Description

Campaign

Campaign in which a user has tasks to complete or already completed.

Chapter

Indicator chapter.

Theme

Indicator theme.

Section

Indicator section.

Indicator

Label of the indicator on which an action has been performed or must be performed by the user (data entry, validation, or closure).

Entity

Entity on which the indicator has been deployed within the campaign.

Unit

Indicator input unit: Unit of the data entered for the indicator.

Value

Indicator entered value.

Status

Indicator status:

  • Started: A value has been entered for this indicator.

  • Validated: The entered indicator value has been validated.

  • Closed: The indicator has been closed. Data entry is no longer possible.

Access to the Data Collection Campaign

NOTE This feature is only available when you have selected a single campaign in the POV.

To access the details of the data collection campaign selected in the POV for a desired entity and workflow step, right-click a cell in one of the sub-columns of the Completed or Remaining column, then click Details - Data collection screen.

The Data Collection Campaigns screen appears with a filtered view. The POV displays the chosen campaign, entity, and workflow step.

To remove the Workflow filter, hover over the drop-down menu, then click Workflow filter.

Export a Campaign Tracking Table

To export the table, click the button in the toolbar at the top right of the screen.

An Excel file is automatically downloaded to your computer.
