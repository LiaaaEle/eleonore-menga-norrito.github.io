Security Notes

Some actions, such as screen access, are permitted only for authorized users, that is, users with the appropriate profile. In other words, if the user does not have the right profile, the user cannot perform the action.

To configure this security (also called user rights), complete the following steps:

  1. Define the profiles in the Profile Management screen.

  2. Define users and attach one or more profiles to them in the User Management screen.

  3. Assign user rights to the desired profiles in the Profile Matrix screen.

Introduction

The Audit Trail screen provides a comprehensive record of all data-related activities during collection campaigns, including data collection, validation, and adjustment.

 

Use this feature to:

  • Track who changed data, when, and why

  • Ensure compliance with reporting standards

  • Investigate data discrepancies

  • Demonstrate accountability and transparency

 

NOTE You can only view the most recent action performed on indicators for collected data without calculation and consolidation:

  • To access a detailed view of all actions performed, go to the Detailed Audit Trail screen from the application menu.

  • To access information on calculated and consolidated data from this screen, see View Calculated and Consolidated Data.

Point of View (POV)

Users can filter audit trail information by selecting the following items in the POV:

  • Year: Select the reporting year

  • Period: Select the reporting period

  • Entity: Select the entity for which to view audit information

The audit trail detail displays the most recent action for indicators matching the selected POV criteria.

Best Practices for Audit Trail Usage

Regular review:

  • Review audit trails weekly during active collection campaigns to ensure data integrity.

  • Monitor unusual patterns or activities.

  • Verify validation workflows are followed correctly.

 

Data quality assurance:

  • Use audit trails to identify data entry errors.

  • Track repeated corrections to identify training needs.

  • Verify calculations and consolidations.

 

Compliance and reporting:

  • Export audit trails for external audit requirements.

  • Maintain documentation of all data modifications.

  • Demonstrate transparency in reporting processes.

 

User accountability:

  • Track user activities for performance management.

  • Identify bottlenecks in validation workflows.

  • Recognize contributors with high-quality data entry.

 

Troubleshooting:

  • Use audit trails to diagnose data discrepancies.

  • Trace data lineage for complex calculations.

  • Resolve questions about historical data changes.

Description of the Table Columns

The table contains the following columns:

Column Description

Indicator

Indicator label.

Unit

Indicator input unit: the unit of the data entered for the indicator.

Value

Value of the indicator entered in a data collection campaign.

Comment

Comment added to the indicator during data collection.

Document

Indicates whether attachments are attached to the indicator.

When you click an attached file name, two options are available::

  • Download the attached file

  • Access the Details of Supporting Documents screen

Data source

Data collection details:

  • Origin: How data entered the system (manual input, file import by administrator, or data extrapolation).

    NOTE When a user other than an administrator imports a file, the systems data to be entered and not imported.

  • Campaign: Data collection campaign label.

  • Data collection date: Date and time of data entry or modification.

  • Data collection author: User who entered or modified the data.

 

Data quality:

  • Extrapolation method: Method used if the data was extrapolated. For more details, see the Extrapolation Methods section from the Extrapolation Data Follow-Up documentation.

  • Alert: Whether validation alerts were triggered.

Validation steps

Information on data validation:

  • Data validation date: The data validation date.

  • Data validation author: The user who validated the data.

  • Data invalidation date: The data invalidation date.

  • Data invalidation author: The user who invalidated the data.

  • Data closing date: The data closing date.

  • Data closing author: The user who closed the indicator.

Adjustments on validated data

Information on data adjustments — when the campaign is closed:

  • Adjustment date: The adjustment request date.

  • Adjustment author: The user who generated the adjustment request.

  • Initial value: The data value before the adjustment request.

  • Adjustment comment: Justification entered by the adjustment author when requesting an adjustment to the indicator value.

  • Adjustment validation date: The adjustment request validation date.

  • Adjustment validation author: The user who validated the adjustment request.

Indicator reference

Unique code identifying the indicator. This code is associated to the indicator by the administrator in the Indicator Management screen.

Description

Indicator description.

Export an Audit Trail

To export the audit trail table in Excel format:

  1. Click the button above the table.

    The Export pop-up window appears with a download link.

  2. Select an Entity to which you have access.

  3. Click OK.

    An Excel file is automatically downloaded to your computer.

 

To export all supporting documents referenced in the audit trail for one or more indicators:

  1. Click the button above the table.

    The Export attachments for selected indicators pop-up window appears.

  2. Select one or more indicators for which you want to export attachments.

  3. Click OK.

    A download link appears.

  4. Click the download link.

View Calculated and Consolidated Data

Click the button to access information on calculated and consolidated data.

The Details of Consolidations screen appears.

This feature enables users to verify the accuracy and consistency of reported information throughout the consolidation process.

Troubleshooting

Error Solution

Cannot access the screen

Ensure your user profile has the correct permissions. See Security Notes above.

Performance issues

Avoid displaying excessively large datasets at once; use filters to limit the scope.

No data appears on the screen

Verify that:

  1. Data has been entered for the selected indicators.

  2. Your functional scope includes the relevant indicators and entities.

  3. You have selected the correct entity, period, and year in the POV.
