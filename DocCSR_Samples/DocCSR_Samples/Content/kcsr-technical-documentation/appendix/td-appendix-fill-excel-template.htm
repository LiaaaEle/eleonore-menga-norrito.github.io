Fill In the Excel Template

Introduction

In the CSR Insight application, you can export and import Excel files in multiple screens.

This appendix helps you fill in the Excel template you exported. To do so:

  1. In the On this page menu, search for the name of the screen for which you want to find information on filling in the Excel template.

    NOTE The sections in the On this page menu are arranged in alphabetical order.

  2. Check all the mandatory and optional fields mentioned in the corresponding section.

If your import fails:

  1. Download, then open the Excel file.

    Error messages appear in the Comment column.

  2. Check all the error messages written in the file.

  3. Correct all the errors.

  4. Save your data.

  5. Import your Excel file again.

NOTE The Excel file you want to import must be in the same language as the user language in the CSR Insight application.

Mandatory Fields
Field Label Input Type Important Information

Login

Alphanumeric

  • Enter the user login

  • The user login must exist in the CSR Insight application. You can find your desired user login in the User Management screen.

First Name

Alphanumeric

  • Enter the user first name.

  • The user first name must exist in the CSR Insight application. You can find your desired user first name in the User Management screen.

Last Name

Alphanumeric

  • Enter the user last name.

  • The user last name must exist in the CSR Insight application. You can find your desired user last name in the User Management screen.

Profile

Alphanumeric

  • Enter the user profile.

  • The user profile must exist in the CSR Insight application. You can find your desired user profile in the Profile Management screen.

Entity

Alphanumeric

  • If the user profile has restricted access to entities, enter the entity the user can access. Only active entities, as defined on the Indicator Management screen.

    NOTE If the profile can only access specific alternative hierarchies, you can only enter an entity included in one of those alternative hierarchies.

  • If the user profile does not have restricted access to entity, enter All.

  • To know if the chosen user profile has restricted access to entities or not, go to the Profile Management screen.

Scope

Alphanumeric

  • If the user profile has restricted access to functional scopes, enter the functional scope the user can access.

  • If the user profile does not have restricted access to functional scopes, enter All.

  • To know if the chosen user profile has restricted access to functional scopes or not, go to the Functional Scope Management screen.
Optional Fields
Field Label Input Type Important Information

Entity type

Alphanumeric

  • If the user profile has restricted access to organizations, enter the entity type of the organization to which the user profile has access.

  • If the user profile does not have restricted access to organizations, leave the cell empty.

  • To know the entity type of the organization to which the user profile has access, go to the Entity Type Management screen.
