Indicator Tracking

SEARCH TIP  Press CTRL + F (Windows and Linux) or CMD + F (Mac) to search within this page.

To access this screen, there are three ways:

  • First way:

    1. Click: Strategy > My actions > Action reports.

      The Action Reports screen appears.

    2. Click the button at the top right of the action attached to an indicator, then Target definition.

  • Second way:

    1. Click: Strategy > Defining the strategy > Strategy deployment.

      The Strategy Deployment screen appears.

    2. Click the Quantitative target pastille for a strategy or a deployment level (stake, target level 1, target level 2, action) attached to a quantitative indicator.

  • Third way:

    1. Access either the Action Reports or Strategy Deployment screen, then the Create/Edit pop-up panel.

    2. Click the button in the Quantitative follow-up block from the Follow-up tab.

Security Notes

Some actions, such as screen access, are permitted only for authorized users, that is, users with the appropriate profile. In other words, if the user does not have the right profile, the user cannot perform the action.

To configure this security (also called user rights), complete the following steps:

  1. Define the profiles in the Profile Management screen.

  2. Define users and attach one or more profiles to them in the User Management screen.

  3. Assign user rights to the desired profiles in the Profile Matrix screen.

Introduction

NOTE You can view this screen only for strategies, stakes, targets level 1, targets level 2, and actions attached to a quantitative indicator.

 

On this screen, you can define and/or consolidate and distribute quantitative target values across the entities:

  • For the action selected from the Action Reports screen, or

  • For the strategy or deployment level selected from the Strategy Deployment screen.

 

You can also:

  • Calculate the Quantitative Target Trajectory: Distribution on the Temporal Axis

  • Validate or Reject an Alternative Value for a Quantitative Target

  • Freeze Quantitative Target Values

  • Export Quantitative Target Values

 

The table content depends on the input mode of the quantitative target, that is:

  • Bottom up, or

  • Top down

 

The aggregation method used on the entities is by default the temporal aggregation method defined for the linked indicator on the Indicator Management screen, that is:

  • Sum

  • Last known value including empty values

  • Last known value

  • Average

  • Average excluding null values (0)

  • Minimum

  • Maximum

  • Uncertainty (absolute value)

 

However, distribution modes across the entities always prevail over temporal aggregation methods.

Description of the Table Columns

The table contains the following columns:

Column Description

Entity

The entity on which the quantitative target is deployed.

Entity type

The entity type attached to the entity on the Entity Type Management screen.

Actual

Actual quantitative results of a company's operations that have already occurred.

Actual results can be raw data collected or the aggregation of multiple data collected on the linked indicator.

The "Year" sub-column refers to the reference year for which actual data was collected, namely the year prior to the first target year (year N-1).
Target

In this column, you can view "Year" sub-columns, one for each year on which the quantitative target is deployed.

 

If the periodicity of the deployment level attached to the indicator is Yearly, you must define quantitative target values directly in this column for each year.

 

If the periodicity of the deployment level attached to the indicator is Semiannually, Quarterly, or Monthly, you must defined quantitative targets values for all periods each year in another table. If so, the "Year" sub-column displays the annual cumulative, that is the aggregation of all quantitative target values defined by given period.

 

The number and type of "Period" sub-columns available in this other table depends on the periodicity of the deployment level attached to the indicator:

  • If the periodicity is Semiannually, you can view HY1 and HY2 sub-columns.

  • If the periodicity is Quarterly, you can view Q1, Q2, Q3, and Q4 sub-columns.

  • If the periodicity is Monthly, you can view January, February, March, April, May, June, July, August, September, October, November, and December columns.

 

For more details, see Define a Quantitative Target Value.

Define Quantitative Target Values

There are two different ways to define quantitative target values depending on the periodicity of the deployment level attached to the indicator.

 

If the periodicity is Yearly:

  1. Double-click the cell in the Target column for the desired entity and year.

  2. Enter your quantitative target value.

  3. Save.

    This quantitative target value appears in this screen table, as well as in the table of the Quantitative Target Synthesis screen.

    In the Action Reports screen, the icon is in bold to indicate that at least one quantitative target value has been entered for the action.

 

If the periodicity is Semiannually, Quarterly, or Monthly:

  1. Click the cell from the Target column corresponding to the desired entity and year.

    Another table appears in a panel at the bottom of the screen.

  2. Double-click the cell corresponding to the desired period.

  3. Enter your quantitative target value for this period.

  4. Save.

    The quantitative target value appears in this other table.

Consolidate and Distribute Quantitative Target Values across the Entities

Depending on your profile, you can consolidate and distribute quantitative target values across the entities for one or multiple years. See the Security Notes above.

 

The purpose of consolidation and distribution is to portray an accurate picture of your data entered over all the entities.

 

Quantitative target values are consolidated depending on the input mode chosen for the linked indicator, that is Bottom up or Top down.

 

Distribution modes across the entities are only available for the Top down input mode.

Input Mode: Bottom Up

If the input mode for the quantitative target is Bottom up, the entered values of the child entities are automatically consolidated towards the parent entity after saving.

 

Example

  • France is the parent entity of France (Office), Subsidiary 1 and Subsidiary 2.

  • The aggregation method for the linked indicator is Sum.

  • The quantitative value for France (Office) is 10,000.

  • The quantitative value for Subsidiary 1 is 10,000.

  • The quantitative value for Subsidiary 2 is 0.

  • By aggregating the values of the child entities, that are 10,000, 10,000 and 0, the consolidated value for France must be 20,000.

 

Input Mode: Top Down

If the input mode for the quantitative target is Top down, you can:

  • Consolidate the Value of the Parent Entity towards the Child Entities (consolidation and distribution across the entities)

  • Consolidate the Values of the Child Entities towards the Parent Entity (consolidation only)

 

Consolidate the Value of the Parent Entity towards the Child Entities

NOTE Consolidation and distribution across the entities are only available for unfrozen years. When all years are frozen, the Entities repartition option is no longer available after clicking the button. See Freeze Quantitative Target Values.

 

You can consolidate the value of the parent entity towards the child entities using one of the following distribution modes:

  • Copy on children: Values of the parent entity are copied to child entities.

  • Fair distribution: Values of the parent entity are distributed evenly across the child entities.

  • Prorata of the existing: Values of the parent entity are distributed across the child entities in the same proportions as actual data collected on the reference year, namely the year prior to the first target year (year N-1).

 

Distribution modes always prevail over temporal aggregation methods. The temporal aggregation method of the linked indicator is not taken into account in the calculation.

 

To consolidate the values of the parent entity towards the child entities, using the Copy on children as distribution mode:

  1. Check the desired boxes on the left of the table to select one or multiple entities.

    NOTE In the Top down input mode, you can select all entities one by one.

  2. Click the button at the top left of the table.

  3. Click the Entities repartition option from the drop-down menu.

    The Distribute across the entities pop-up panel appears.

  4. Select the Copy on children option from the Repartition mode drop-down menu.

  5. Select one or more years on which you want to copy-paste the quantitative target value.

  6. Click OK.

    The quantitative target value of the parent entity is automatically copy-pasted to the selected child entities for selected years.

Consolidate the Values of the Child Entities towards the Parent Entity

NOTE Recalculation is only available for unfrozen years. When all years are frozen, the Consolidation on entities option is no longer available after clicking the button. See Freeze Quantitative Target Values.

If you find incoherence when entering a value on a child entity, the cell corresponding to the year and the parent entity affected by the error turns red.

 

If quantitative target values were defined by period, the other table that appears at the bottom of the screen also turns red.

 

You can then consolidate the values of the child entities towards the parent entity to retrieve the overall coherence of the values. To do so:

  1. Check the desired boxes on the left of the table to select one or multiple entities.

    NOTE In the Top down input mode, you can select all entities one by one.

  2. Click the button at the top left of the table.

  3. Click the Consolidation on entities option from the drop-down menu.

    The Calculate consolidation for this entity and its descendants pop-up window appears.

  4. Select one or more years on which you want to consolidate quantitative target values.

    The values of the selected child entities are automatically consolidated towards the selected parent entities for selected years.

 

Example

  • BC Group is the parent entity of France and Germany.

  • France is the parent entity of Subsidiary 1 and Subsidiary 2.

  • Germany has no child entity.

  • The temporal aggregation method for the linked indicator is Sum.

  • Quantitative target values entered for 2025 are as follows:

  • By aggregating the quantitative target values of the child entities of France, that are 10 and 5, the consolidated value for France must be 15. No error.

  • By aggregating the quantitative target values of the child entities of BC Group, that is 15 and 10, the consolidated value for BC Group must be 25. However, the BC Group current value for 2024 is 15. The cell in the BC Group line for 2025 has turned red.

  • To retrieve the overall coherence of values:

    1. Check the in front of the BC Group line.

    2. Click the button at the top left of the table.

    3. Click the Consolidation on entities option from the drop-down menu.

    4. Confirm your choice from the pop-up window that appears.

 

Calculate the Quantitative Target Trajectory: Distribution on the Temporal Axis

NOTE Defining the trajectory is only available for unfrozen years. When all years are frozen, and you try to define the trajectory, a warning message appears. See Freeze Quantitative Target Values.

You can define the trajectory of a quantitative target in both Bottom up and Top down input modes.

 

Defining the trajectory of a quantitative target means defining its evolution over time. More precisely, a numeric value or a percentage is distributed from a source year to a target year.

 

To define the trajectory of a quantitative target:

  1. Check the desired boxes on the left of the table to select one or multiple entities.

    NOTE In the Bottom up input mode:

    • When you select a parent entity, all child entities up to leaf level are automatically selected. The calculation applies to all child entities.
    • When you select a child entity, its parent entity is automatically selected. The calculation applies to the selected child entity.

    In the Top down input mode, you can select all entities one by one.

  2. Click the button at the top left of the table.

  3. Click Defining a trajectory option from the drop-down menu.

    The Defining a trajectory pop-up panel appears.

  4. Select the Source year from which the distribution begins.

    NOTE This source year must contain quantitative target values or a last known actual value. If not, you cannot select any data type in the next step.

  5. Depending of the source year selected, select the Data type: Actual or Target.

    NOTE When the selected source year contains a last known actual value, as well as quantitative target values, you can select Target or Actual as data type.

    When the selected source year only contains a last known actual value, you can select Actual but not Target as data type.

    When the selected source year only contains quantitative target values, you can select Target but not Actual as data type.

  6. Select the Target year until which the distribution ends.

  7. Select the Value type applied during the trajectory calculation: Numeric or Percentage.

  8. Enter an Evolution value, either an increase or a decrease.

  9. Select a Repartition mode by which the value or percentage is distributed:

    • Distribute evenly across each in-between year

    • Apply the evolution to each year

  10. Select OK.

    The trajectory is calculated. If quantitative target values already exist, these values are overwritten with new ones.

Validate or Reject an Alternative Value for a Quantitative Target

Depending on your profile, you can validate or reject an alternative value that has been requested for a quantitative target on the Quantitative Target Synthesis screen. See the Security Notes above.

 

The lines with alternative values that need to be validated or rejected are displayed in orange.

 

To validate an alternative value for a quantitative target:

  1. Click the button next to the desired value on the orange line located:

    • In the main table if the periodicity is Yearly, or

    • In the another table that appears at the bottom of the screen, if the periodicity is Semiannually, Quarterly, or Monthly

    The Validate objectives values pop-up window appears.

  2. Click OK.

    The validated value is displayed in the tables on this screen, as well as in the table of the Quantitative Target Synthesis screen.

 

To reject an alternative value for a quantitative target:

  1. Click the button next to the desired value on the orange line located:

    • In the main table if the periodicity is Yearly, or

    • In the another table that appears at the bottom of the screen, if the periodicity is Semiannually, Quarterly, or Monthly

    The Reject objectives values pop-up window appears.

  2. Click OK.

    The value displayed in the tables on this screen, as well as in the table of the Quantitative Target Synthesis screen, does not change.

Freeze Quantitative Target Values

Freezing quantitative target values allows you to disable their input for one or several years.

 

To freeze the quantitative target values:

  1. Click the button above the table.

    The Freeze target pop-up panel appears.

  2. Select one or several years from those available in the drop-down menu.

  3. Click OK.

    You cannot enter and edit the quantitative target values for the selected years anymore. Recalculation and copying are also not available. Moreover, the button is no longer displayed if freezing is done for all years.

 

To unfreeze the quantitative target values:

  1. Click the button above the table.

    The Unfreeze target pop-up window appears to confirm your action.

  2. Select one or several years from those available in the drop-down menu.

  3. Click OK.

    You can again enter and edit the quantitative target values for the selected years. Recalculation and copying are also available.

Export Quantitative Target Values

To export the quantitative target values, click the export button available in the toolbar at the top right of the screen.

An Excel file is automatically downloaded to your computer.
