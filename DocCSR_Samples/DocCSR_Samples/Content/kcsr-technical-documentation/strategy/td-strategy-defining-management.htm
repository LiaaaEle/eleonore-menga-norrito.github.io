Security Notes

Some actions, such as screen access, are permitted only for authorized users, that is, users with the appropriate profile. In other words, if the user does not have the right profile, the user cannot perform the action.

To configure this security (also called user rights), complete the following steps:

  1. Define the profiles in the Profile Management screen.

  2. Define users and attach one or more profiles to them in the User Management screen.

  3. Assign user rights to the desired profiles in the Profile Matrix screen.

Introduction

STEP BY STEP

Creating strategies on this screen is the first step to take in the Strategy module.

After creating strategies, you need to deploy them on the Strategy Deployment screen, that is creating their deployment levels.

You can create actions (last deployment level) from the Strategy Deployment screen or the Action Reports screen.

This screen allows you to view and manage all strategies.

NOTE Each strategy has different deployment levels:

  • Stake

  • For each stake, one or multiple Target level 1

  • For each target level 1, one or multiple Target level 2

  • For each target level 2, one or multiple Action


To deploy your strategies, see the documentation on the Strategy Deployment.

 

Create a Strategy

To create a strategy:

  1. Click the Create strategy button at the top-right of the table.

    The Create new strategy pop-up panel appears with two tabs. Fill out first the Identification tab to provide identification items for your strategy.

  2. Enter the strategy labels in all languages available in the CSR Insight application.

  3. Select the Star year and End Year from the drop-down menu.

    NOTE The start date must be lower than end date. The end year must be higher than start date.

  4. Optional: Select the Person in charge of the strategy.

  5. Click Save.

    You can now fill out the Deployment tab to deploy the strategy on entities.

  6. Select the Deployment Mode:

    • Default: Only one entity is selected or deselected on click.

    • The entity and its children: The entity and its direct child entities (N-1 level) are selected or deselected on click.

    • The entity and its descendants: The entity and all its child entities are selected or deselected on click.

  7. Check the desired boxes to select one or multiple entities.

  8. Click Deploy.

Edit a Strategy

To edit a strategy:

  1. Click the button.

    The Edit strategy pop-up panel appears.

  2. Enter the new information about the strategy.

  3. Click Next.

  4. Select the entities on which this strategy is deployed.

  5. Click Save.

Delete a Strategy

To delete a strategy, click the button at the end of the line for the strategy you want to delete.

WARNING If the strategy has deployment levels, you need to delete them before deleting the strategy. See the View and Edit the Strategy Content section below.

Import or Export a Strategy

To export strategies:

  1. Hover over the button at the top-right of the table.

  2. Click Export strategies.

    The Export strategies pop-up window appears with a download link.

  3. Select one or multiple strategy items from the drop-down menu to choose what you want to export.

  4. Click OK.

    A download link appears.

  5. Click the download link for the Excel file.

 

To import strategies:

  1. Export the strategies, as mentioned above.

  2. Open the exported Excel file.

  3. Fill in the Excel template, then save your data.

    NOTE To help you fill in the Excel template, see the Fill In the Excel template appendix.

  4. In the CSR Insight application, hover over the button at the top-right of the table.

  5. Click Import strategies.

    The Import strategies pop-up window appears.

  6. Choose a file.

  7. Select one or multiple strategy items from the drop-down menu to choose what you want to import.

  8. Click OK.
